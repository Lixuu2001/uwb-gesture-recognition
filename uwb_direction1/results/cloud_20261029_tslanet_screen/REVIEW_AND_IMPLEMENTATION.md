## Primary sources and read scope

Eldele et al., ICML2024, PMLR235:12409–12428: [publisher record](https://proceedings.mlr.press/v235/eldele24a.html), publisher-linked PDF SHA256 `09ebe9bfd2efe4b629dac7dfd6b57090f27c3257dbadf4bf042695b3db831046`, 1,331,383 bytes. Read methods3.2–3.6 and AppendixD.1–D.3/E.1, plus the author classification core/driver, loader, masking utility and dataset commands. This is not a complete-paper review. The browser rejected the PDF MIME type and directory page; the legitimate publisher-linked public PDF was retrieved normally through the cloud proxy, and the public source repository was cloned and pinned. No access controls were bypassed.

The paper proposes adaptive spectral processing followed by interactive convolution, with masked pretraining. Its classification setup uses50 pretraining and100 fine-tuning epochs, AdamW1e-3/decay1e-4; pretraining uses unlabeled training samples. Its benchmark splits differ from user-held-out UWB evaluation. These facts justify an implementable published baseline, not a claim that it improves this corpus or generalizes to new users.

[Author repository](https://github.com/emadeldeen24/TSLANet) pinned at `ca0e88416d3ae49fd50e399c44ae94868378a94d`. Source byte hashes and lawful retrieval URLs are in SOURCE_INDEX.json. The repository's UEA command specifies embedding256/depth3, whereas the Python CLI defaults are128/depth2. The prototype uses the UEA256/3 configuration with patch8/stride4, dropout0.15, masking0.4 and all ASB/ICB/adaptive flags enabled. It has4,132,879 parameters including the author's unused input_layer. It preserves the full inspected architecture; it is not a reduced response bank or smaller rewritten network.

## Implementation observations that must survive any future protocol

`author_core.py` executes only the unedited AST bodies of the five model classes and the masking function. It binds LightningModule to nn.Module for model-only execution; it never runs the Lightning trainer, dataset loader, evaluation exporter or command-line entrypoint. DropPath and truncated-normal initialization come from pinned timm1.0.22 source (`78c3724f4545c0067d0b4d2f7df6337196be01ce`). This framework-only adaptation is explicitly not an exact original-environment/GPU/Lightning-driver reproduction. MIT and Apache2 licenses are materialized with the source files.

Code inspection shows that the spectral gate uses median-normalized energy and an author-specific straight-through threshold derivative. It is not a physical Doppler estimate or simply a cutoff by frequency index. Pretraining predicts a learned patch embedding; its target keeps a gradient connection and dropout, as written by the author. Do not silently detach or redesign it. The input_layer is unused in both phases; the head is additionally unused during pretraining. Those tensors remain present. The repository's padding assignment occurs after constructing dataset tensors; the core with90frames/patch8/stride4 has21tokens and leaves the final2frames outside the convolution windows. No padding correction was applied. The report exporter calls CUDA explicitly, so the original full driver is unsuitable for direct CPU execution.

No literal TSLANet/Adaptive Spectral Block/Time Series Lightweight Adaptive matches were found in the latest STATUS and two memory files or the original789-file source snapshot. This is bounded textual evidence, not exhaustive semantic equivalence proof. Previous frozen spectral descriptors and earlier small neural variants do not by themselves test this full author architecture and two-stage pretraining. That structural difference is an accuracy-experiment rationale, not originality evidence.

## Concrete remaining work and falsifiable future comparison

After the existing confirmation and already registered TimeMIL work are resolved, a future protocol could test whether this fixed full architecture and author50+100 schedule improve the same source-held1 classification problem against the strongest frozen CNN, with a matched100epoch no-pretraining arm to separate the pretraining increment. It must freeze exactly one configuration/seed, train3–6/validate2/diagnose1, input normalization and checkpoint rules, a real cost budget and accuracy stop gate before any new scores. Expected input is the existing real signed maps arranged as567channels×90frames, without invented IQ/kinematics. Any per-record/view RMS adaptation must be explicit because the author's loader has its normalization call commented out. No source7–8 labels may enter choices; no repeated seeds/grids to rescue a failed exact configuration. At present these are design prerequisites, not an executable or registered scientific trial.

Positive scores would only support a useful known baseline/transfer and further frozen confirmation. Negative scores would close that exact implementation/configuration, not all spectral networks. The eight repeatedly developed users preclude independent-validation claims. All real models, IDs, logs and predictions would remain private, with no arrays/model tensors in Git.

To reproduce source verification and the existing synthetic check in a fresh folder, first materialize the pinned sources with `python prepare_sources.py --materialize`, then run the synthetic script under an independent process CPU/wall supervisor. The synthetic output uses an exclusive destination and must not overwrite a prior receipt. The present original training job must not be restarted or duplicated.
