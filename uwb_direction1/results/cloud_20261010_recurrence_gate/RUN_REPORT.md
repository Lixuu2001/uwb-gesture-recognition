# 递归图/RQA候选先例门控（2026-10-10）

## 结论

不以“在雷达手势上使用 recurrence plot / recurrence quantification analysis（RQA）”作为独立新方法继续训练。先例筛查发现其已用于雷达微多普勒人体动作分类：Rani 等在 CW radar 上由 cadence-velocity diagram 构造状态距离/递归表示，并用 RQA 与 Poincaré 特征进行动作识别（IEEE Sensors Journal 2021, DOI 10.1109/JSEN.2021.3126436）。检索到的摘要/元数据说明了这一点，但本轮未取得其全文，故不能声称完整复现或逐项比对。[DOI 记录](https://doi.org/10.1109/JSEN.2021.3126436)。

递归图作为一般时序动作表征也已有先例；例如 Ngo 等报告 RQA 用于 human-activity recognition（EMBC 2020, DOI 10.1109/EMBC44109.2020.9176347）。其传感器与任务协议未证明等同本项目，故不能直接比较分数。[PubMed 记录](https://pubmed.ncbi.nlm.nih.gov/33019022/)。
