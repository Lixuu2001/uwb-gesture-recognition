# SWAD既有方法训练对照：源用户先导准备

2026-10-03。时序矩分支已经停止扩展。本轮转向训练轨迹平均对照，不改输入/架构，不主张SWAD或其雷达适配本身是原创算法。

实际读取作者仓库khanrc/swad的config.yaml，默认LossValley参数为n_converge=3、n_tolerance=6、tolerance_ratio=0.3；hparams_registry.py不是这些默认参数的来源。保存作者两份源码、配置和MIT许可证，blob来源见research/sources/SWAD_IMPLEMENTATION_INDEX.json。未读完正式论文，不能冒称完整论文复现。

tools/swad_core.py保留作者LossValley及AveragedModel算法，改CUDA返回为CPU、无收敛时日志为print，省略未用IIDMax/BN帮助函数；新增显式队列/权重序列化。保留作者final_model初始n_averaged=0的原始语义，没有擅自修正或改成简单最终两点平均。每步累计到一个epoch区间平均，用该epoch末原训练模型验证CE标记；SWAD等权平均选中的区间。当前GroupNorm无BN运行统计。

先导仅在用户3–8内部运行六个划分：一个诊断用户、循环下一个验证用户、其余四个训练；不请求用户1/2信号。每折同一条24轮训练轨迹派生三种检查点：最早最小验证CE（含epoch0）、第13–24轮所有更新的固定平均、SWAD。原轻量CNN、seed2026、AdamW与学习率见冻结SWAD_SOURCE_PROTOCOL.json。训练轨迹不因SWAD谷死亡提前停止，确保所有对照同训练预算；只在三者选择完成后评估诊断标签。源先导平均不能和完整八折94.1843%直接相减。

门槛事先固定：SWAD比ERM平均至少+0.5pp、比固定平均+0.25pp，分别至少4/6用户改善，最差用户不比ERM低超过1pp。失败不扩八折/网格；通过也只是后续强基线资格，不是独立确认或创新。源六用户也已有研发历史。

四项检查通过：36组官方数值对照（窗口长短关系、无收敛、谷死亡、平损失、随机损失及每步序列化恢复）；优化器/Dropout/平均队列中断恢复逐位一致；篡改诊断和排除用户标签不影响所选权重且排除用户信号读取受守卫拒绝；真实CNN结构的合成小样本完整训练/三检查点独立函数式前向与官方选择重放。检查日志见TESTS.log。合成检查不代表真实准确率。

真实源数据成本探针包含5次梯度更新、每步双平均开销；源encoder梯度有限非零、平均后的真实CNN独立前向逐位一致。COST_INITIAL.json的3线程初探估计0.874小时；加入第四项测试后最终身份的3线程探针COST_THREADS3.json估计3.054小时，未过原3小时预算，说明短探针/宿主负载存在较大耗时波动。没有据此启动队列或放宽预算。仅改运行线程数为1后，COST.json估计1.558小时（含75%余量）通过。24轮/优化器/选择/效果门槛均未改变；线程数改变导致5步loss最多约4.8e-7数值差异，不能声称逐位相同。三个探针及原3线程配置均保留，1线程下重跑全部检查。实际运行可能波动，探针不是质量结论。
