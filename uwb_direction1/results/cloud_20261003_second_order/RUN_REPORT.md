# 冻结编码器二阶读出：完整源先导未过门槛

2026-10-03。预注册021bd332afcbc311b19dbbe384bc81f904c7295e后完成六源轨迹的72个候选岭读出及24个验证选定模型。平方根协方差未胜过强网格和CNN对照，停止本投影/描述先导，不扩维度、lambda、种子网格或八折。目标仍未完成。

## 结果与协议

源用户3–8循环：四用户训练、下一源用户验证、一用户诊断。仅复用各折固定第24轮内平均CNN编码器，不重新训练encoder。不同于旧六训练用户的完整八折，以下macro accuracy不能直接与旧LTR93.4417%排序。

|读出/模型|描述维数|六用户平均|
|---|---:|---:|
|原3×4平均网格 + 岭读出|1728|92.8586%|
|投影通道均值 + 标准差|96|86.1705%|
|投影通道均值 + 完整协方差|456|89.1124%|
|投影通道均值 + 矩阵平方根协方差（主候选）|456|89.2879%|
|相同第24轮段平均CNN原融合头|—|92.7083%|
|既有固定13–24轮尾平均CNN强控制|—|92.7222%|

主候选相对网格−3.5707个百分点（1/6改善）、相对均值/标准差+3.1174pp（6/6）、相对原协方差+0.1755pp（3/6）、相对尾平均CNN−3.4343pp（1/6）。门槛要求对网格/对角/尾平均分别至少+0.5pp、对raw至少不降，所有比较至少4/6改善且最差用户不下降超过1pp；仅对角控制比较通过，联合失败。不能因为优于较弱控制就认为达成目标，不能改用raw或挑HV6作为成功结论。

48通道末层12×8特征由固定Gaussian QR正交投影到16维；每雷达独立中心化协方差，除以96位置数，float64特征分解求PSD矩阵平方根（不是逐元素开方），上三角非对角乘sqrt(2)。所有描述拼接投影均值，三路再拼接。没有跨雷达帧协方差/同步/3D假设。固定投影丢失信息、全局二阶统计不保留位置，故本负结果也不能证明二阶信息总体无效。

岭回归按训练用户及其现存类别等权、权重和1，仅训练数据估计均值/尺度，含不惩罚截距；lambda固定0.001/0.01/0.1。每臂独立验证macro最高，其次one-hot MSE最低，其次较大lambda。保存选择后才汇总诊断指标；旧tail CNN只作最终强对照，没有参与读出选择。没有新用户1/2分析、目标统计拟合或测试标签调参。

## 文献与实现边界

依据CVPR2018 fast-MPN-COV/ICCV2017 MPN-COV的协方差池化思想，已读作者README和完整MPNCOV.py，主文未读完。本代码独立表达数学定义，采用特征分解而非作者Newton–Schulz迭代，没有复制版权源码；这是冻结特征探针，**不是端到端iSQRT-COV复现，更不是原创方法**。pyRiemann切空间也不是本次实现。旧时序矩分支的abs RF距离质心/扩展不同，源码核查范围见SECOND_ORDER_REVIEW.md。

## 核验与成本

15个合成样本雷达组合的NumPy covariance/SciPy sqrtm独立对照、零输入/秩亏、位置置换不变性、QR正交性、三个sklearn岭对照及池外数据隔离检查通过。SciPy在故意奇异输入上给出警告，比较仍通过，警告保留。

运行中每折训练/验证/诊断角色首32样本的独立功能卷积、协方差和SciPy矩阵根与实现通过；不是全量特征图重算。全部72候选的验证预测与独立sklearn Ridge重拟合误差<1e−7。最终AUDIT独立核24产物SHA、全部样本ID/角色、72验证读数及24选择、预测指标与冻结门槛。所有逐样本诊断/候选验证输出、选定系数/尺度/偏置及投影矩阵已保存。未保存大特征图，可用固定checkpoint与投影精确重建。

CPU1线程；真实64样本特征与满维合成求解成本估算319.25秒（2倍余量）通过1800秒门槛。实际六轨迹耗时106.28秒，不含初始数据SHA、另行后审计和备份。没有新端到端模型或后台训练在运行。
