第12、24轮，所有轨迹的所有训练用户均零分类错误。验证用户均值仍为7.7222%与7.4343%。因此“持续训练组欠拟合”预冻结门槛未通过（0/6轨迹），不基于此假设直接启动无额外正则的组重加权。验证CE从第1轮0.493761升至第24轮0.638063，同时验证错误率降低；不能把降低分类错误与概率质量混为同一指标。

这不是新方法准确率提升，也不能证明任何特定虚假相关、标签错误或距离/时间机制。Group DRO作者摘要明确指出：训练组损失全低不能保证最差组泛化，更强正则或早停才可能重要。当前诊断与其警示相符，但不等于复现其论文，不否定正则化Group DRO。当前既有基线AdamW weight_decay=0.001，不得误写0.0001；AdamW权重衰减也不能无条件等同原文L2设置。

数据口径：每用户内现存类别等权宏平均；HV6类别3沿原质量排除，不填补。6条轨迹重叠，106,500条角色记录含重复评估，仅7100个源样本，不是新增独立数据。eval模式、轮内平均模型损失不是在线train-mode Dropout损失。验证用户有研究历史，不能当独立外部测试，也不能与旧完整八折93.4417%或当前tail诊断92.7222%直接相减。

耗时203.63秒，CPU单线程，无GPU训练。审计：28个产物SHA、18个模型SHA、1065个组单元独立NumPy重算，CE最大差2.66e-15；每模型每角色首/末批共72批独立函数式前向最大误差0。独立重建角色、汇总和门槛；没有全量106500行独立原信号前向复跑。
