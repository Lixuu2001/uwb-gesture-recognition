## 实验范围和来源

数据继续使用已通过原文件SHA审计的UWB-Gestures，9300条质量保留记录，测试用户h、验证h%8+1、其余六用户训练。每折原编码器导出的三路256维特征冻结。新训练的是原融合头同结构771→256→12 MLP（含3个观察标志），不是原始信号编码器重训。

实现与 [协议](../../research/FULL_VIEW_HEAD_PROTOCOL.json) 在读取本次新测试结果前本地落盘；不是先于结果公开提交的预注册。详见 [依据与原报告复核](../../research/FULL_VIEW_HEAD_RATIONALE.md)。本轮读取了旧单视角迁移报告，避免把既有跨用户SupCon叫作新发明。

四臂拥有相同初始化种子、同批源用户样本、同模型容量及优化器，都按完整三路验证CE选择最早最优轮次（允许epoch0）。subset_ce每批随机实际观察七种子集之一，其他臂只使用完整三路。完整CE与子集CE是本轮匹配对照。旧LTR仍作工程参照，但其训练/选择方案不同，不能把新旧差异全部归因于子集采样。

SupCon采用同一256维激活的L2标准化，不添加投影头；系数0.05、温度0.1固定。跨用户正样本限定为同类不同源用户，同类同用户样本从该对比分母排除。编码器、标准化、目标构造均不读取测试标签；测试指标在验证选轮次完成后计算。

## 全部八用户结果

| 方法 | 八用户平均macro accuracy | 最差用户 |
|---|---:|---:|
| 匹配子集CE | 92.0367% | 71.7273% |
| 完整三路CE | 92.5178% | 71.9091% |
| 完整三路+普通SupCon | 93.1030% | 74.0909% |
| 完整三路+跨用户SupCon | 93.3625% | 76.0000% |
| 历史LTR缓存 | 93.4417% | 75.0000% |

完整CE对匹配子集CE为+0.4811pp，5/8用户改善，描述性用户bootstrap 95%区间[0.0000,1.0313]pp。该有限信号支持保留“针对三路部署优化训练目标”的问题，不证明新方法成立。

跨用户版对完整CE为+0.8447pp，4/8用户改善，区间[-0.4678,2.3542]pp；对普通SupCon仅+0.2595pp，4/8改善，区间[-0.0729,0.7680]pp。对历史LTR为−0.0792pp，6/8改善，但区间[-1.2563,0.8687]pp。最差用户提高1pp不能抹去平均未超过强基线和用户间波动。

冻结门槛要求同时超过完整CE、普通SupCon、历史LTR各至少1pp，并至少6/8用户优于完整CE；未通过。因此不启动第二seed，不扩大读出网格。结果不能称可靠提升或论文创新。

7/32个run选中epoch0：fold2全部四臂，fold5的两项CE，fold6的完整CE。固定旧编码器已经在原融合头下学过特征；本轮沿用原代码的初始化种子，不能把这些“未更新读出”解释为无训练系统。这些选择均按运行前规则保留，不因结果不利更换种子或丢弃用户。

八个用户已参与长期路线开发，用户bootstrap只是当前重叠训练折下的描述性不确定度，不是独立确认。一种读出训练种子也不等于独立编码器复验。
