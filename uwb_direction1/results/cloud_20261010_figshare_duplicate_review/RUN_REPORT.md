# Figshare UWB_HGR 条目是否独立：元数据核查

**日期：** 2026-10-10 UTC  
**结论：** 不作为独立外部队列。该公开条目由上传者明确描述为原始 UWB-Gestures 数据集的预处理版本；它报告 12 类、8 名志愿者、每类 800 个样本和 90×183×3 的文件形状。该说明与本项目使用的原始公开语料身份一致。此次仅核查公开页面元数据，没有下载数据，也没有把它算作独立外部验证。

## 证据与边界

Figshare 条目 [UWB_HGR_Dataset（27915876）](https://figshare.com/articles/dataset/UWB_HGR_Dataset/27915876) 于 2024-11-27 发布，说明其为“原始数据集的预处理形式”，并指向 Ahmed 等人的 *UWB-gestures, a public dataset of dynamic hand gestures acquired using impulse radar sensors*。页面列出 12 个手势类别、8 位志愿者、每类 800 个样本，以及 90×183×3 的样本形状，并显示总下载大小约 3.5 GB。

这些字段支持“同一数据集的再处理/再发布”，而不是新增参与者或采集条件。页面没有公开证明文件逐项同源的校验清单；因此本结论是对其**独立队列资格**的排除判断，不声称已做逐文件 SHA 比对。原始数据描述可见 [Ahmed et al., Scientific Data 2021, DOI 10.1038/s41597-021-00876-0](https://doi.org/10.1038/s41597-021-00876-0)。

## 项目影响

- 不把该 Figshare 条目作为独立外部测试集或跨数据集贡献证据。
- 不下载其约 3.5 GB 文件：可见元数据已将其定位为原语料的预处理版本，下载不会提供独立受试者证据。
- 这关闭了本次发现的外部验证候选，但不是穷尽式数据集搜索，也没有验证任何分类方法。
- 现有 3 视角融合/局部全局融合已被同语料论文先例覆盖。离开一个视角的评估仍只是新的测试问题，不能单独作为原创方法。
- 当前云端没有采集设备、CUDA 或活动训练进程。真实方法目标仍未达到；新的实证路线需要独立采集队列/传感器或有独立外部真值的数据，并先通过先例排重。
