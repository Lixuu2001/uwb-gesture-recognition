# 共享参数的直接干预：源用户对照

2026-10-03，预注册fd4d754b完成后，12条新轨迹已在云端启动；本报告不是识别收益结果。

上一项单损失视角路径梯度诊断在6/6源轨迹满足固定冲突筛查，但负内积不等于有害干扰。本实验直接比较共享编码器与三个独立编码器，另加近似等参数量共享对照，避免把增加容量当成解除共享的证据。

|模型|参数|安排|
|---|---:|---|
|shared128|265836|复用既有SWAD源先导的ERM、固定尾部平均；SWAD不进入本实验|
|untied128|351788|三个独立编码器，初值由同一个共享编码器深拷贝，融合头保持原128宽度|
|shared177|351145|共享编码器，177宽融合头；比untied少643参数，约0.183%|

训练仍是源用户3–8的六个循环留出组合：一个诊断用户、下一个源用户验证、其余四个训练；不新分析用户1/2。24轮AdamW、种子2026、batch64、原legacy输入、无数据增强。主要结果固定为13–24轮逐更新权重平均，最小验证CE的ERM只是次要结果，不按诊断结果切换选择器。对照头的参数位置不同，不能称完全等容量或等函数族。

冻结推进条件：独立编码器的尾部平均相对shared128平均至少+0.5个百分点，相对shared177至少+0.25个百分点；分别至少4/6用户获益，最差用户分别不能低于两个对照超过1个百分点。任一不通过则不扩展该假设的种子、宽度、平均窗口网格或八折实验。这是研发筛选门槛，不是显著性检验；这些用户已有研究历史。

验证已完成：

- 原训练器与新共享训练器在合成数据的前三轮模型、优化器、RNG、尾部平均和最佳模型逐位一致。
- 新两臂中断后恢复与连续训练逐位一致；改变诊断用户输入和标签不会改变所选权重。
- 三独立编码器无参数存储别名，初始化同共享模型；实际训练后参数会分离。
- 三架构均与独立函数式前向逐位一致；真实训练批次64的shared128/untied128初始logits最大差为0。
- 新共享训练器真实首轮的训练CE、验证CE、批次顺序、步数、全部段平均权重与已完成基线逐位一致。首次验证CE为2.4733965397，首轮验证CE为0.2271981239。这仅验证训练匹配，不是新识别收益。
- 基线六条轨迹的配置、环境、公共代码、数据和结果文件SHA核验一致。

实际CPU1线程探针：untied每训练步中位约0.271秒，shared177约0.340秒；单样本推理约2.732ms、1.999ms，共享128约2.137ms。短探针不代表稳定部署测评。288新epoch队列估算含75%余量3.179小时，通过预设4小时成本门槛。成本模型不含另行数据恢复、备份和全部独立复算时间；实际耗时待记录。
