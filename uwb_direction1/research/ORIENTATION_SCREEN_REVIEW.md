# Local range–time orientation: source feasibility screen

HOG is established prior art: Dalal and Triggs, Histograms of Oriented Gradients for Human Detection, CVPR2005. Scikit-image's documented HOG example explains contrast compression, first-order gradients, local orientation pooling and block normalization, and cites Dalal–Triggs and Lowe2004. Read the complete example source docstring at https://github.com/scikit-image/scikit-image/blob/main/doc/examples/features_detection/plot_hog.py (blob41c7fbe50da5e631fac1906a7f4184eb2174c545). This is a library exposition, **not a read of the original papers**.

Read structure_tensor definition, docstring and implementation lines1–155 from https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/feature/corner.py (blob0c61d5b60c5230cc8a8be3c171823031014fce4e). It constructs Gaussian-smoothed products of Sobel derivatives; eigenvalue coherence and principal orientation follow elementary symmetric2×2matrix algebra. Our short implementation independently expresses these operations in SciPy, with Sobel/8 and an explicitly fixed image scale. It is neither a HOG implementation nor a new tensor estimator. The initial main/src/skimage/feature/corner.py lookup was a migration wrapper, not evidence about tensor implementation; the pinned tag resolves that.

Bounded repository searches found no matching orientation-tensor diagnostic in the inspected original Python/Markdown. A GitHub repository search for radar gesture HOG returned no entries; this is **not** a literature-wide search and provides no novelty evidence. A specific radar-HOG paper has not been verified; we do not invent one.

Why examine this after failed local matching? A broad evolving range envelope may have a stable image tangent even without a unique inter-frame patch correspondence. Conversely static range texture and temporal flicker can produce high coherence along coordinate axes: those are excluded by an obliqueness criterion. A per-record time-permutation control preserves frame range profiles but destroys temporal locality. Coherence is internal image structure, not independent physical truth; coherent multipath/amplitude modulation also passes it. No speed, 3Dtrajectory or synchronization claim follows.

Before looking at new real metrics, freeze original/shuffled processing,568prior source IDs, grid/scale/eligibility/coherence/obliqueness and feasibility gates. Labels serve only provenance/quality checks, not fitting or threshold selection. A pass only justifies future recognition controls; failure stops this exact parameter family. Full-paper review and classification benefits would still be needed, and combining HOG/structure tensors with a CNN is not by itself an original contribution.

## Follow-up protocol (before classification scores)

The frozen568-clip diagnostic passed in18/18user/view pairs. This licenses a **separate** fixed readout test, not a favorable classification conclusion. Local orientation histograms use2time×3range cells and9bins, concatenated with the same old128-dimensional CNN hidden vectors. Primary coherence/obliqueness gating is compared with equally sized all-orientation, independently randomized orientation-sign and shuffled-cell controls plus the strong CNN readout/tail baselines. Signs refer to range-time slope orientation moduloπ, not signed RF carrier phase. This remains established CV machinery; benefits and radar-specific originality require independent evidence. The additional readout protocol must be committed before any new classification score is computed.
