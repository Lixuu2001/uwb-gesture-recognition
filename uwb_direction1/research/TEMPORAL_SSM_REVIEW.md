# Temporal self-similarity: prior art and bounded screen

2026-10-07. No novelty claim. This is a mechanistic source-development screen, not a new method contribution.

He, Aubry, Le Chevalier and Yarovoy, *Self-similarity matrix based slow-time feature extraction for human target in high-resolution radar*, IJMWT6(3–4):423–434,2014, DOI10.1017/S1759078714000087. [Institutional paper](https://repository.tudelft.nl/file/File_20f97e3f-1d5f-41f5-92ba-8bebdcd22518). Read extracted text introduction,III(A–D),IV,V and conclusion opening; figures were not visually inspected, remaining references not reviewed. Radar SSM is established prior art: their mutual-information/aligned range-Doppler analysis studies gait periodicity, with weaker range-profile behavior and imperfect angular invariance. It motivates a bounded temporal-relation screen, not gesture accuracy or transfer guarantees. Our cosine envelope Gram and ridge are neither their implementation nor novel by combination.

Junejo etal, *Cross-View Action Recognition from Temporal Self-similarities*, ECCV2008:293–306, DOI10.1007/978-3-540-88688-4_22. [Publisher](https://link.springer.com/chapter/10.1007/978-3-540-88688-4_22). Publisher abstract and metadata read; author-hosted conference and PAMI PDFs were blocked by connector. The abstract motivates temporal relations and explicitly avoids strict viewpoint invariance. Full paper replication is not claimed.

Repository original/tools/research searched for self-similar, recurrence plot, 自相似, 递归图/复现图/回归图: no matching implementation found. Prior spatial-channel covariance pooling discards temporal coordinates; this uses ordered temporal pairs. Prior time-reversal augmentation and multiscale convolutions do not explicitly construct such pairwise relations. Search coverage is not a novelty proof.

Hypothesis: relations between nonadjacent envelope profiles add information to a fixed CNN readout beyond stationary lag statistics. Compare original ridge, ordered SSM, lag-only SSM, and per-record conjugate-shuffled SSM. Shuffling keeps Gram eigenvalues and all entries but breaks consistent event order; lag-only has equal stored width but lower intrinsic capacity, so cannot alone establish a temporal mechanism. All augmented arms share feature count and the same train/validation protocol. Fixed18blocks of5frames provides bounded CPU cost; no data-driven block choice. Real-data fitting only after protocol push and synthetic cost gate. All code, configuration, IDs, weights/predictions and logs retained; raw arrays excluded from Git.

The algebraic spatial-orthogonal invariance is limited to centered frame profiles; it can remove direction cues and is not a physical radar invariance theorem. Normalizing low-energy frames can amplify noise. Full-clip centering excludes causal early-recognition claims. A failed screen closes this fixed choice; do not tune controls or relabel failure as innovation.
