# Conditional RegMixup preparation — no UWB fit or preregistration

Published lead: Pinto, Yang, Lim, Torr and Dokania, NeurIPS 2022, *Using Mixup as a Regularizer Can Surprisingly Improve Accuracy & Out-of-Distribution Robustness*. [Publisher paper](https://proceedings.neurips.cc/paper_files/paper/2022/file/5ddcfaad1cb72ce6f1a365e8f1ecf791-Paper-Conference.pdf); [official code](https://github.com/FrancescoPinto/RegMixup/tree/fd7846532990da67bf56ae71f78517270252f5f5). The paper adds clean-example classification to mixed-example learning, with equal weighting as its practical recipe. Its visual classification and distribution-shift evidence motivates a transfer experiment; it establishes neither radar accuracy nor an original UWB contribution. Updated main scientific text and supplement review, full-native synthetic checks and fixed capacity evidence are recorded in NATIVE_REVIEW.md; reference verification remains bounded.

The pinned released implementation, rather than supplementary pseudocode, governs this prototype. `models/regmixup.py` concatenates B clean and B mixed inputs and performs one model forward, so BatchNorm observes 2B. With equal-sized halves and mean-reduced cross entropy, its loss is one half the sum of clean and mixed losses. Multiplying it by two silently changes gradient scale. `models/regularizers/mixup.py` uses one NumPy Beta draw per batch and torch.randperm; fixed points are allowed. There is no different-class constraint. Class defaults and the released CIFAR10 commands use alpha=beta=20; CIFAR100 commands use 10. Neither is established as optimal for UWB. Official image experiments use ResNet50/WideResNet, B128, 350 epochs and learning rate .1; a native GAP/OvR-BCE/AdamW/64-epoch adaptation would be a disclosed transfer, not a reproduction of that benchmark.

`prototype.py` implements the published batch and CE arithmetic, plus an explicitly proposed native OvR-BCE loss adaptation. `check_math.py` compiles the actual pinned author's mixup function with only its CUDA device call changed to CPU and the actual author criterion. It checks identical mixing/targets/lambda, CE values and gradients against soft-label CE, the half-sum normalization, single concatenated BatchNorm update, and BCE values/gradients against independently weighted hard-target BCE. These are synthetic tensors only. Reproduce with `python check_math.py` under the documented runtime (Python3.12.14, Torch2.15.0+cpu, NumPy2.3.5). MIT author sources and license are retained unmodified; AUTHOR_SOURCES.json records their original Git blob hashes. FILE_HASHES.json hashes this preparation and synthetic evidence.
