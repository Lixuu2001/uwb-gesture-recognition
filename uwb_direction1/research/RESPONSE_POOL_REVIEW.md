# Temporal response pooling: bounded literature/source review

MiniRocket (Dempster, Schmidt, Webb; KDD2021; DOI10.1145/3447548.3467231; arXiv2012.08791) and MultiRocket (Tan, Dempster, Bergmeir, Webb; arXiv2102.00457) are explicit prior art. Author READMEs support these bibliographic identifiers; the papers themselves were **not obtained/read in this turn**. No journal-publication metadata is asserted for MultiRocket.

Sources: https://github.com/angus924/minirocket (README blob a6d1652ae9345cd3ffdc8c0550e8b4bce798302e); https://github.com/ChangWeiTan/MultiRocket at commit3ccaa4f8ed11769b904af885e17018c39c89a2ac (README blob03c26dbf02832605657a29eab1772267c066549f). Read MiniRocket README and MultiRocket README method/introduction, not every long result table. Read multivariate implementation lines1–172 and260–346: source-only bias quantiles, zero-sum length9 kernels, source channel subsets, raw/differenced responses, four pooling statistics. Author code is GPLv3; new code is an independent short mathematical implementation, with no copied source.

The contribution already belongs to prior work: multiple statistics and differences cannot be claimed as a new radar invention. The source version inspected adds `C[j]+bias` for its positive-response mean, uses raw mean indices/run lengths, and alternates padded/unpadded responses. Our **modified mechanism screen** uses positive excess `C-b`, normalized indices, an exact consecutive run, always valid convolution, fixed14kernels/8channels, and balanced ridge. This is not an exact author reproduction; no claim of a bug in the author implementation is made without full-paper verification. Our504responses/2016features are much smaller than the usual author configuration.

Existing original repository searches found an OS-ROCKET open-set citation, but no MiniRocket/MultiRocket implementation in the inspected files. This bounded search proves neither novelty nor absence of other prior art. Previous geometric and optimizer screens failed; this screen asks whether duration/position of full-series responses adds value over positive-proportion statistics. Equal-dimension four-threshold PPV controls feature count; response-position permutation controls ordering while preserving response marginal statistics. Fixed legacy inputs and frozen existing CNN readout/tail predictions provide stronger practical comparators.

The paired temporal-null control is intentionally computed after convolution: it tests pooling response order, not whether convolution itself depends on time. Normalized positions/run lengths alone do not establish speed invariance, physical velocity or radar alignment. Private data remain on the cloud and private Drive. The protocol must be pushed before cost/data scoring; only source-training data are accessed for timing/calibration. A negative result stops this exact screen without an adaptive parameter search. No publication-ready novelty is established by a positive pilot.
