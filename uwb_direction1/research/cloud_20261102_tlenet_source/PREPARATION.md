# Full review-author t-LeNet: source and exact streaming preparation

Next published practical baseline after the failed, audited and privately preserved full TCN20/B64 configuration. Accuracy gain and originality remain separate questions; neither is established here. Bounded remote/local history found no equivalent full t-LeNet1000/B256 execution. This is not an exhaustive novelty search.

Literature: Le Guennec, Malinowski and Tavenard (2016), *Data Augmentation for Time Series Classification using Convolutional Neural Networks*, ECML/PKDD Workshop on Advanced Analytics and Learning on Temporal Data. Verified review: Fawaz et al., *Deep learning for time series classification: a review*, DOI 10.1007/s10618-019-00619-1, section 3.2.6 and optimization table, https://germain-forestier.info/publis/dmkd2019.pdf. The original paper PDF at https://core.ac.uk/download/pdf/48148906.pdf was found but could not be retrieved by the connected tool; its full text was NOT read. Implementation claims are limited to the complete pinned review-author executable and the review, not historical original-paper numerical replication. Architecture is unchanged: Conv1D5/k5/ReLU/same, MaxPool2, Conv1D20/k5/ReLU/same, MaxPool4, Flatten, Dense500/ReLU, Dense12/softmax. Input81x567, 121212 parameters, 8 trainable tensors, 17 Adam variables. Retain complete source defaults 1000 epochs/B256, Adam initial .01 with inverse-time decay .005 per update, unweighted categorical CE and source ModelCheckpoint(min training loss, best only, strict improvement). Validation is logged, not used to select a new policy.

The source itself changes warping=[.5,1,2]/slice=.1 to warping=[1]/slice=.9 when the number of original training examples exceeds 2000. Our fixed metadata 4700 train,1000 validation,1200 diagnostic,time90 triggers that exact unchanged branch before any new UWB value/label read. Each original parent contributes all 10 length81 overlapping windows. Full training is 47000 augmented examples,184 batches/epoch (last152),184000 updates and47000000 appearances; validation10000 windows/40 batches(last16), diagnostic12000/47(last224). Parent RMS is computed on full90 steps; crops do not renormalize.

The eager author preprocessing would allocate17268552000 bytes for the float64 training augmented array alone. A lazy streaming adapter maps augmented index j to parent j//10, crop start j%10, length81. Unchanged author preprocessing at warp1 uses interpolation identity then casts to model float32. Synthetic tests compare every window, repeated labels and permuted rows exactly after float32 conversion; no examples, windows, widths, epochs or batch scale are reduced. Only batch materialization changes. Future real engine must disclose its explicit augmented-row seeded sampler rather than claim native legacy fit DataAdapter RNG parity.

Compatibility is explicit: legacy Adam(lr=.01,decay=.005) becomes native Keras3.11.3 Torch-backend Adam(InverseTimeDecay(.01,1,.005)), preserving intended update-index LR .01/(1+.005*iterations), with native beta .9/.999 and epsilon1e-7. Legacy TensorFlow numerical parity is not claimed. best_model.hdf5 becomes .keras. No fake TensorFlow module or GPU path is used.

Source fit() correctly votes separately over each parent's crop argmax classes, with sorted np.unique giving the smallest class on ties. Standalone source predict() mistakenly votes globally; it is NOT used. The adapter preserves the already-correct fit() parent vote and its tie rule. This is a source-level issue established without gesture labels, not an accuracy-driven rescue.
