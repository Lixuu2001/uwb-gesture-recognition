# Source-user deletion readout robustness

Motivation is to measure decision sensitivity to source-user composition instead of penalizing within-class feature means/covariances (earlier failed experiments). Freeze the already-trained encoder. Refit its linear readout after each of four source users is removed; use the lowest of four scores for each candidate class. Compare to arithmetic averaging and random deletions with exactly matched retained class counts. This finite-model stress test does not remove the user's influence on the encoder and cannot be sold as an unseen-user confidence interval.

Domain deletion is deterministic, class-count-matched random deletion is without replacement, and the primary uses a minimum rather than bagging average. No source implementation copied.

For four fitted class scores s_1..s_4, min_j s_j = min_{q>=0,sum q=1} sum_j q_j s_j. Thus max_class min_j s_j is robust only against choosing a convex mixture of these fixed four score models. It is not a statement about true population distributions, calibrated probabilities, a statistical confidence level or label-preserving sensor physics. Correlated deletion estimates and an encoder exposed to all four users further limit interpretation. Raw ridge scores may be negative; no probabilistic lower-bound language is used.
