### 七、机制事实（画错即整图作废）

1. 三个视角**共用同一组**瓶颈 token `B`，`N_B = 4`；每个视角把自己的 token 序列
   与 `B` **拼接**后送进**同一个**（权重共享的）Transformer 块，块内是普通自注意力。
2. 块的输出按原长度**切回两段**：前段是该视角更新后的 token，后段是该视角
   自己的一份瓶颈副本 `B̃_v`。
3. 三份瓶颈副本**跨视角取平均**得到下一层的 `B`。这条平均是**唯一**的跨视角通道。
4. 视角之间**没有**两两稠密注意力，也没有 3×3 的视角注意力矩阵
   （那是另一张图「特征级融合」的内容，不要混进来）。
5. 更新后的三路 token 仍然**分开**，各自算各自的特征码，检查器保持逐视角独立。
6. 交换发生在编码器**最后 K 层**内部，前面的层逐视角独立，**总层数不变**。
7. 视角嵌入 `e_v` 是在 token 上、在交换**之前**加的。
