## 【提示词正文，从这里开始复制】

我有一张已经画好的三栏对比图，现在只改第三栏 (c) MBT 式瓶颈中层融合。
**构图骨架不要重排**，顶部（栏标题 / 左 L·上 T·右 R 胶囊 / 三张 CIR 图 /
共享编码器 Eθ 虚线框）与底部绿色结论条一个像素都不动，只改中间那段。
下面坐标是栏内局部坐标（栏宽 553、高 829）。

### 改动 1 · 补连线（最要紧，原图这里一根线都没有）

原图上下两组 token 列与中间的瓶颈框之间没有任何箭头，机制的动词全丢了。
补两组：

- **漏斗（向下汇聚，双向箭头）**：6 条曲线，起点是 6 列输入 token 的底部中心
  （x = 56 / 136 / 238 / 318 / 420 / 500，y = 394），终点均匀落在瓶颈框顶边
  （x = 182 / 220 / 258 / 296 / 334 / 372，y = 466）。**两端都要箭头**，
  表示 token 与瓶颈互读互写。线宽 1.3，颜色取该列所属视角色。
- **扇出（向下发散，单向箭头）**：6 条曲线，从瓶颈框底边同样 6 个 x 出发
  （y = 520），落到 6 列输出 token 的顶部中心（y = 590），箭头只在下端。

漏斗 + 扇出的形状本身就在说"6 列宽 → 4 个 token 窄 → 再散开"，
这正是本栏要论证的"窄通道"。**这一条不做，其余都白改。**

### 改动 2 · 瓶颈 token 从椭圆改成矩形

`mbt-bottleneck-token-1..4`：34×34 的 ellipse → **40×17 的 roundRect**，
与 `mbt-L-time-in-1` 等视角 token 完全同尺寸，圆角 2。
位置 x = 181 / 229 / 277 / 325，y = 486。填充 `#E7D9F2`，描边 `#805FA0` 1.1。

理由：同一张图里，**形状表示"是什么"，颜色表示"属于谁"**。瓶颈 token 也是
token，就该是矩形；它的特殊性由紫色承担。现在形状和颜色在重复表达同一件事。

### 改动 3 · 一色一义：绿色只留给结论条

`mbt-bottleneck-frame`：描边 `#28A86B`（绿）→ `#805FA0`（紫），
填充 `#F1FAF5` → `#F4F1F8`，虚线 → 实线 1.6，位置 (170, 472, 212, 46) 圆角 7。

现状是绿色同时出现在瓶颈框、结论条、(b) 栏注意力矩阵三处，紫色出现在瓶颈
token 和右侧小注框两处，读者建立不起"颜色 ↔ 概念"的对应。改完之后：
**绿 = 结论，紫 = 瓶颈，视角色 = 视角**，全图三条规则。

### 改动 4 · 距离 token 的颜色（三栏通病，一起改）

现在所有 `*-range-*` 形状都是 `#D9EFF8 / #4D99B8`，也就是"上 T"视角的蓝色。
于是 L 视角是"黄 + 蓝"、T 是"蓝 + 蓝"、R 是"粉 + 蓝"——12 列里 8 列同色，
读者分不出哪一列属于哪个视角。改成 **颜色 = 视角、明度 = 路径**：

| 视角 | 时序 token（实色，不变） | 距离 token（浅一档，新） |
|---|---|---|
| 左 L | `#FFF0BF` / `#C69A34` | `#FFF9E6` / `#DDBE72` |
| 上 T | `#D9EFF8` / `#4D99B8` | `#EDF7FC` / `#8CBFD6` |
| 右 R | `#F8DDE2` / `#C77782` | `#FCF0F3` / `#DBA6AE` |

(a)(b) 两栏同样处理。

### 改动 5 · 加视角分组条，把 token 数写出来

每个视角的两列上方加一条 3pt 该视角色横线（横跨两列），y = 292（输入侧）
与 y = 600（输出侧），x 范围分别是 36→156、218→338、400→520。
横线下方把原来的「时序 token」「距离 token」两个标签改写成
**「时序 90」「距离 189」**（8.5px），输出侧统一写「更新后」。

原图六列平铺、只有"时序/距离"四个字，既看不出三视角×两路径的分组，
也看不出 token 有 90 / 189 个。**"窄"这个论点需要 90/189 对 4 才成立**，
光画 5 个方块对 4 个圆圈，视觉上一样宽。

### 改动 6 · 上下两组 token 列各压掉一行

现在各 5 行（含 ⋯），压成 4 行：2 个实格 + 一行 ⋯ + 1 个实格。
输入侧 y = 316 / 335 / 354(⋯) / 373，输出侧 y = 618 / 637 / 656(⋯) / 675。
每格仍是 40×17。这样腾出约 70px 给改动 1 的连线。

### 改动 7 · 「在两条路径上应用」注框改造

删掉右上角 95×95 的 `mbt-both-paths-note` 和它里面的 6 个迷你形状
（`mbt-time-path-mini-*` / `mbt-range-path-mini-*`）——占地大、信息少、
用了第三套图形语言。改成两件事：

- 瓶颈框**叠成两层**：在 (178, 464, 212, 46) 再画一个浅色底框
  （填充 `#FAF9FC`，描边 `#AD9AC6` 1.2），压在主框后面；
- 主框右侧写两行 9.5px 紫字：「×2：时序 / 距离」「各一组瓶颈」。

一眼就能看出"两条路径各有一组"，不需要额外示意图。

### 改动 8 · 补平均这一步

瓶颈框右侧（x = 396）加：

- y = 512，Times New Roman 斜体 12px 紫色：`B ← (1/V) Σᵥ B̃ᵥ`
- y = 525，8px 灰字：`三视角各写回一份副本`

以及瓶颈框正上方 y = 459 居中一行 9px 紫色粗体：
`共享瓶颈 token · N_B = 4`（给这行文字加白色描边 3.4、paint-order=stroke，
让它压在漏斗线上仍然可读）。

原图完全没有"取平均"这一步，而这是本栏唯一的跨视角通道，不能只写在结论条里。
