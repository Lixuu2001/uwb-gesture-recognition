# Figure 2 token 视觉统一设计

## 目标

在不改变三种融合机制含义的前提下，把 (a)、(b)、(c) 中时序 token 与距离 token 统一为同一套可编辑 PowerPoint 视觉语法，使读者只感知“融合发生位置不同”，而不会误解为三栏输入表征不同。

## 统一视觉语法

- 每个视角固定使用上下两条横向 token 序列：上方为“时序 token × 90”，下方为“距离 token × 189”。
- 每条序列由 4 个等尺寸圆角 token 单元、省略号和末端 token 单元构成。
- token 单元的尺寸、间距、圆角、描边粗细、标签字体与标签位置在三栏完全一致。
- 左、上、右视角继续使用低饱和黄、蓝、红区分。
- 同一视角内，时序 token 使用略深填充；距离 token 使用同色浅填充，以层级而非新增颜色区分模态。
- 背景保持白色，不使用阴影、渐变、徽章或卡片化装饰。

## 三栏机制表达

### (a) 决策级距离聚合

- 三个视角各自保留一组统一双轨 token。
- 两类 token 独立编码并汇聚为各视角距离输出 `dL`、`dT`、`dR`。
- 最终只在距离层进行 `mean + β var` 聚合。

### (b) 编码后特征级融合

- 注意力前后均使用统一双轨 token。
- 仅三路时序 token 进入视角维多头自注意力。
- 距离 token 以清晰旁路线保持独立，不画成参与该注意力。
- 注意力后的三路时序 token 以相同格式写回各视角。
- 在立体注意力图右侧增加可编辑中文注释：
  - “四头视角自注意力”
  - “行＝查询 · 列＝键”
  - “残差连接后写回各视角”
- 注释采用细绿色竖线引导，无卡片边框和阴影；注意力图片本身继续保持无文字。

### (c) MBT 式瓶颈中层融合

- 瓶颈交互前后均使用统一双轨 token，不再使用“短块列”“时序 90 / 距离 189”等不同画法。
- 中央保留 4 个共享瓶颈 token。
- “时序 / 距离各一组”的含义以紧凑说明表达，避免让两条路径看起来共享同一组模态 token。
- 更新后的 token 与输入 token 使用完全相同的双轨结构，仅通过位置和“更新后”标注表达阶段变化。

## 排版与层级

- 保持现有三栏边界、标题、CIR 输入图与整体白底论文风格。
- token 标签使用与整张图一致的微软雅黑；数学符号继续使用 Times New Roman。
- 连接线保持主流程略粗、旁路略细，避免交叉穿过文字或 token。
- 三栏相同层级尽量共用水平基线：编码器底部、token 输入区、融合核心区和输出区。

## 不改变的内容

- 不更改三种融合策略的科学语义。
- 不更换已批准的无文字立体注意力图片。
- 不重新加入当前源文件中不存在的底部绿色结论框。
- 不改变一页三栏的整体结构。

## 验收标准

- 三栏的时序与距离 token 在形状、尺寸、顺序、字体和标签格式上完全一致。
- (b) 清楚显示只有时序 token 参与视角自注意力，距离 token 独立旁路。
- (c) 清楚显示瓶颈交互前后的对应关系。
- 中文注释可编辑且不遮挡注意力图片或流程线。
- 最终 PPTX 无越界、遮挡、异常换行和模糊图片；完成整页渲染检查。
