# 单视角与三视角总体框架配图设计

## 目标

为论文第2节和第3节制作一组可直接对照的可编辑框架图：图1呈现单视角基础流程，图2在相同骨架上呈现三视角改进，使读者无需阅读正文即可识别新增机制。

## 科学结论与信息边界

- 图1只描述单视角开集识别基础：单路CIR、振幅归一化、双路径Transformer、闭集预测、逐类检查器和阈值判决。
- 图2描述本文三视角方法：三路CIR、权重共享、视角嵌入、跨视角闭集读出、逐类逐视角检查器、决策级距离聚合和随机丢视角训练。
- 特征级融合与MBT是对照策略，不进入图2主方法流程，继续保留在后续融合策略对比图中。

## 视觉系统

- 画布保持现有论文图的宽屏比例和无标题式构图。
- 共同模块使用冷灰、深蓝灰和白色；三视角新增模块使用低饱和蓝绿色；接受/拒识只保留克制的绿/朱红状态色。
- 两图使用相同模块顺序、箭头语义、圆角半径和字体层级。
- 主流程线为1.5--2 pt，辅助/训练路径为1--1.25 pt虚线。
- 所有对象保留为PowerPoint原生可编辑形状与文本。

## 版面

- 图1：单路输入位于左侧，编码器居中，闭集分支位于右上，开集分支位于右下，最终接受/拒识位于最右。
- 图2：三路输入和三路特征纵向对齐；闭集分类器读取三视角聚合特征；开集分支保持三组检查器，经均值与方差聚合后判决。

## 验收

- 两图缩放到Word正文页宽后仍能辨识关键标签。
- 不出现箭头穿过文本、模块重叠、文本截断或一行标题意外换行。
- 图2中所有强调色对象都对应真实的三视角新增机制。
- PPTX可重新打开，且每个模块仍是可编辑对象。
