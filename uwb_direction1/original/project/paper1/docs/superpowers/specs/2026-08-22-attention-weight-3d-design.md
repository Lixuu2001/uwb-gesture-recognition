# Figure 2 立体跨视角注意力权重模块设计

## 1. 目标

为 Figure 2 中“编码后特征级融合”栏重绘一个可独立替换的局部模块。模块需要在白底论文版式中呈现清晰、克制的立体感，使读者第一眼理解为：三路视角表征在每个对齐慢时间位置上形成多头注意力权重，并据此完成跨视角重加权，输出仍保持三路结构。

该图是机制示意，不展示或暗示真实样本的数值注意力分布。

## 2. 科学语义

- 输入为同一慢时间位置的三路时序表征：`z_L^t`、`z_T^t`、`z_R^t`。
- 视角维多头注意力按下式形成权重：
  `A_t^(h) = softmax(Q_t^(h) K_t^(h)T / sqrt(d_h))`。
- 每个 head 的视角权重是一个 `3 × 3` 矩阵，行与列均按 `L/T/R` 排列。
- 对角元素保留，以符合实现中未屏蔽自连接的行为。
- 加权与残差更新后输出 `z̃_L^t`、`z̃_T^t`、`z̃_R^t`。
- 模块不声称距离路径参与跨视角注意力，也不声称对完整 8928 维特征码执行一次全局注意力。

## 3. 构图

采用水平的“输入 → 权重张量 → 输出”单一构图，不再使用九条交叉连线。

1. 左侧放置三条细长半透明特征带，分别代表 L/T/R。
2. 中央放置四层浅透视的半透明 `3 × 3` 权重矩阵，四层对应四个 attention heads。
3. 权重格子的透明度和轻微凸起表达相对强弱；所有格子均为示意，不标具体数值。
4. 右侧由权重张量展开三条更新后的特征带，保持 L/T/R 三路输出。
5. 小型残差弧线绕过张量并回接输出，配合简短的 `weighted sum + residual` 标记。
6. 公式放在张量上方，模块标题放在下方；标题使用“跨视角多头注意力”。

## 4. 立体视觉语言

- 使用约 15° 的浅轴测透视，不采用强烈消失点。
- 权重矩阵采用玻璃片式叠层，边缘清晰、内部轻透明。
- 阴影仅用于区分层级，模糊半径小，避免悬浮卡片感。
- 单元格凸起高度控制在矩阵边长的 3%–6%，不得画成柱状统计图。
- 不使用深色科技背景、霓虹光晕、金属高光或摄影级 3D 渲染。

## 5. 配色与文字

- L：低饱和暖黄 `#F2C45E`。
- T：清洁青蓝 `#55B4DD`。
- R：低饱和珊瑚粉 `#E98A9C`。
- 权重张量：青绿色梯度 `#DFF8EF → #15966C`。
- 主文字：深蓝灰 `#15263A`；辅助文字：灰蓝 `#657487`。
- 白色背景，禁止彩虹色权重矩阵。
- 正式图中只保留公式、`L/T/R`、输入输出符号、`h = 1…4` 和模块标题。

## 6. 输出与适配

- 第一版输出为高分辨率横向 PNG，用于直接评估最终视觉效果。
- 同时保留 HTML/SVG 源，以便调整透视、颜色和矩阵权重示意。
- 构图按 Figure 2 中间栏的宽高比例设计，缩放进入现有 PPTX 后，最小文字仍应可辨。
- 用户确认 PNG 后，再决定是否将该模块替换进可编辑 PPTX。

## 7. 验收标准

- 第一眼读作“多头注意力权重张量”，而不是节点网络、热力图结果或柱状统计图。
- 三路输入、三路输出和跨视角重加权关系清晰。
- 没有交叉线团，没有重复图例，没有伪造数值。
- 在白底、单栏宽度和论文缩印条件下仍具备清晰层级。
- 视觉立体，但不抢过 Figure 2 另外两栏的主叙事。
