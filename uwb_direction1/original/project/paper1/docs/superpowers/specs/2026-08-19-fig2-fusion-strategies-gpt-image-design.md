## 1. 目标与交付边界

本轮以 `C:\Users\19252\Desktop\fig2_three_fusion.pptx` 为视觉与内容基础，先生成一张接近投稿完成度的横版效果图，用于确定 Figure 2 的构图、视觉层级和配色。效果图用于设计决策，不替代最终可编辑 PowerPoint；确认效果后，再在保留原文件的前提下重建可编辑版本。

图的唯一叙事任务是：让读者立即识别三种策略的跨视角信息首次发生交换的位置，并理解三者使用相同输入、共享编码器设置和下游开集判决流程。

## 2. 已确认方案

采用方案 A：对齐式三栏方法图。

- (a) 决策级距离聚合（本文）：编码与检查全程逐视角独立，仅在异常分数端聚合距离证据。
- (b) 编码后特征级融合：三路独立编码完成后，三路完整特征码通过跨视角注意力交换，再进入逐视角检查器。
- (c) MBT 式瓶颈中层融合：编码器拆为前后两段，各视角仅通过少量共享瓶颈 token 在中层交换信息，随后写回各视角。

三栏使用相同纵向骨架、相同下游出口和严格对齐的模块基线。差异只由跨视角交换发生的层级表达。

## 3. 必须修正的内容问题

### 3.1 特征级融合

当前图将该策略描述为“时间 token 全带宽交互、距离路径独立”，与论文方法不一致。新图改为：

`L/T/R CIR → 共享参数双路径编码器 → z_L/z_T/z_R → 跨视角注意力 → 更新后的三路特征 → 逐视角检查器`

其中 `z_v` 表示编码完成后的完整视角特征，包含时间路径和距离路径的信息。不得把跨视角注意力限制在时间 token，也不得画成距离路径独立于融合。

### 3.2 统一下游流程

三栏均显示相同的简化下游：

`逐视角检查器 / 原型 → d_L, d_T, d_R → 归一化均值—方差异常分数`

这样明确实验的唯一结构变量是交换层级，而不是检查器或判决规则。

### 3.3 判决公式

不得只写容易被误解为原始距离的 `mean + β var`。效果图优先使用紧凑但准确的公式：

`s(X)=mean(d_v)/σ̄ + β·var(d_v)/σ̄²`

若生成模型无法稳定呈现公式，则在效果图中写“归一化均值—方差分数”，最终 PowerPoint 再重建完整公式。

### 3.4 符号与标签

- 左、上、右视角统一标为 `L`、`T`、`R`，避免重复使用 `R` 表示距离维。
- 若出现距离路径索引，使用 `m=1…M`；时间路径使用 `t=1…T`。
- “时间路径”和“距离路径”通过文字或小型双条结构表示，不再使用六座高 token 塔。

## 4. 最终构图

画布为约 2:1 的横向白底学术信息图，保持当前三栏顺序。三栏等宽、等高、栏间距一致。

每栏从上到下分为五层：

1. 短标题：策略名称与交换层级。
2. 输入：真实风格的 L/T/R CIR 缩略图。
3. 共享编码：三路独立前向、参数共享的双路径编码器。
4. 核心差异：交换位置与机制，占据全栏最大的视觉面积。
5. 统一出口：逐视角检查器、三路原型距离和同一异常分数。

三栏底部各保留一句结论：

- (a) `仅在决策端汇合`
- (b) `编码后全特征交互`
- (c) `编码中层窄通道交换`

## 5. 三栏机制表达

### (a) 决策级距离聚合

三条视角轨道在产生 `d_L/d_T/d_R` 之前不得出现任何横向连线。三路距离通过规整的直角汇合线进入统一异常分数框。核心视觉指纹是“三条平行独立轨道在最底端汇合”。

### (b) 编码后特征级融合

三路完整特征码 `z_L/z_T/z_R` 进入一个绿色跨视角注意力区。注意力区使用三个节点与少量双向连接表达全视角交互，输出仍保持三路，并分别进入相同的逐视角检查器。不得使用复杂注意力矩阵、线型图例或大量交叉线。

### (c) MBT 式瓶颈中层融合

编码器明确分为前半段和后半段。每个视角以一个紧凑的“时间 + 距离”特征块与少量紫色共享瓶颈 token 互相读写；瓶颈在视角间平均后再写回各视角。各视角之间不得出现绕过瓶颈的直接连接。瓶颈 token 数量只作示意，不表达固定超参数。

## 6. 视觉系统

- 背景：纯白或极浅暖白，适合论文印刷。
- 主结构：深灰文字与中灰轮廓，不使用阴影、玻璃质感或三维效果。
- 视角色：L 为低饱和黄、T 为低饱和蓝、R 为低饱和珊瑚红。
- 跨视角交换：绿色，仅出现在实际交换模块和信息流上。
- 瓶颈 token：紫色，仅用于 MBT 瓶颈。
- 普通编码器与检查器：浅灰或浅灰绿，避免与关键机制竞争。
- 主流程箭头明显强于内部示意线；虚线只表示瓶颈平均或回写。
- 文字使用简洁中文无衬线体；数学变量使用规范斜体风格。

颜色不得同时承担“视角身份”和“时间/距离路径”两种语义。时间/距离双路径改用结构位置或小型文字标签区分。
