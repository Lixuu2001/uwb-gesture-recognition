# 论文一图二三栏重排设计规格

## 1. 目标与边界

本次只规划 `paper1/figs/fig2_three_fusion_strategies_cn_editable_v6_faithful_r3.pptx` 的单页图二，不修改论文正文、实验结果或模型实现。

图的唯一叙事任务是：让读者快速比较三种策略的跨视角信息交换位置。

- (a) 决策级距离聚合：编码与检查全程独立，只在距离分数端汇合。
- (b) 编码后特征级融合：三路独立编码后，通过跨视角注意力交换特征。
- (c) MBT 式瓶颈中层融合：编码器中层仅通过少量共享瓶颈 token 交换信息，再写回各视角。

采用用户确认的 **C 方案：保留三栏结构，按严格统一网格重排**。保留当前三组真实 L/T/R CIR 位图；其他框、文字和连线继续使用 PowerPoint 原生可编辑对象。

## 2. 总体版式

保留当前约 `18.219 × 9.531 in` 的宽画布与三等宽栏。三栏的外框、标题、输入图、编码区、策略差异区和结论区必须使用相同的纵向基线。

建议坐标节奏如下，实际制作允许在不破坏对齐的情况下微调：

| 区域 | 画布纵向位置 | 作用 |
|---|---:|---|
| 栏标题 | 8%–13% | 只写策略名称 |
| L/T/R 标签与 CIR | 14%–27% | 三栏完全同构 |
| 编码器 | 29%–37% | 同栏只出现一次 `共享参数编码器 Eθ` |
| 策略差异主体 | 40%–75% | 三栏唯一需要重点比较的区域 |
| 一句话总结 | 88%–94% | 同尺寸、同位置、短句 |

布局规则：

- 三个外框等宽、等高，栏间距相同；左右页边距相同。
- 每栏内部使用三条固定视角轴：L、T、R。对应对象的中心线从上到下不偏移。
- 主流程只允许向下或水平汇合，禁止大跨度斜线、回头线和穿过文字的连线。
- 所有连接线先绘制、节点后绘制，使连线位于节点下层。
- 三栏内同类对象尺寸一致；不再通过局部缩小字体解决拥挤。

## 3. 视觉规范

### 3.1 圆角框

- 三栏外框：圆角矩形，圆角较小，避免做成卡片或胶囊；线宽约 `1.4 pt`。
- 编码器、注意力、瓶颈区和聚合节点：圆角矩形，圆角约为短边的 `12%–18%`。
- token/特征节点：统一小圆角矩形；同一层的宽高完全一致。
- 一句话总结框：低高度圆角框，不使用阴影。

### 3.2 线条层级

当前文件大量线条约为 `0.56 pt`，缩入论文后过细。重排时采用四级线宽：

| 线条 | 建议线宽 | 语义 |
|---|---:|---|
| 主流程箭头 | `1.8 pt` | 输入到编码、编码到融合、融合到输出 |
| 汇合/分支线 | `1.5 pt` | 三路汇入或从节点分出 |
| 节点轮廓 | `1.2–1.4 pt` | 编码器、特征、注意力、瓶颈、聚合 |
| 内部示意/回写虚线 | `0.9–1.0 pt` | 注意力互连、瓶颈平均与回写 |

箭头统一为中等大小实心三角箭头。虚线只表达 MBT 回写或示意性交换，不再承担普通主流程。禁止同时用颜色、虚线和不同箭头形状重复编码同一含义。

### 3.3 颜色与文字

- L、T、R 沿用黄、蓝、红的轻填充，并在全图保持一致。
- 绿色只用于跨视角融合/距离聚合等关键机制；紫色只用于瓶颈 token。
- 编码器和普通后续模块使用浅灰或浅中性色，不再给每个小节点单独配色。
- 标题与正文使用深色；次要说明使用灰色，但保证缩入论文后的可读性。
- 三栏标题字号一致；模块标题、节点文字和脚注分别只使用一套字号。
- 所有公式变量采用统一形式：`d_L`、`d_T`、`d_R`、`mean + β var`；中英文之间保留适当空隙。

- (b) 单独的“自连接/互连接”线型图例。
- (c) 右侧嵌套小框和重复路径缩略图。

## 5. 三栏具体流程

### (a) 决策级距离聚合（本文）

严格按下列方向从上到下：

`L/T/R CIR → 共享参数编码器 Eθ（三路独立前向） → 三路独立特征/检查器 → d_L、d_T、d_R → mean + β var`

排版要点：

- 三条视角轴在得到 `d_L/d_T/d_R` 前互不相连。
- 三路汇合使用直角折线，先汇到同一水平汇合线，再垂直进入聚合框。
- 底部总结：`仅在决策端汇合`。

### (b) 编码后特征级融合

严格按下列方向从上到下：

`L/T/R CIR → 共享参数编码器 Eθ（三路独立编码） → z_L、z_T、z_R → 跨视角自注意力 → 更新后的三路特征 → 逐视角检查器/判决`

排版要点：

- 注意力框位于三条视角轴的正中，三路输入先垂直进入，不使用扇形斜线。
- 框内只画 L/T/R 三个节点和少量互连，表达“全特征交互”即可。
- 若画更新后的三路特征，使用三个等大的小节点；不再恢复成长 token 塔。
- 底部总结：`编码后全特征交互`。

### (c) MBT 式瓶颈中层融合

严格按下列方向从上到下：

`L/T/R CIR → 编码器前半段 → 各视角的时间/距离特征 → 少量共享瓶颈 token → 瓶颈平均 → 回写三视角 → 编码器后半段 → 检查器/判决`

排版要点：

- 编码器明确分为“前半段”和“后半段”，瓶颈区夹在两者之间。
- 各视角使用一个含“时 | 距”的紧凑块，表达两条路径都参与，不再画六座 token 塔。
- 进入瓶颈的主通路使用实线；平均后回写使用紫色或中性虚线，线宽约 `0.9–1.0 pt`。
- 瓶颈 token 数量仅作示意，文字写“少量共享瓶颈 token”，避免图形数量被误读为固定超参数。
- 底部总结：`编码中层窄通道交换`。

## 6. 对齐与连线验收标准

- 三个外框、三个栏标题、九张 CIR、三个编码器区和三个底部总结框分别等顶、等高或等中心。
- 每栏的 L/T/R 三条视角轴等间距；同一视角从 CIR 到策略主体保持同一中心线。
- 主箭头不得穿过任何文字、节点或图片，不得与栏框重叠。
- 不出现两条含义不同但视觉完全相同的交叉线；不可避免的内部互连只存在于注意力框或瓶颈框内部。
- 同类箭头方向一致、箭头大小一致；所有汇合点处于模块中心线。
- 正文缩放尺寸下仍能分辨主流程、模块边界和 L/T/R 三种视角颜色。
- PowerPoint 检查无文本溢出、对象越界、意外遮挡或断裂连线。
