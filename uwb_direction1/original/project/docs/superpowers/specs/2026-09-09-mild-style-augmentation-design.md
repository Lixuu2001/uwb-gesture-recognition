# 低强度同类跨用户统计增强

用户要求继续下一步，沿用此前时间/风格诊断所保留的低强度独立风格实验，以及持续执行到结果的授权。先前时间增强的固定设置未达开发门槛，本轮不继续调整其幅度，也不叠加时间增强。另一备选三视角阶段对应目前缺少优于 Right 的诊断证据。

本轮只改训练输入投影后的浅层统计。对每个训练样本，以 25% 概率启用 10% 供体统计混合。供体为六位训练用户内、同一手势类别、不同用户的样本：先均匀选可用供体用户，再选该用户的同类实例。验证/测试不选择供体、不施加增强。两个分支使用同一供体和同一启用掩码，在位置编码前操作。

设投影序列 z 的逐通道序列均值/标准差为 μ/σ，供体为 μd/σd，则混合为 z + 0.1*((σd−σ)*(z−μ)/σ + μd−μ)。统计用 float32、population variance、标准差下限 1e-6，源与供体统计均停止梯度。未启用样本保持逐值不变。供体只经过当前线性投影，无梯度、无额外编码器或随机层；输出恢复原 dtype。它是特征统计干预，不声称统计全是用户风格或物理可解释量。

继续使用原 Right 模型、损失、优化器、初始化、批次顺序、dropout 序列和干净验证 CE 选择规则。训练供体/掩码使用从 epoch 前 sampler 状态派生的独立 NumPy 随机序列，断点恢复可重复。训练期间用可移除 hook，保存/部署为原始无 hook Right 模型。

主比较为 STYLE 与上一轮当前环境新训练的 CONTROL。必须核查原代码/数据/runtime/NumPy、配置、平滑矩阵、划分、初始化和采样一致；禁用 hook 的三步短跑与该 CONTROL 短跑 logits 逐值一致后才复用。若条件不满足，先查明原因或重新训练匹配对照。

八折、单模型种子 2026；平均至少 +2 个百分点且至少 6/8 位用户改善才进入后续验证。报告逐用户准确率和宏 F1、选择轮次、描述性用户配对 bootstrap。结果不满足门槛则停止本固定设置。全部训练结束后独立 Right 重放验证和测试输出；本轮不做依赖测试标签的同类供体压力测试。
