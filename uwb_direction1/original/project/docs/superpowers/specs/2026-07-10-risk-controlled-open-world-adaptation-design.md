# 复合分布漂移下风险可控的开放世界 UWB 手势自适应：研究设计

日期：2026-07-10
状态：设计经三轮评审通过并提交(29a30c7)。执行进展：G1a 审计证伪(RESULTS §41，已提交 0eb30c4)；2026-07-11 经审定将 G1b 主方法修正为 calib-select，伪注册降级为机制性负结果，G1 门槛按 b2e/rot2 双家族重锚(早筛与诊断见 RESULTS §42)；2026-07-12 修正选择性反馈的统计口径：反馈预算切片(§5.5)、在线共形阈值只吃随机校准片且覆盖声明分三级(§5.6)、新增查询策略消融(§6.2)与协议测试(§11.1)、相关工作补反馈协变量漂移(§14)
约束：不采集新数据，不把真实硬件部署作为论文成立的前提

## 1. 决策摘要

后续主线从原规划的“潜在运动轨迹 `z(t)` + JEPA + 未知手势描述”调整为：

> 研究 UWB 手势系统在新用户、连续传感器退化、新类到来和有限用户反馈同时存在时，如何在不重训整个模型、不遗忘基类的前提下持续适应，并对自动更新的风险进行控制。

暂定英文题目：

> **Risk-Controlled Open-World Adaptation for UWB Gesture Recognition under Compound Distribution Shifts**

这条路线复用论文一的多视角重建与逐视角检查器，复用论文三的少样本注册、共形集合输出、路由先验校正和自个性化闭环，但研究对象从静态离线注册升级为非平稳数据流中的持续决策。论文成立不能只依赖“换了一个热门模型”，必须同时回答以下三个问题：

1. 现有静态配方在复合漂移下如何失效；
2. 新旧检查器的尺度不对称如何用数据自动校正，而不是人工固定 `s=1.5`；
3. 系统在自动采纳、询问用户和拒识未知之间如何分配有限风险与反馈预算。

## 2. 与论文一、论文三的边界

### 2.1 继承的资产

- 论文一：三视角独立编码、决策级聚合、跨视角重建误差 `e_recon`、缺视角与连续退化的研究入口。
- 论文三：免遗忘的逐类检查器、少样本原型注册、留出用户共形校准、路由与接受解耦、共形门控的个人记忆更新。
- 已有工程：LOSO/leave-(1+n)-out 切分、两组注册词表、编码器缓存、分数 dump、闭环模拟器。

### 2.2 必须新增的研究单元

本研究不能被写成“论文三再加一个在线实验”。它必须新增：

- 一个受控的非平稳开放世界数据流协议；
- 一个无需测试集标签调参的路由尺度估计器；
- 一个显式区分稳定记忆和可塑记忆的在线更新机制；
- 一个受反馈预算约束的风险控制器；
- 时间维度上的恢复速度、覆盖漂移、查询成本和遗忘评价。

### 2.3 明确不做

- 不宣称完成真实长期硬件部署；原数据没有真实时间戳，实验只能称为“deployment-inspired controlled stream”。
- 不把模型包装成 UWB foundation model；现有数据规模不足以支撑这一主张。
- 不以全编码器测试时更新为默认方案；论文三已经证明表征几何变化可能破坏新旧检查器尺度可比性。
- 不把 JEPA、扩散模型或 LLM 作为题目本身；它们只有在直接解决本研究问题且通过早筛时才可作为组件。
- 不重复已证伪的架构级跨视角融合、受试者对抗训练和原有 episodic 辅助损失路线。

## 3. 研究问题与可证伪假设

### RQ1：复合漂移是否构成一个真实且未被现有配方解决的问题？

**H1**：相对于单独的新用户或单独的缺视角，用户漂移、连续视角污染和类别到来叠加后，会使静态 `s`、静态共形阈值和固定个人记忆出现明显的覆盖偏差、错误采纳或恢复迟缓。

若至少两种复合漂移不能造成 `H-mean` 下降 10 个百分点或覆盖误差增加 10 个百分点，本课题停止，不人为制造“困难”。

### RQ2：新旧检查器的尺度不对称能否在部署前自动估计？

**H2a(候选基线，不预设成立)**：基类校准样本的真类分数与新类支持集的留一真类分数之间的稳健中位数比例，与逐折路由最优 `s` 区间稳定相关。2026-07-10 的代理诊断已给出反面证据：在 rot2 dump 上用 `R_cal_reg` 近似 support-LOO，比例估计落在 2.7 附近，而 H-mean oracle 约 1.4--1.9，代理估计的 H-mean(85.8/78.6)劣于固定 1.5(89.8/79.5)。把新旧真类距离中位数拉齐不等于找到最优路由边界，路由还受错误类别距离、孪生冲突和基类先验影响，因此 H2a 只作为审计对象与对照基线。

**H2b(主假设，07-11 按早筛修正为 calib-select)**：对部署的真实 bank，用校准用户的 base 样本与注册类样本(共形侧本已要求的 calib_reg，不新增数据假设)在预注册 `s` 网格上按约束 H-mean 选出路由系数，能够在不接触测试用户标签的前提下替代固定 `s=1.5` 并逼近测试侧 oracle。原伪注册方案被早筛证伪：编码器见过伪新类，其表征与其余 base 类天然可分，base 样本缺乏向伪新列的翻越压力，约束不咬合、`s_hat` 无刹车膨胀——"见过则偏保守"的预期方向相反(RESULTS §42)；伪注册降级为机制性负结果。

### RQ3：风险控制能否同时降低人工反馈和错误自学习？

**H3**：把共形集合输出、用户查询和双记忆更新组织成三动作控制器，可以在固定查询预算下维持目标覆盖，并比“所有 singleton 都自动采纳”显著降低个人记忆污染。

### RQ4：跨视角重建误差能否作为连续传感器可靠度，而不只是 OOD 分数？

**H4**：观测视角与其跨视角重建之间的误差可用于动态降低受污染视角的权重，在干净数据损失不超过 1 个百分点的条件下改善连续退化曲线。

H4 是次级假设。若失败，不影响 H1--H3 构成的主论文。

## 4. 数据与受控开放世界数据流

### 4.1 数据边界

只使用仓库当前的 UWB-Gestures 数据及由其确定性生成的信号退化版本。允许使用公开方法的代码作为基线，但不引入新的自采 UWB 数据。

开发阶段沿用当前两组 `6 base / 3 register / 3 unknown` 词表。最终阶段从五组 OSR base 划分分别构造一对互补的 `register/unknown` 划分，形成 10 组注册词表：按 `config.py` 中每组 unknown 的既有顺序，前三类先作 register、后三类作 true-unknown，再交换两者角色。同一 base 划分的编码器必须缓存复用，避免重复训练。

### 4.2 防泄漏切分

每折采用 leave-(1+n)-subjects-out：

- 训练用户：训练冻结编码器、基类检查器和基类统计；
- 校准用户：建立基类共形分数与路由尺度参考；
- 测试用户：构造开放世界数据流；
- 新类支持样本：只用于注册，不能重复出现在测试流；
- 测试标签：除被查询样本外，只能用于离线评价，不能参与任何在线状态更新。

所有日志必须记录训练用户、校准用户、测试用户、支持样本索引、随机种子和退化日程。

### 4.3 数据流阶段

每个测试折生成一个确定性伪时间流：

1. **冷启动段**：干净的新用户 base、register 和 true-unknown 混合流；
2. **渐变退化段**：某一视角的噪声、衰减、距离轴偏移或局部遮挡逐步增加；
3. **类别到来段**：注册类频率上升，系统开始建立个人记忆；
4. **复合漂移段**：传感器退化、类别先验变化和真未知同时出现；
5. **恢复段**：传感器恢复，用于检查适应机制是否产生滞后或灾难性记忆。

原数据不含可靠时间顺序，因此每段内部采用有种子的随机排列，并在论文中明确这是受控压力测试，不是自然时间序列。

### 4.4 连续退化族

对单视角或多视角施加 0--1 严重度曲线：

- 幅值衰减；
- 加性噪声；
- fast-time/range-bin 平移；
- slow-time 连续块遮挡；
- 从部分污染到完全 view drop；
- Raw 与 ClutterRemoved 之间的处理域切换。

每种退化必须单独报告，再报告随机组合；不得只展示对本方法最有利的组合。

### 4.5 严重度离散化与缓存粒度

连续退化逐样本改变输入，编码器前向无法整流复用，是全计划的算力生死线，第一阶段就必须定死：

- 严重度离散成固定网格：开发期 5 档(0 / 0.25 / 0.5 / 0.75 / 1)，最终退化曲线按需加密；流内逐样本严重度取最近档；
- 静态分数缓存：逐类距离矩阵、共形分数和 `e_recon` 按有序 base 类元组、用户切分、退化类型、视角、严重度档为键全量缓存，但只服务冻结 bank 的基线——距离矩阵只对当前 bank 有效，双记忆在线更新后新类检查器、原型和尺度变化，旧距离作废，在线变头方法不得复用；
- 特征缓存不做"只存 singleton 候选"：一个后续样本是不是候选要用更新后的头判定，而计算更新后的距离又需要它的完整编码特征，是循环依赖。改为两层：计算缓存 = 当前条件(折 × 退化类型 × 视角 × 严重度)下全部流样本的冻结编码器 `f_views`，float16 加 mmap，按条件按需物化、一次只保留当前条件、跑完即清再切换，不同时保存全部组合；持久记忆 = 只有自动采纳与确认样本随可塑库长期保存特征。在线变头方法每次 bank 更新后，从计算缓存对后续样本重算距离；
- 编码器缓存键从 case 编号改为内容指纹：有序 base 类元组(避免类别映射顺序差异)、训练用户集合或 train_idx、测试与校准用户、编码器配置指纹。现有实现(`main.py` 的 `_enc_cache_path`)以 `c{ci}` 开头建键，同 base 的两组词表不会天然复用；
- 旧缓存迁移的冲突规则：同一新键匹配到多个 `c{ci}` 旧文件时，必须比较 state-dict 哈希；内容不一致时禁止静默选择其中一个，重训 canonical 缓存。迁移后 10 组词表只对应 5 套编码器。

## 5. 方法设计

### 5.1 总体数据流

```text
UWB 三视角样本
    -> 冻结编码器与逐类检查器
    -> 逐视角距离 + 重建误差
    -> 视角可靠度聚合
    -> 新旧头尺度对齐后的路由
    -> 未缩放分数上的共形风险控制
    -> {自动采纳 / 请求确认 / 拒绝或暂存}
    -> 仅更新可塑记忆与有标签在线校准状态
```

路由与接受必须继续解耦：尺度对齐只改变“预测为哪一类”，不能偷偷改变共形接受阈值。

### 5.2 稳定—可塑双记忆

**稳定库**保存：

- 冻结编码器；
- base 类检查器、原型和尺度；
- 训练/校准用户建立的 base 共形分数。

稳定库在测试期间只读，因此任何在线错误都不能遗忘 base 类。

**可塑库**保存：

- 注册类初始支持集；
- 用户确认的个人样本；
- 通过严格自动采纳门的低权重伪标签样本；
- 注册类的原型、尺度和样本来源标记。

确认样本权重为 1；自动采纳样本权重不高于 0.25。可塑库采用每类固定容量和来源均衡采样，防止容易样本淹没跨用户支持样本。任何一次更新都必须可回滚到初始注册状态。

### 5.3 自动路由尺度对齐(G1a 审计 + G1b 主方法)

当前固定路由规则把 base 列距离乘以人工常数 `s=1.5`。RESULTS §40 与 rot2 代理诊断共同说明最优 `s` 依赖具体配置：base 头越松，所需 `s` 越小，b2e 与 rot2 的最优区间并不相同，固定常数不可迁移，必须按部署配置估计。估计分两级。

**G1a：中位数比例估计器(候选基线，先审计后使用)**，用下式估计：

1. 在校准用户上收集 base 样本真类的归一化距离中位数 `m_base`；
2. 对每个注册类的每个支持样本 i 做检查器级留一：用剩余 K-1 个支持样本重训该类的三视角检查器，负样本与增强配置保持不变，再用重训后的检查器给被留出的样本 i 计算非合规分数；三类各 K 个，K=5 时共 15 个真 LOO 分数，汇总真类归一化距离中位数 `m_new`；
3. 计算原始比率 `r = m_new / (m_base + eps)`；
4. 令 `n_new` 为所有注册类中有效的 leave-one-out 分数总数，用 `rho = n_new / (n_new + 10)` 向 1 做对数收缩：`log(s_hat) = rho * log(r)`；
5. 把 `s_hat` 裁剪到 `[1, 3]`；若支持集不足 2 个有效样本或统计量非有限，则回退到 `s_hat=1` 并触发”需要确认”状态。

审计纪律：公式、收缩常数 10 和裁剪区间全部预注册，禁止看测试结果后调整；support-LOO 分数必须从缓存编码器对真实支持样本重新提取，现有 NPZ dump 只保存 `register_and_score` 返回的距离矩阵、重建误差和类别尺度，没有支持集特征、支持样本索引和留一分数，不得用 `R_cal_reg` 代替。留一必须是检查器级的：被留出样本不得以任何形式参与该类 MLP 检查器的训练；"检查器固定、只重算原型"的快速近似必须命名为 frozen-head LOO，只能作附加诊断，不得进入主分析。通过标准是 `s_hat` 与逐折 oracle 最优区间稳定相关且方向一致；若如代理诊断预示的那样系统性高估，则降级为对照基线，主方法切换到 G1b。

**G1b：校准侧路由尺度选择 calib-select(主方法，07-11 修正版)**

- 估计器：对部署的真实 bank，用校准用户的 base 样本(`R_cal`)与注册类样本(`R_cal_reg`)在预注册网格 `s in {1.0, 1.1, ..., 3.0}` 上评估路由，取满足"base 准确率相对同一 bank `s=1` 下降不超过 2 分"约束下 H-mean 最大的 `s` 作为 `s_hat`；
- 数据假设：`calib_reg` 是冻结配方共形侧(mondrian/hybrid 新类阈值)本已要求的数据，本方法不新增采集；路由与接受解耦不变，`s` 不触碰共形阈值，覆盖保证不受选择污染，但论文必须明示路由选择与新类共形校准共用 calib_reg；
- 口径：base acc = 校准用户全部 base 类的路由准确率；new acc = 校准用户注册类的路由准确率；H 为二者调和平均；多个校准用户时主判据用池化，逐人结果作尺度敏感性诊断；
- 局限(写入 discussion)：真正"野生"新手势没有校准用户样本，calib-select 只覆盖"注册词表在校准阶段可采样"的部署形态；
- 早筛证据(RESULTS §42)：rot2 上 s_cal 均值 1.25/1.26 vs oracle 1.31/1.35，H@calib-s 距 oracle 0.4/1.2 分，7/8 折 |s_cal − oracle| ≤ 0.3。

**伪注册(原 G1b 方案，降级为机制性负结果)**：留出 base 类 `g`、冻结编码器重训其余检查器(`g` 从真实负样本、mixup、all_real 三处删除)、伪新头用 subject-balanced 支持样本——已实现于 `tools/p4_g1b_pseudo.py`，1 折全量早筛证伪：伪 bank 的 base 精度全网格仅降 ~2 分(真实 bank 即使只留单个注册列也降 ~10 分)，约束不咬合、`s_hat` 膨胀至 2.7、迁移过冲(H 89.8 < 固定 1.5 的 92.7)。机制 = 编码器见过伪新类，base 样本缺乏向伪新列的翻越压力，与 §36 模拟任务共形失败同轴：真实新类的先验排练不出来。保留为论文的方法论证据，不铺 8 折全量。

路由时：

- base 类使用 `s_hat * r_base`；
- register 类使用原始 `r_new`；
- 接受/拒识仍使用未经 `s_hat` 修改的共形分数。

两级估计都只使用训练与校准用户标签和注册支持标签，不使用测试流隐藏标签。oracle-s 的定义：在同一预注册网格上、以"base 准确率下降不超过 2 分"为约束最大化 H-mean 的测试标签最优 `s`，不是只最大化 new accuracy。最终论文必须同时报告固定 `s=1`、固定 `s=1.5`、oracle-s、G1a 比例估计(对照)、伪注册(负结果)与 calib-select(主方法)，避免把固定经验值伪装成无调参方法。

### 5.4 逐视角可靠度

对每个在场视角 `v`，用其余视角重建它，计算标准化重建误差 `e_v`。可靠度定义为：

`w_v = clip(1 / (e_v + eps), w_min, w_max)`，随后在可用视角间归一化。`w_min` 与 `w_max` 不单独调参，分别取校准用户逆重建误差分布的第 5 和第 95 百分位数。

逐类距离按 `sum_v w_v * r_{k,v}` 聚合。若少于两个视角可用于交叉重建，则回退到训练期固定权重；若所有视角均超过校准用户的 99% 重建误差分位数，则禁止自动采纳，只能请求确认或拒绝。

可靠度模块首先以无参数规则早筛。只有无参数版本明显有效时，才允许尝试小型 Adapter；不得直接更新主编码器。

早筛前置一个污染视角定位检查：只污染单个视角 A，比较 `e_A` 的上升与 `e_B/e_C` 的串扰。重建 B/C 的输入里含被污染的 A，`e_B/e_C` 也会被抬高，归因天然是糊的。按严重度分层报告污染视角识别准确率或定位 AUROC；若中等严重度下不能稳定定位被污染视角，H4 直接停止，不进入完整方法。

### 5.5 三动作风险控制器

对每个流样本计算共形预测集 `C_t` 和 top-1/top-2 分数间隔：

- **自动采纳**：`|C_t|=1`、top-1 非合规分数不高于校准真类分数的第 80 百分位数、视角未触发退化警报；样本以低权重进入可塑库，但不进入共形校准队列。第 80 百分位阈值是固定的严格门，不在测试流上调优。
- **请求确认**：`|C_t|>1`、路由尺度回退、覆盖漂移警报，或 top-1 分数处于校准真类分数第 80 百分位与共形接受阈值之间，且当前反馈预算未耗尽；确认标签只更新可塑库与个人原型，不更新在线共形状态——在线阈值只吃随机校准片的标签(见下方预算切片)。
- **拒绝/暂存**：`|C_t|=0`，或风险高且预算已耗尽；样本不更新任何分类记忆。

用户反馈预算以”每 100 个流样本最多查询 B 次”定义，主实验报告 `B in {0, 2, 5, 10}`。控制器不能预先查看未来样本排序，也不能在同一预算下离线挑选最有利样本。

**反馈预算切片(2026-07-12 增补)**。预算内部切成两片，比例预注册、不看结果调整：

- **随机校准片**：每 100 样本 `B_rand = max(1, round(0.2 * B))` 次(B=0 时无任何查询)，查询对象在每个连续 100 样本块内用流种子均匀无放回抽取，与样本难度和模型输出无关。该片是唯一允许更新在线共形阈值的标签来源；其确认标签同时可进入可塑库(入选与分数无关，不污染阈值)；
- **不确定性片**：其余 `B - B_rand` 次按上文“请求确认”的触发条件挑选，确认标签只更新可塑库与个人原型，不进入在线共形状态。

切片的动机：被“请求确认”选中的样本经过不确定性筛选，与全流不可交换，用它们更新分位数会把“困难子集的覆盖”冒充“全流覆盖”；且确定性触发规则下容易样本的被查询概率为零，逆倾向加权没有正概率支持、无法事后修正，因此用切片保证校准标签无偏，而不是用加权补救。随机片会把少量预算花在容易样本上，这是无偏校准的明码成本，照实报告。折算到约 1049 样本的流，随机片/不确定性片约为：B=2 时 10/11，B=5 时 10/42，B=10 时 21/84。

四档预算的角色预先定义，流长按现有闭环约 1049 样本计：

- `B=0`：纯静态共形加只读记忆，检验无反馈下的系统上限；在线阈值与警报链路整体不启动；
- `B=2`：低反馈极限，约 21 次查询；覆盖警报需要 20 个确认样本，可能到流末才激活甚至不激活；
- `B=5`：主方案档，约 52 次查询；
- `B=10`：反馈充足上界，用于分离”方法不行”与”反馈不够”。

B=0/2 档没有明显在线共形增益属预期对照结果，不作为反对在线共形模块的证据。

### 5.6 在线共形更新

静态阈值来自留出校准用户。在线阈值只用**随机校准片**的确认样本更新(§5.5)：不确定性片的确认标签虽然真实，但经过难度筛选，与全流不可交换，不得触碰阈值状态。伪标签只能更新个人原型，不能用于覆盖保证。在线分位数采用 `eta_t = 1 / sqrt(t + 1)` 的递减步长更新，其中 `t` 只统计随机片已确认反馈，并记录每个有标签时刻的命中指示。

覆盖声明分三级，论文与结果表中不得混用口径：

1. **全流离线覆盖(主对象)**：用隐藏测试标签在整条流上事后计算，只作评价、不参与任何在线状态，是 G2 覆盖判据的统计对象；
2. **随机片在线覆盖(无偏但低精度)**：B=5 档每折约 10 个标签，90% 目标下二项标准误约 9 分，只报告点估计与区间，不做逐折判定；
3. **确认子集诊断(有偏，仅监测)**：全部确认样本上的经验覆盖只用于触发警报，不构成覆盖声明。最近 20 个确认样本的经验覆盖低于 85% 或高于 95% 时触发覆盖漂移警报；不足 20 个确认样本时不触发。该警报是有偏样本上的启发式监测器，其触发动作(进入保守模式：关闭自动采纳、提高查询优先级、继续保留稳定库作为回退)不依赖无偏性。

无反馈或随机片标签不足时阈值保持静态，不宣称拥有新的在线覆盖保证。

## 6. 对照与消融

### 6.1 主要基线

1. 论文三冻结系统，`s=1`；
2. 论文三冻结系统，固定 `s=1.5`；
3. 固定 `s=1.5` + 原 singleton 自个性化；
4. 不带风险控制的朴素伪标签自训练；
5. 只做在线共形、不更新记忆；
6. 只更新可塑记忆、不做在线共形；
7. T3A 式测试时原型更新(主要 TTA 基线)：冻结特征提取器、只用测试样本调整类模板，与本系统的原型和逐类检查器结构天然对口；
8. TENT/CoTTA 与开放世界 ODS(次要 TTA 基线)：编码器为 LayerNorm、决策是逐类距离而非 softmax，接口适配方式必须显式报告；
9. 提议的完整方法。

所有 TTA 基线必须使用相同的流顺序、反馈预算和计算时间。若其输出接口无法自然支持逐类检查器，应明确报告适配方式，而不是静默删掉不利基线。本方法相对 T3A 的差异必须落在共形风险门、稳定—可塑双库与查询预算上，而不是原型更新本身。

### 6.2 必做消融

- 固定 `s` vs G1a 比例估计(对照) vs 伪注册(负结果) vs calib-select(主)；
- 单记忆 vs 稳定—可塑双记忆；
- 全部 singleton 采纳 vs 固定 q80 严格门控 vs 用户确认；
- 静态共形 vs 在线共形；
- 查询策略：全随机 vs 全不确定性 vs 预注册切片混合，相同总预算下比较全流覆盖、记忆污染与 H-mean；
- 等权视角 vs重建可靠度权重；
- 只含单一漂移 vs 复合漂移；
- 不同反馈预算；
- 不同可塑库容量和伪标签权重；
- 现有两组词表早筛 vs 10 组词表最终验证。

## 7. 评价指标

静态指标仍报告，但不能作为唯一结论：

- base accuracy、new accuracy、二者 `H-mean`；
- OSCR、AUROC、true-unknown rejection；

- 覆盖指标一律标注口径：全流离线 / 随机片在线 / 确认子集诊断(§5.6)，三种口径不得混排同一列；

- 相对冻结系统的计算开销。

## 8. Go/No-Go 阶梯

### G0：问题成立

用现有论文三冻结配方跑受控流。至少两类复合漂移满足以下任一条件：

- `H-mean` 下降不少于 10 个百分点；
- 目标 90% 覆盖的绝对误差增加不少于 10 个百分点；
- singleton 自动采纳污染率超过 10%。

否则停止该方向。

**(07-18 执行修正,判决前定死)** 第三条的绝对 10% 口径不可用:clean 流的 §39 采纳池污染率本身已达 20.0%(c0)/51.1%(c1)——单校准被试抽签折的新类 q 塌缩所致,连分数与 clean 逐位相同的 atten 都会"触发"。三条线统一改读相对 clean 流的增量:H-mean 降 ≥10 分(全流或退化子集)、max|cov−90| 增 ≥10 分、采纳池污染率增 ≥10 分。退化条件按(族 × 受灾视角)展开为单元格,族触发=任一单元格在任一词表触发(存在性命题),全部单元格照报。**判决(07-18,RESULTS §44,每折重播种 bank 确定性重生成后的终版):PASS,5/6 族触发(A 线全网格无单元触发,漂移让采纳门变稀而非吃毒),仅 atten 因 abs_std 逐视角标准化解析恒等而免疫。**

### G1：自动尺度对齐成立(G1a 审计，G1b 主判据)

**G1a 审计(先行)**：用 §5.3 的检查器级 support-LOO 提取真实留一分数后，比例估计与逐折 oracle 最优区间稳定相关、方向一致。通过则保留为轻量候选；不通过则降级为对照基线，主方法切换到 G1b。审计失败是可报告的负结果，不设生死线。

**G1b 主判据(07-11 重锚)**：在 b2e(6 训练被试，`s=1` 未经矫正)与 rot2(5 训练被试，`s=1` 已被"少一人"半矫正，RESULTS §40)两个 dump 家族分别评估：

- 与 oracle-s 的 H-mean 差距不超过 2 个百分点，oracle-s 按 §5.3 定义在固定网格上、base 下降不超过 2 分约束下取 H-mean 最大；
- H-mean 不劣于固定 `s=1.5`(差距 1 分内视为持平)；
- base accuracy 相对同 bank `s=1` 平均下降不超过 2 个百分点；
- "new accuracy 相比 `s=1` 提升至少 5 分"仅对 b2e 家族要求：rot2 的 `s=1` 基线已被半矫正，case-0 连 oracle 都不满足该条，照字面执行会误杀；
- 两组互换词表均不出现系统性反向退化；孪生重灾词表(现 case-1)单独报告，孪生吞噬是几何问题，超出尺度校正的解释范围，不计入 oracle 差距判据。

否则回到"逐头显式尺度约束"，不再继续调估计器常数。

### G2：风险控制成立

在 `B=5/100` 的反馈预算下：

- 自动采纳污染率低于 5%；
- 覆盖采用双层判据，统计对象为全流离线覆盖(§5.6 第 1 级口径，隐藏标签仅作事后评价)。主判据：每组词表、每种退化条件下，8 折宏平均覆盖率落在 87--93 之间；单折约 150 个新类评价样本在 90% 覆盖下的二项标准误约 2.4 分，逐折 ±3 硬门会被抽样噪声误杀，故不设。稳定性诊断：报告逐折覆盖误差的中位数、90 分位数和最差折，且相比静态方案逐折绝对覆盖误差显著下降，置信区间用以测试用户为聚类单位的 bootstrap；
- `H-mean` 相比论文三静态闭环提升至少 5 个百分点；
- base 遗忘不超过 1 个百分点。

双层设计的动机：论文三已证明平均覆盖接近 90% 仍可掩盖逐用户 61--100 的摆动，只看池化均值会重演尺度抽签。

否则只保留自动尺度对齐论文，不堆叠更多控制模块。

### G3：连续退化模块成立

可靠度加权需在至少 4/6 类退化上改善退化曲线面积，且干净流下降不超过 1 个百分点。否则删除 H4，不影响主线。

### G4：最终论文级稳定性

完整方法需在 10 组注册词表中至少 8 组优于最强静态基线，适应开销相对冻结系统不超过 50%，并通过所有泄漏审计。否则只能作为论文三的扩展实验，不独立成篇。

计划新增独立模块，避免污染论文一/三主路径：

## 10. 异常与安全回退

- 支持样本不足、`s_hat` 非有限或 G1b 网格选择在互换词表上方向不一致：使用 `s=1`，关闭自动采纳并请求确认；
- 反馈预算耗尽：冻结在线共形状态，继续拒绝高风险样本；
- 所有视角被判为不可靠：不更新记忆，输出拒绝/暂存；
- 可塑库污染警报：回滚到初始注册快照；
- 新类样本长期不进入 singleton：不做伪标签自证，保留为能力边界；
- 在线方法运行速度低于数据流速度：按真实计算时间减少其可处理样本，不能暂停数据流等待；
- 任一运行使用了隐藏测试标签：该运行作废，不能进入结果表。

## 11. 验证与测试要求

### 11.1 协议测试

- 训练、校准、支持、测试和被查询集合索引互斥；
- 随机校准片的查询时刻在流生成时由种子确定、可完整复现，且生成过程不读取任何模型输出或分数；

- 相同种子生成完全相同的数据流和退化日程；
- 不同种子只改变允许随机化的部分；
- 每 100 样本查询数不超过预算；
- 测试标签只在 query 事件和最终 evaluator 中可见。

### 11.2 状态测试

- 测试前后稳定库逐张量一致；
- 自动采纳样本不进入共形校准队列；
- 回滚能恢复初始原型、尺度和队列；
- `s_hat` 只作用于路由分数；
- 所有视角失效时不发生 NaN 或错误记忆更新。

### 11.3 回归测试

- 原论文一 LOSO、缺视角和重建分数接口输出不变；
- 原论文三静态注册、共形和闭环模式输出不变；
- 新模块关闭时，完整入口退化为论文三冻结系统；
- 编码器缓存键迁移后，同一 base 集合的两组词表命中同一编码器缓存，旧键缓存仍可读；同一新键匹配多个内容不一致的旧文件时报错并重训，不静默选择；
- G1b 每次留出重训的 base 检查器负样本池中不含留出类(负样本、mixup、all_real 三处断言)。

1. 提出面向 UWB 手势部署的复合漂移开放世界数据流协议，同时评价用户漂移、连续传感器退化、类别到来和有限反馈；
2. 提出校准侧伪注册的自动新旧头尺度对齐，中位数比例估计作为被审计的对照，替代人工路由先验并保持接受判决独立；
3. 提出稳定—可塑双记忆与预算约束的共形风险控制器，在维持基类和目标覆盖的同时降低人工确认与错误自学习；
4. 系统量化恢复速度、覆盖漂移、记忆污染、查询成本和计算开销，给出静态准确率之外的部署边界。

若 H4 通过，可将重建误差可靠度作为第四项方法贡献；若不通过，只作为负结果或附录，不能削弱前三项主线。

## 14. 相关方法定位

- 测试时适应：研究非平稳测试分布下的在线更新，但本研究额外面对注册类、真未知和反馈预算。
- 在线共形预测：提供随时间更新的风险工具，但本研究必须区分有标签阈值更新和无标签记忆更新。
- 反馈协变量漂移下的共形预测：当查询哪些样本由系统自身决定时，标签集合与目标分布不可交换；JAWS-X 一类加权方法要求查询概率有正支持，本设计的确定性触发不满足该条件，故用预算切片(§5.5)而非加权修正。
- 雷达自监督学习：可提供重建误差和轻量适配信号，但不以大规模基础模型为前提。
- JEPA/world model：保留为未来有更多无标签雷达数据时的长期方向，不进入本设计的关键路径。

## 15. 最终边界声明

本设计在“不采新数据”的条件下，用受控数据流、复合漂移、用户反馈成本和在线风险评价提升现实性。它可以证明方法更接近部署约束，但不能替代真实跨天、跨地点和硬件在线实验。论文必须把这一区分写清楚：贡献是部署导向的方法与评测，不是已经完成现实部署。
