# Paper 1 Figure 2：GPT Image 中文版原生 PPT 复刻设计

## 目标

将 `paper1/figs/fig6_fusion_variants_technical_ai.png` 作为严格视觉与空间参考，重新绘制为一页 PowerPoint。最终文件必须由 PowerPoint 原生形状、连接线和文本框构成，而不是把 PNG 作为背景或整图嵌入。

最终用途是论文插图，因此保持 GPT Image 版本的宽幅比例、三行紧凑结构和科研线稿质感。输出为新文件，不覆盖 `fig6_fusion_variants_technical.pptx`。

## 输出

- 最终 PPT：`paper1/figs/fig6_fusion_variants_gptimage_rebuilt.pptx`
- 全页预览：`paper1/figs/fig6_fusion_variants_gptimage_rebuilt.png`
- 生成器：`paper1/figs/build_fig6_fusion_variants_gptimage_rebuilt.mjs`

## 画布与视觉语言

- 单页自定义宽幅画布，比例贴近 GPT Image 原图 `1728 × 928`。
- 纯白背景，不使用渐变、阴影、3D、装饰性底板或卡片式布局。
- 主线为黑色或冷灰色，线宽细且统一；箭头由左向右。
- 功能分组使用圆角虚线框。
- 共享权重编码器使用极浅蓝填充；F1 跨视角模块使用浅紫描边；F2 瓶颈交换使用柔和琥珀色描边。
- 中文说明采用微软雅黑，数学变量采用 Times New Roman 或兼容数学字体。
- 所有文字保持水平排列，避免竖排与旋转文字。

## 面板结构

### (a) 决策层聚合（本文方法）

- 左侧为 L、T、R 三个输入节点及“三视角 UWB CIR”。
- 三条通道分别进入共享权重编码器，每条显示 `Transformer模块 ×4`。
- 编码结果 `fL/fT/fR` 分别进入视角特定检验器。
- 检验器显示 `ηL/ηT/ηR` 和 `8928 → 1024 → 128`。
- 输出 `dL/dT/dR`，仅在末端聚合到异常分数 `s`。
- 禁止在编码器、特征或检验器阶段绘制跨视角连线。

### (b) 特征层融合（F1）

- L、T、R 经共享权重编码器得到 `fL/fT/fR`。
- 三条特征流进入 `Q/K/V`，再进入“多头注意力”。
- 从编码器后特征位置绘制一条明确的紫色残差旁路，接入“相加与归一化”。
- 融合后输出 `f̂L/f̂T/f̂R`，再进入三个视角特定检验器。
- `dL/dT/dR` 在末端汇入 `s`。
- 禁止把融合位置移动到编码器内部或检验器之后。

### (c) 瓶颈中层融合（F2，MBT式）

- L、T、R 分别进入独立模块，并生成普通 token 堆叠 `TL/TT/TR`。
- 普通视角 token 不允许直接跨通道连接。
- “唯一跨视角通道”虚线框内总共恰好四个琥珀色瓶颈 token：第一个标 `B`，其余三个留空。
- 四个瓶颈 token 连接三条视角通道与三个瓶颈融合模块。
- 独立阶段标注 `×(4−K)`，瓶颈融合阶段标注 `×K`。
- 融合后 `f̂L/f̂T/f̂R` 进入三个视角特定检验器，产生 `dL/dT/dR` 并汇入 `s`。

## 可编辑性约束

- 每个模块、token、距离节点、分组框和标题必须是独立 PowerPoint 对象。
- 所有箭头必须是原生连接线，不能作为位图的一部分。
- GPT Image PNG 只能作为人工对照参考，不嵌入最终幻灯片。
- 不将整组结构栅格化，不使用 SVG 整图替代原生对象。

## 质量验证

- 自动测试确认三个面板顺序、中文标签、F1 残差支路和 F2 的四个瓶颈 token。
- 自动测试禁止 Figure 1 专属内容：闭集分类器、View dropout、Accept/Reject、OSCR。
- 导出 PPTX 后渲染为 PNG，逐页全尺寸检查。
- 运行幻灯片溢出检查，修复任何越界、裁切或意外重叠。
- 人工检查所有箭头方向、虚线分组、中文换行以及普通 token 的跨通道禁连约束。

## 完成标准

最终 PPT 在视觉上明显贴近 GPT Image 中文版，而不是上一版流程图；同时保持所有核心对象可编辑、科学拓扑准确、中文清晰，并可直接用于论文插图导出。
