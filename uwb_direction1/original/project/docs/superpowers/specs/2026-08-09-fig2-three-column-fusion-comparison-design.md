# 图2三列融合策略对比图设计

## 目标

将现有三行流程图重构为适合中文期刊单栏或通栏缩放的三列对照图。读者应在不阅读正文的情况下，一眼判断三种方法的唯一变量是跨视角信息交换层级，而不是编码器容量或下游判决方式。

## 语义边界

- 三种方法均接收左、上、右三视角输入，并使用同一套共享编码器权重。
- 决策级聚合：编码与检查阶段三路独立，仅距离 `d_L, d_T, d_R` 在末端聚合。
- 特征级融合：共享编码器输出 `f_L, f_T, f_R` 后，通过一次跨视角注意力得到交互特征，再分别进入检查器。
- 瓶颈中层融合：编码器拆为前后两段；跨视角信息仅通过少量共享瓶颈 token `B` 汇入、平均和再分发。
- 下游检查器与异常分数只保留简化出口，不展开完整分类与判决流程。

## 顶会方法图拆解结论

参考 MBT、CrossViT、TokenFusion、Swin Transformer、Mask2Former 与 Segment Anything 的原论文方法图，采用以下可复用视觉语法：

- 主数据流使用连续实线，结构内部的注意力流使用更细、更浅的线；关键交换处才提高颜色饱和度与线宽。
- 实线框表示真实存在且执行计算的模块；虚线框表示共享作用域、重复层组或受约束的信息交换区域；虚线不得仅作装饰。
- 大模块内部使用 token、特征图、残差支路或层堆叠等微型结构，避免只有文字标签的空方框。
- 重复模块用层叠、括号和 `×N` 压缩，不逐个复制完整大框。
- 图片只用于说明输入形态、空间层级或输出语义，不在每个节点塞图；图片与模块之间留出明显的角色差异。
- 配色遵循低饱和主体、单一高亮机制和中性下游，不用三列各自换一套颜色。

## 版式

- 画布保持当前宽幅比例，采用三个等宽纵向结构区，顺序为决策级、特征级、MBT。
- 顶部为一句结论式标题和颜色图例；底部为一行共享条件说明。
- 每列由方法标题、交换层级标签、三视角观测缩略图、token 流、核心交换机制和简化输出构成。
- 列间仅使用细分隔线，不使用大面积卡片背景，避免仪表盘感。
- 每列内部形成“输入图像层 -> token/编码层 -> 交换机制主视觉 -> 简化检查出口”的纵向节奏，其中交换机制占据最大视觉面积。

## 线条与边界语法

- 主流程线：深灰、约 1.25--1.5 pt，单向实线箭头。
- 视角内支路：蓝灰、约 0.8--1.0 pt；三路保持平行，减少无意义交叉。
- 跨视角注意力：青绿色、约 0.55--0.8 pt，使用双向弧线或汇聚边；仅在特征级和 MBT 列出现。
- 关键机制外轮廓：约 1.2--1.4 pt；普通计算模块外轮廓：约 0.7--0.9 pt；辅助分隔线：约 0.35--0.5 pt。
- 实线框只包围实际计算模块；虚线框只表达共享权重、重复层组或交换窗口；不使用虚线箭头表示正常前向传播。
- 同一列最多保留三档线宽，避免所有元素等粗造成“流程软件截图感”。

## 配图策略

- 输入端复用论文现有的 L/T/R 三张 CIR 距离--慢时间图，裁成窄幅微型热图并保留各视角差异；不使用通用雷达图标代替数据。
- 编码器不画成单个文字框，而是用浅色特征条、token 阵列和 `×N` 层叠表示共享 Transformer。
- 特征级融合的核心区域使用小型注意力矩阵/连线束，表现 `Q_v` 对其他视角 `K,V` 的读取。
- MBT 核心区域使用少量高亮瓶颈 token 和两侧密集视角 token，形成“宽 -> 窄 -> 宽”的视觉收缩。
- 决策级聚合核心区域使用三个独立距离分布小条带或刻度条，在末端由均值与方差符号汇合，避免只画三根线进入一个框。
- 所有微型配图均服务于数据形态或机制解释；不添加与论文无关的装饰插画。

## 视觉语言

- 蓝色：视角内独立计算；青绿色：跨视角交换；灰色：三种方法共享的下游模块。
- 使用小型 token 胶囊、层堆叠、局部虚线边界、细箭头、数学符号和 CIR 微型热图，替代普通大方框串联。
- 决策级聚合用三条平行轨道、三组距离刻度和末端统计汇合形成视觉指纹。
- 特征级融合用三路 token、注意力矩阵和双向交叉边形成视觉指纹。
- MBT 用前后编码层之间的“宽--窄--宽”token 布局形成唯一中继通道。
- 除三张 CIR 数据缩略图外，其余元素全部使用 PowerPoint 原生形状、文本和连线，保持逐项可编辑；不嵌入整页位图。

## 参考与原创边界

- 参考 CrossViT、TokenFusion、Multimodal Bottleneck Transformer、Swin Transformer、Mask2Former 和 Segment Anything 的信息层级、边界语法与配图位置。
- 不复刻论文原图的具体构图、配色或文字；最终图仅借鉴顶会方法图的信息层级与视觉语法。

## 验收标准

- 三列在缩放后仍能区分交换发生在末端、编码后和编码中层。
- 决策级聚合列不得出现编码阶段的跨视角连线。
- 特征级融合列必须显示编码后全视角交互及交互后的逐视角输出。
- MBT 列必须显示跨视角通信只能经过共享瓶颈 token。
- 实线框、虚线框和三档线宽必须具有稳定且可在图例中解释的语义。
- 输入端必须包含真实数据风格的三视角 CIR 微型热图，且缩放后仍能辨认三路差异。
- PowerPoint 可正常打开；无嵌入整页图片；无文字溢出或意外重叠。
