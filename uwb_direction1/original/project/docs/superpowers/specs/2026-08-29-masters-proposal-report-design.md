# 硕士研究生选题报告书设计说明

## 1. 目标与交付物

以桌面原始文件 `附件3_硕士研究生选题报告书.doc` 为唯一格式依据，形成一份可直接交导师审阅的完整 Word 初稿。报告暂不填写姓名、学号、学生类别、专业、导师、培养单位、入学日期和开题日期等身份字段，也不代写导师意见、答辩记录、评议意见及签名。

拟定题目为：**面向开放环境的多视角与连续流雷达手势感知方法研究**。

最终仅交付一个新文件，原始模板保持不变。报告正文保留学校表格的固定栏目和次序，允许在“文献综述”“调研报告”和“选题报告”栏目后增加附页。

## 2. 总体研究主线

全文以真实部署中的三类不确定性为主线：多视角观测缺失带来的空间不确定性、新类别与未知动作带来的语义不确定性、连续输入中事件出现与承诺时机带来的时间不确定性。两大研究内容各含三个研究点，形成“空间与语义可靠识别—时间轴连续事件感知”的递进关系。

### 2.1 研究内容一：多视角 UWB 雷达手势可靠识别

1. **三视角开集识别与传感器容错。** 三路 CIR 采用权重共享的双路径编码器，已知类由跨视角读出完成，未知类由逐类逐视角检查器及决策级距离聚合拒识；训练期随机丢视角提高缺失传感器条件下的鲁棒性。
2. **少样本新手势注册与尺度校正。** 冻结编码器，以少量支持样本建立新类原型；类别路由与接受判定解耦，并用独立校准数据控制接受覆盖，避免新类与基类分数尺度不一致造成系统性偏置。
3. **跨视角掩蔽重建与缺失视角合成。** 训练时掩蔽一个视角，利用其余视角恢复被掩蔽回波；重建误差作为类别无关的异常证据，同一生成模块在推理期用于缺失视角补全。

### 2.2 研究内容二：FMCW 雷达连续流手势事件感知

1. **因果流式事件检测与起点定位。** 以逐帧原始雷达表征和几何量为输入，因果模型输出动作性、类别与事件起点；主指标为事件 F1、起点 MAE 和每分钟误触发数。
2. **承诺时机及延迟—误承诺前沿。** 把模型何时输出稳定结论作为独立问题，以停时规则控制承诺；同时报告起点后的承诺延迟、提前承诺、误承诺率及不同风险预算下的性能前沿。
3. **开集事件拒识与少样本注册闭环。** 未知动作应被成段检出但不强行命名；探索多步预测误差和时间轴掩蔽重建误差等因果开集信号，随后用少样本完成新事件注册。

## 3. 证据与表述边界

- 多视角开集识别、随机丢视角容错、留一受试者评测、少样本注册和跨视角重建已有代码、日志或论文结果，可写为“前期已完成/已有结果”。
- FMCW 连续流的口径一致用户组 8 折 LOSO 基线、几何表示消融、起点定位和实时性已有结果，可写为“已建立基线与完成可行性验证”。
- 承诺时机的系统实验、因果开集信号、少样本事件注册闭环及 DiffAct 类教师模型尚未完成，只写为“拟研究/待验证”。
- 不把程序生成的固定窗口当作真实变长终点；不把半合成拼接流称为自然长期连续流；不把 FMCW 结果外推为 UWB 连续流结果。
- DiffAct/DiffAct++ 仅作为候选离线教师或对照，不作为整篇课题的默认核心模型。
- 负结果和协议问题如实保留，包括架构级跨视角融合未带来主指标增益、MIRA 基线尚未复现、FMCW 数据存在两套标注口径等。

## 4. 报告结构

1. 封面及基本信息：题目填写，身份字段留空。
2. 文献综述：不少于 5000 个汉字；列出不少于 40 篇真实文献，国外文献不少于三分之一；围绕雷达手势感知、多视角与缺失视角、开集与少样本学习、连续动作检测与在线时序分割四条文献线展开。
3. 调研报告：说明调研时间、地点、对象、采用的资料与主要收获；明确项目仓库、公开数据、论文原文和实验记录的作用。
4. 选题报告：严格覆盖题目及来源、目的与意义、国内外现状、研究目标与关键问题、研究内容、研究方法与技术路线、预期成果与创新点、进度安排和论文写作计划。
5. 参考文献：采用 GB/T 7714 风格，确保正文编号与文末条目一一对应。
6. 学校审核栏目：导师意见、答辩情况、评议意见、签名和日期保持空白。

## 6. 文献核验规则

- 优先使用论文官网、出版社页面、DOI、正式会议/期刊页面和数据集官方页面。
- 仓库现有参考文献只作为候选清单，写入前核对作者、题名、来源、年份、卷期和页码。
- 无法核实的条目不写入；预印本与正式发表版本并存时优先正式版本。
- 综述中的结论必须由相邻引文支持，项目自己的发现明确标注为“本课题前期实验”。

## 7. 文档实现与验收

- 先把旧版 DOC 模板转为工作 DOCX，保持原文件不变；在工作副本中填充和扩展。
- 保持 A4、学校规定页边距、宋体小四和 18 磅行距；新增附页沿用原页眉、页码和边框语言。
- 身份字段和审核字段保持空白，不出现“待填”“TODO”或虚构信息。
- 交付前检查参考文献数量、国外文献比例、综述字数、七项选题报告内容、图题/表题、内部引用和项目数字。
- 通过 Microsoft Word 导出 PDF，并把全部页面渲染为 PNG 逐页检查；不得出现截断、重叠、表格破坏、字体缺失或异常分页。
