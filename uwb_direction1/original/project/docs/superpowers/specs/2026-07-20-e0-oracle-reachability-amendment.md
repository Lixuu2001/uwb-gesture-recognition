# E0 独立修订:oracle 可达性诊断(2026-07-20 锁版)

对 c-lite 预注册(v0.2.1)的独立增补,经 07-20 用户书面裁决。**§46 的 S0 根因门
FAIL 判决保持不动,不回头改判**;本修订另立新假设:S0 只否定了"λ=1 统一解释三种
覆盖崩塌",未否定可靠度加权本身——drop 是单视角退化(另两视角可能健康,正是重加权
的适用场景),而用 occlude_vall/domain_vall 两个全视角条件裁决 single-view H4
存在研究问题错位。

**授权范围**:仅 E0-a(现有 dump,零 GPU)与条件性 E0-b(缩小静态网格)。
正式 G3 继续冻结;整个 E0 阶段**不得运行 `--gate s1` 或 `--gate g3`**;
不测试真实 reliability 权重(它属于 H4-v2,须另行预注册)。

## E0-a:现有 drop dump 上的 oracle 天花板(零 GPU)

数据:Phase A 流调度 `drop`(v0 受灾)单元,c0/c1 × 8 折原始 D/M。
只允许计算 uniform-rv 与 oracle-mask 两系统(各自用自身校准行重算 μ/σ/q/s_cal;
校准干净 ⇒ 两者 s_cal 相同,预期行为)。

**口径钉死(落盘前锁定)**:
- oracle 语义=逐事件知道受灾视角与严重度:仅 sev>0 事件掩蔽 v0(权重 0 后归一),
  sev=0 事件用均匀权重——避免掩蔽健康视角把天花板测矮;
- ΔH 统计对象=全流(与 §44/§45 口径同源);按严重度 {0.25,0.5,0.75,1} 分层的
  ΔH 只作方向性诊断,不设门。

**门槛(锁定)**:
- c0、c1 的 oracle ΔH(oracle-mask − uniform-rv)均 ≥ +3 分;
- 两词表各自 ≥6/8 测试用户方向为正。

不过 ⇒ 立即执行路线 a,E0 终止。通过 ⇒ 进入 E0-b(须再次确认后点火)。

## E0-b:缩小版静态可达性网格(条件性,~24 cell/fold)

仅 {drop, domain} × v0/v1/v2 × 严重度 {0.25,0.5,0.75,1},c0/c1 × 8 折,
静态网格(p4_g3_stream --mode static --deg 指定 cell)。逐族门槛:
- oracle-mask 对 uniform-rv 的 ΔAUC_H ≥ +3(梯形积分,含 sev=0 端点=clean);
- c0、c1 平均方向均为正;
- 每词表 ≥6/8 折方向为正。

分支:两族全不过 ⇒ 路线 a,停止实验;只过一族 ⇒ 未来 H4 只针对该族,不再声称
通用连续退化恢复;两族都过 ⇒ 另行预注册 H4-v2,之后才允许看 S1 与真实可靠度。

## E0 失败时的论文四定稿框架(路线 a)

1. G0:冻结开放世界系统在复合漂移下失效;2. G1:calib-select 数据驱动尺度对齐;
3. G2:自动采纳失败、确认通道才是有效贡献;4. S0:漂移失败族异质(惩罚误伤 vs
距离破坏);5. limitation:全视角严重域迁移=表征废墟,非阈值/控制模块可修。
定位=数据驱动尺度对齐方法 + 受控开放世界漂移审计 + 在线自适应失败机制图谱,
不包装为"完整在线自适应方法"。
