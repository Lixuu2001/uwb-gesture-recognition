# 硕士开题答辩 PPT 原理优先版修改设计

日期：2026-08-30

## 目标

将现有 11 页、约 10 分钟的开题答辩 PPT 从“结果汇报型”改为“背景—原理—方案型”。页面与演讲者备注不再展示具体实验数值，重点回答课题为什么提出、雷达如何感知手势、两个研究内容分别解决什么问题，以及方案如何形成完整技术闭环。

## 修改边界

- 保留题目、11 页体量、海军蓝与青绿色视觉系统、封面留空字段和演讲者备注。
- 删除准确率、OSCR、F1、AUROC、时延、虚警率等具体实验数字，以及由这些数字形成的结果判断。
- 不把拟开展的方法写成已完成成果；可行性只从已有数据、代码、硬件和研究基础四个方面作定性说明。
- 不新增“研究内容三”，研究内容仍严格限定为三视角 UWB 与 FMCW 连续流两条主线。

## 叙事结构

1. 封面：课题题目与“空间可靠性、时间因果性、类别开放性”三个关键词。
2. 背景：说明固定片段分类与真实连续输入之间的部署差距。
3. 基本原理：从雷达发射、手部运动调制、回波表征到手势判别，区分 UWB CIR 与 FMCW 时频特征。
4. 问题定义：空间、时间、类别三类不确定性如何对应两项研究内容。
5. 研究内容一原理：三视角逐路编码、保留证据、可靠聚合和未知拒识。
6. 视角重建方案：训练期掩蔽、可见视角恢复、重建残差、缺失视角决策和少样本注册。
7. 研究内容二原理：连续帧因果输入、动作性、起点、类别与开放集分数的联合输出。
8. 连续流闭环：背景、候选、可撤回早判、稳定承诺、冷却及未知事件缓存。
9. 总体技术路线：两条主线在统一开放世界接口汇合，但数据和实验协议保持独立。
10. 创新点与可行性：用“机制—解决的问题—验证方式”表达两项创新，并说明研究边界和风险控制。
11. 研究计划：按协议与基线、UWB 重建、FMCW 事件、综合复核四阶段推进。

## 重点图示

- 雷达手势感知原理图：发射信号 → 手部运动调制 → 回波序列 → 时空特征 → 手势/未知判断。
- 三视角可靠识别图：三路 CIR → 共享编码 → 逐视角证据 → 可靠聚合/未知拒识。
- 连续流状态机：背景 → 候选 → 可撤回早判 → 稳定承诺 → 冷却，并保留未知事件分支。
- 双主线技术路线图：UWB 与 FMCW 分别完成空间和时间建模，最后通过统一的开放世界输出接口连接。
