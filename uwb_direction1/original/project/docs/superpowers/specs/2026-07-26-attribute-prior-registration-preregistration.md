# 属性先验注册预注册(v0.1,2026-07-26)

## 授权范围

只检验一个问题:**新手势的原型能不能由已见属性合成,从而在极少样本(K=1)甚至零样本
(K=0)下把注册做起来**。不改编码器结构,不改共形框架,不引入新训练目标。本文档写在
点火之前,判据和分支条款在看到结果之前锁定。

## 背景与动机

注册线的已知短板是 shot 曲线的低端:K=10 才跨过 80 线(§37),K=1 最弱,根因是少样本
原型又偏又抖、且跨人转移差(§34:同人 91.1 vs 跨人 75.2,换人占新类误差 2/3)。

2026-07-26 的属性读出实验给出一个新的可用先验:词表本身是一张属性网格(G1--G4 为四个
单轴滑动,G5--G8 为其两两组合),而属性方向在冻结特征里线性可读(二分类 82--97,§待编号)。
如果可读且可组合,新类原型就不必只由 K 个样本估出来。

## 核心机制(为什么必须在特征空间做,不能在原型空间做)

每个检查器是独立 MLP,`phi_k` 活在各自的潜空间里(§4.2 已警告),**跨类的 phi 不可直接
线性组合**。因此属性算术必须做在**编码器输出的共享特征空间** `f`(逐视角特征码)上:

    phi_hat(h,v) = mu(h 类) + mu(v 类) - mu(全部单轴类)

得到的是一个**合成特征点**,再按现有路径喂给 `train_inspector`(当正样本)或直接当 NCM
原型。这样既不动架构,也不破坏跨头可比性(§34.6/34.7 两次失败都源于打破它)。

## Gate 0(已完成,零 GPU,纯后处理)

合成原型对四个**未见组合**做 4 分类(随机 25),编码器从未见过任何对角类,LOSO:

| 输入 | 读出 | pooled | LOSO |
|---|---|---|---|
| 幅度 | views-concat | 90.84 | **88.91 ± 9.5** |
| 幅度+多普勒 | views-concat | 89.31 | 87.84 ± 9.0 |
| 幅度 | mean(L,T,R) | 79.03 | 78.34 ± 9.3 |
| 多普勒 only | mean(L,T,R) | 41.91 | 41.59 ± 6.0 |

**判读**:① 合成先验携带真实的类信息,K=0 在原理上成立;② **不需要多普勒**,幅度特征
最好,故后续全部在冻结的现有输入管线上做;③ 读出方式再次统治结果(concat 88.9 vs
mean 78.3),`mean` 下最差的格子是 G7=RL+UD(31--49),即两个"反向"父类的组合。

**Gate 0 不是交付物**:它是 4 个对角之间的封闭比较,没有 base 类竞争、没有真未知拒识、
没有共形阈值。注册任务的困难恰好都在那三件事上(孪生吞噬 §35、d 膨胀 §33、尺度抽签 §38)。
**不得把 88.9 与 acc_new 75.2 并列宣传**,那是 §29.2b 稻草人错误的重演。

## Gate 1(便宜臂:零编码器成本,单类)

现成 case-1 词表 `base=[1,4,5,7,8,11]`、`register=[6,9,10]`,其中 **G7(RL+UD)
恰好是 base 中三个类的平行四边形第四角**:

    phi_hat(G7) = mu(G5) + mu(G8) - mu(G6)
                = (LR+UD) + (RL+DU) - (LR+DU) = RL+UD

三个父类全在 base 里,**编码器缓存已存在,不需要新训练**。G10/G11 没有属性父类,作为
同一跑内的阴性对照(它们不应该获益)。

三个先验注入方式(全部预注册,不看结果再改):

| 变体 | 做法 |
|---|---|
| P-A | 合成点当额外正样本喂 `train_inspector`,K 个真样本 + N 个合成点 |
| P-B | NCM 原型混合 `phi = (1-w)*phi_hat + w*mean(shots)`,w 随 K 增大 |
| P-C | K=0,纯 `phi_hat`,不用任何目标类样本 |

基线 = 冻结的论文三配方(方法 A、balanced support、最近原型路由、hybrid 共形)在同一 K。

## Gate 2(干净臂:需新编码器族)

Gate 1 通过才点火。新增属性网格词表,让**注册类全是未见组合、父类全在 base**:

    base=[0,1,2,3,8,11]  register=[4,5,6]  unknown=[7,9,10]

即 base = 四个单轴滑动 + 旋转 + 空动作,注册 = 三个对角。成本 = 一个新编码器族
8 折(按 §43 的量级约 7 小时),之后 K 扫描与 Gate 1 同协议。

## 指标与判据(锁定)

主指标沿用注册线:`acc_new`、`base` 准确率、`rejU`、调和均值 H,外加共形经验覆盖率。

**Gate 1 通过条件(三条同时满足)**:
1. K=1 上 `acc_new(G7)` 相对基线 **+5 分以上**;
2. `base` 准确率下降 **≤2 分**,`rejU` 下降 **≤3 分**;
3. 方向一致性 **≥6/8 折为正**。

**阴性对照必须成立**:G10/G11 的 `acc_new` 变化在 ±2 分内。若它们也涨,说明增益来自
"多了些正样本"这个与属性无关的效应,判为**混淆**,不算通过。

**K=0(P-C)单独报告**:acc_new(G7) 显著高于随机即为可报结果,不作为 Gate 1 的门槛。

## 分支条款

- Gate 1 三条全过 → 点火 Gate 2,论文二按"属性先验注册"立项。
- Gate 1 只有 K=0 有效、K=1 无增益 → 论文二**不独立成篇**,该结果写成论文三期刊扩展版
  的一节(或学位论文一章),按 2026-07-26 会话的判断执行。
- 阴性对照失守(G10/G11 同涨)→ 先查混淆源,不得在未解释前推进 Gate 2。
- 全线无增益 → 收为诚实负结果:属性在特征里可读且可合成(Gate 0),但对距离几何与
  路由无用。这条与 §47"掩蔽天花板证伪"同类,照实报告。

## 成本

Gate 1 约半天代码 + 一夜 GPU(无编码器训练);Gate 2 追加约 7 小时编码器 + 一夜。

## 已知风险

1. **属性空间很小**:只有水平、垂直两条轴可组合,合计八个方向;旋向大概率不组合
   (2026-07-26 环路面积探针 d'=0.10)。审稿人会质疑组合性的规模。
2. Gate 0 的 88.9 是封闭 4 分类,与开集路由不可比(见上)。
3. 平行四边形算术假设属性在特征空间近似线性可加,只在 LOSO 的 4 分类上验证过,
   在 base 竞争下可能不成立。
