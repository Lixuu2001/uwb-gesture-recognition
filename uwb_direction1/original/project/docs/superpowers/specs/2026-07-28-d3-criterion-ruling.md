|---|---|---|

§49 自身声明"属用户书面裁决事项，本节不自行改判"。本文书处理该裁决。

## 2. 裁决

### 2.1 预注册的 FAIL 判决**维持**，不改判

`>70` 线是在点火之前锁定的、施加在**三分类**协议上的判据。§49 提交的不是"同一判据下的
新数据"，而是**换一个判据**。事后换判据把 FAIL 变成 PASS，正是 §45.4 明确防范的
"看结果改门槛"。故：

- **柱二按 §48 原设定不予复活**（原设定的"复活"含义 = 以组合泛化把水平轴盲区修好，
  并据此立项论文二主线）。该条**不追第二次**的止损条款继续有效。
- 该 FAIL 作为**已完成的负结果**写入论文与学位论文，不隐藏、不重跑。

### 2.2 §49 的归因改写**成立**，且必须与 FAIL 一并报告

维持判决不等于否定证据。§49.3 表中的三条修订全部采纳：

| §48.3 原文 | 处置 |
|---|---|
| "学出来的表征远追不上手工物理读数（58.1 对 90.6）" | **撤回**。三分类对二分类，苹果对橘子。同条件比：学到的特征二分类 82–97 ≥ 手工 90.6。不得再以任何形式引用该比较 |
| "抵消解释通过证伪测试" | **加限定**。`L+R` 在二分类下 88.91 > `L−R` 85.72，"对称通道恒盲"不成立；读出 +36 是真的，机制是"幅度被压入 none 带"而非"信息被抵消"。**不支持"必须加反对称通道"这类架构级主张** |
| §26.3 "传感模态的内在性质" | **证伪**。替代解释：方向可解码、但幅度经聚合后落入 none 带，即**存在性判据的尺度标定失败**，不是表征缺陷 |

### 2.3 报告口径（锁定，今后一律执行）

凡报属性读数，**必须同时给出二分类（信息含量）与三分类（存在性判定）两个数**，
二者差值记为**标定债务**。不得单报其一。理由：§49.1 的贡献分解显示改判据 +64 >
改读出 +22 > 加多普勒 +7，单报任一个数都会误导读者关于"瓶颈在哪"。

### 2.4 新增第三方证据（本次 W1/W2，`proposal_v2/04`、`05`）

在完全独立于"特征空间怎么编码"这场争论的通道上——**物理重建轨迹的零训练读数**：

| 读数 | 结果 |
|---|---|
| 水平方向（E[vx³]） | 93.75（8/8 折 >75%） |
| 垂直方向（E[vy³]） | 84.38（6/8 折） |
| **旋向（重建环路有向面积）** | **92.81，d′=2.771**（7/8 折 >75%） |

这支持 §49 一方的归因：**信息在数据里、方向可解码**，争议只在于识别系统的特征如何编码
它、以及用什么判据判定"存在"。该证据不改变 2.1 的维持判决（它不是同一判据下的重测），
但它使 2.2 的归因改写更稳固。

### 2.5 预注册文档的连带修订

`2026-07-26-attribute-prior-registration-preregistration.md` §已知风险 1 原文：

> 旋向大概率不组合（2026-07-26 环路面积探针 d′=0.10）

**修订为**：特征层的多普勒质心环路面积 d′=0.10（`RESULTS.md` §49.5）；但**物理层的
重建轨迹环路面积 d′=2.771**（`proposal_v2/04` §2.2），旋向在物理层可读。**旋向能否在
特征空间做属性组合仍未测**，风险条目的方向不变（不宣称可组合），但其依据必须更新，
不得继续引用 d′=0.10 作为"旋向不可读"的证据。

## 3. 对后续研究线的后果（防止以后自己绊到）

1. **研究点 2.3 不是柱二的复活**。柱二的判据是三分类 >70 线（已 FAIL 并封存）；研究点
   2.3 走的是预注册文档的 Gate 1/2，判据是注册线指标（acc_new / base / rejU / H /
   共形覆盖），与 >70 线无关。二者不得混为一谈，也不得互相引用对方的判决。
2. **Gate 1 可以按预注册原样点火**，本裁决不修改其任何判据或分支条款。
3. **§49.4 的方法学结论**（属性存在性改由校准被试上的幅度阈值 + 共形机器判定，替掉学出来
   的 none 类）**不并入 Gate 1**，作为 Gate 1 之后的独立改进项另行预注册。理由：Gate 1
   的协议已锁定，中途加装置会污染其判据。
4. **论文写作口径**：论文一与学位论文现有的表征级措辞（"闭集交叉熵未能将其组织为连贯的
   方向表示" / "所学表征存在系统性的水平分量盲区"）**不需要改口**，但须补一句更准确的
   归因（存在性判据的尺度标定失败），并删除任何形式的 "58.1 对 90.6" 比较。
