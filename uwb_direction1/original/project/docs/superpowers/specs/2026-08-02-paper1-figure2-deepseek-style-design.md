# 论文一图二重绘设计

## 目标

将论文一的“三种跨视角融合策略”结构图重画为接近用户参考图的高密度论文技术线稿，并交付可编辑的 PowerPoint 文件。新图不复用原图的视觉风格；信息组织允许重构，但必须与论文第 2.4 节和图注自洽。

## 选定版式

采用“公共主干 + 三处放大框”的 B 方案，16:9 横向画布：

- 左侧用一条公共主干定位三视角 UWB CIR、共享双路径编码器、逐类 × 逐视角检查器、原型距离和异常分数。
- 右侧纵向排列三个蓝色虚线放大框，分别展开决策级聚合、特征级融合和瓶颈中层融合。
- 蓝色虚线从公共主干的相应深度连接到放大框，使读者可以沿主干判断跨视角交换发生的位置。
- 信息密度以已批准的高密度草图为准，不退化为少量概念框。

## 科学内容

### 公共主干

- 输入为左、上、右三个视角的 CIR，记为 L、T、R。
- 编码器为权重共享的双路径 Transformer：时间路径含 90 个 token，距离路径含 189 个 token；两路均为 4 层 pre-LN Transformer，标出 LayerNorm、多头自注意力、残差、MLP 和 GELU。
- 两路 token 展平拼接并加入视角嵌入，得到 8928 维逐视角特征码。
- 每个已知类、每个视角使用一个深度检查器，结构标为 8928 → 1024 → 128；潜向量与对应原型比较得到 dL、dT、dR。

### 三种放大结构

1. 决策级聚合（本文）：三路特征从编码器到检查器保持独立，只在末端聚合 dL、dT、dR。显示论文异常分数的均值项和方差项。
2. 特征级融合：在编码器输出后加入跨视角注意力，明确画出 Q/K/V、多头注意力、残差旁路以及相加与归一化；融合后的三路特征再分别进入视角特定检查器。
3. 瓶颈中层融合（MBT 式）：编码器前段为独立层 ×(4−K)，后段为瓶颈融合层 ×K。跨视角信息只能通过恰好四个共享瓶颈 token 交换，普通 L/T/R token 之间不得出现直接跨通道连线。

## 视觉语言

- 白色论文画布，黑色与冷灰色细线，蓝色虚线功能分区和放大连接。
- 浅黄色表示视角内计算，浅蓝色表示共享编码器，浅绿色表示跨视角交换或汇合。
- 无渐变、阴影、透视、照片、装饰性 3D 元素和水印。
- 使用短中文标签与保留的数学符号；字体优先使用 Arial、Times New Roman 和 Microsoft YaHei。
- 通过浅绿色模块在主干中的垂直位置表达融合深度，形成整图的主要视觉叙事。

## 内容边界

图中不加入性能数值、OSCR、数据集标识、闭集分类头、随机丢视角、接受/拒绝框、训练损失、合成样本流程或论文结论性长段文字。图二只回答“跨视角交换发生在哪一层、各策略如何连接”。

## 交付与验证

- 主交付物：完全可编辑的 `.pptx`，所有框、线、箭头、标签和 token 均为 PowerPoint 原生对象。
- 辅助交付物：同版式 PNG 预览，用于检查整体布局。
- 不覆盖当前论文中的旧图文件，使用带版本标识的新文件名。
- 生成后检查：三种拓扑与论文一致；瓶颈 token 数量恰好为四；无普通 token 跨视角直连；无文字溢出、重叠或越界；缩放到论文通栏宽度后标题和关键标签仍可辨认。
