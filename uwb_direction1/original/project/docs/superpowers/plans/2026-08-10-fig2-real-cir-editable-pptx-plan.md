# 图二真实三视角 CIR 与可编辑 PPTX 实施计划

## 目标

将论文图二改为三列式融合层级对比图。图中使用 UWB-Gestures 同一手势事件的真实 L/T/R CIR，其余编码器、跨视角注意力、瓶颈 token 与连线均为 PowerPoint 原生可编辑元素。

## 数据约束

- 数据源：`D:\uwb_gestures\12652592` 下 UWB-Gestures 原始 CSV。
- 三视角配对：同一受试者、同一手势、同一重复序号。
- 论文默认输入：`ClutterRemoved`，按样本、按视角执行 `abs_std`。
- 绘图不插值、不平滑、不生成纹理；三视角使用同一显示色标。

## 实施顺序

1. 从原始 CSV 读取同步 L/T/R 数据，生成候选样本板并选取结构清楚的一组。
2. 导出三张论文缩略图与可追溯元数据。
3. 备份现有 PPTX，按三列布局重建图二；仅 CIR 为位图，其余为原生形状。
4. 用 PowerPoint 导出整页预览，检查文本、连线、层次、图片真实性和可编辑对象数量。

## 验收标准

- 三张 CIR 可追溯到同一原始事件。
- 三列只突出编码阶段的差异，删除完整下游 `d_v -> s` 流程。
- 实线表示实际模块，虚线表示共享/交换作用域；主流程、局部连接、内部注意力线有明确粗细层级。
- PPTX 不以整页图片充当流程图，除三张 CIR 外均可单独编辑。
