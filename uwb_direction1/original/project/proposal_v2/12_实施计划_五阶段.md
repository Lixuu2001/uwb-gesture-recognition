## 阶段 0｜对角零样本的物理基线（2 天，零 GPU）

**目的**：量出物理渲染器与真实回波的差距有多大，以及这个差距在**见过的单轴手势**和**没见过的组合
手势**上是否相同。这决定 2.3 的生成分支是否值得做。

**为什么必须先做**：物理渲染器是轨迹的确定性函数，**它压根不区分见过没见过**；而 `04` 已证明轨迹层面
组合性成立（对角 x/y 摆幅比 G5 0.69 / G6 0.83 / G7 1.00 / G8 0.66）。所以"零样本生成对角回波"这件事，
**物理骨架那部分是白送的**，生成模型真正要证明的只有散射/残差那一层。这一步就是把两者分开计量。

**新文件**：`tools/w3_diag_b0.py`

**做法**：
1. 从 `tools/traj_w1.py` 的重建结果取 G1–G4 的控制点（若当前 npz 未存 `C`，改一行存下来）。
2. 合成对角轨迹：`p_diag(t) = c + a_x·u_x(t) + a_y·u_y(t)`，`u_x` 取 G1/G2 归一化平均剖面、
   `u_y` 取 G3/G4；幅度 `a_x, a_y` 用 `04` 表里 G5–G8 的**实测**摆幅标定（G5 125.0/181.6 mm 等）。
3. `forward.render` + `forward.clutter_filter(alpha=0.80)` 渲三视角 → `X̂_diag`。
4. 与真实 G5–G8 比**分布**，三个度量（**不要用逐样本 MSE**，起始时刻/相位不对齐会毁掉它）：
   - (a) 距离–时间边缘分布的 2-Wasserstein / 直方图距离
   - (b) 峰值路径统计量（摆幅、斜率、拐点数、−6 dB 宽度）
   - (c) **分类器双样本检验 AUC**（真 vs 合成，小 CNN 或复用现成 encoder）
5. **同一套度量也在 G1–G4 上跑一遍**（这是对照，缺了就没法解释）。

**输出**：`logs/w3_diag_b0.npz`、`figures/w3_diag_b0.png`

**期望**：峰值路径统计应当接近（几何是对的）；**回波宽度/多峰/幅度应当明显不同**——点目标假设
vs 实测 −6 dB 宽度 154.5 mm。差距在 G1–G4 与 G5–G8 上应当**相当**。

**门**：
- AUC 已接近 0.5（B0 就够真实）→ **2.3 的生成分支作废**，退回 `11` 前一版的三点结构。
- G5–G8 上明显比 G1–G4 更差 → 组合运动的散射有额外结构，**这本身是一条发现**，生成模型空间更大。
- 差距相当且 AUC 高 → 正常路径，缺口已量化，进阶段 1。

## 阶段 1｜轨迹带 + 3×3 灵敏度表（3–5 天，零 GPU）

**目的**：一周内拿到**开题主图**，同时把生成器的验收标准先立起来。

**新文件**：`tools/w3_band.py`、`tools/w3_sens.py`

**做法（w3_band）**：
1. 在 `fit_trajectory` 的解 `C*` 处取现成的 `jac` → `J`；`σ²` 从残差估。
2. Laplace 近似 `Σ ≈ σ²(JᵀWJ)⁻¹`（`W` 用维特比置信度）。**注意 `00` §5.6 那条死路：不要用 `pinv`**
   ——不可观测方向会被映射成方差 0 而不是无穷，符号正好反。用特征分解，把小特征值显式报成大方差。
3. 沿最小特征方向做 **profile likelihood**（固定该方向分量、重优化其余），扫出真实剖面，不靠二次近似。
4. 超参按 `00` §4.2 权威值 **K=30 / λ=0.05 / μ=0.05**。⚠️ `fit_trajectory` 的函数默认是 `lam=3.0`，
   `bspline_basis` 默认 `K=15`——**调用时必须显式传**，别吃默认值。

**做法（w3_sens）**：输出解析 3×3 表，并用 `reproject` 的有限差分数值验证。

**已经可以先算出来的三条预言**（按标称几何 L(−0.55,0,0)、T(0,0.55,0)、R(0.55,0,0)、目标 (0,0,0.45)，
单点目标、逐帧、不含样条正则）：

```
J = [[+0.774,      0, +0.633]      ← Left
     [     0, −0.774, +0.633]      ← Top
     [−0.774,      0, +0.633]]     ← Right

JᵀJ 的特征值：1.476 / 1.198 / 0.325
最小特征向量（最不可观测方向）：(0, 0.873, 0.488)   ← 垂直与深度的混合，不是任何单轴
标准差条件数：sqrt(1.476/0.325) = 2.13
```

**预言 1**：三视角齐全时后验带子**最宽的方向应指向 (0, 0.87, 0.49)**（"向上并向前"），而不是纯垂直或
纯深度。
**预言 2**：最宽方向的不确定度约为最窄方向的 **2.1 倍**。
**预言 3**：丢视角时，主方向应与 `tools/traj_w1_obs.py` 给的盲方向余弦 **0.77–0.83** 吻合。

（caveat 必须写进论文：这是逐帧、单散射中心、不含样条先验的局部预言；样条正则会跨帧耦合，实测方向
会有偏移。三条预言是**方向性**检验，不是精确等式。）

**输出**：`logs/w3_band.npz`、`figures/w3_band_12gestures.png`（**开题主图**）、`logs/w3_sens.npz`

**门**：无。这一步不会失败，只会给出数。

## 阶段 2｜似然化 + 多峰率（1–1.5 周，零 GPU）→ 研究点 2.1 收官

**目的**：把读出从"取一个数"升级成"给一个似然函数"，并检验**多峰率能否预测台账里已记录的失败**。

**新文件**：`tools/w3_like.py`

**做法**：
1. 每帧每视角：杂波滤波后剖面与脉冲模板做匹配滤波 → `ℓ_v^t(ρ) ∝ exp(response/T)`，温度 `T` 由残差标定。
2. 多峰判定：峰检测 + 次峰/主峰高度比 > 阈 **且** 峰间距 > 分辨率（154.5 mm / 6.35 mm ≈ **24 bin**）。
3. 相位中心模型（已标定：L −74.5 / R +80.5 / T 深度 −74.5）进观测模型，当 **nuisance 参数 profile 掉**。

**关键实验（必须预注册，别事后挑方向与阈）**：多峰率 vs 台账已记录失败
- 已记录失败：**HV3 旋向 57.5%**（全体 92.81%）、**垂直 6/8 折**、**丢 Top 垂直塌 30.9 分**。
- 检验：逐被试多峰率与逐被试读数正确率的 Spearman；逐样本多峰率预测旋向读数对错的 AUC。
- **预注册阈：|Spearman| > 0.5 且 p < 0.05，或 AUC > 0.65。**
  （`00` 记忆里有过一次教训：G1a 比例估计的 Spearman 是负的、方向反了。所以方向要先写下来。）

**输出**：`logs/w3_like.npz`、`figures/w3_multipeak.png`

**门**：
- 达阈 → 研究点 2.1 成立，头条数字就是这条预测力。
- 不达阈 → **2.1 降级为观测模型工程**（仍然是 2.2 的必要前置，但不当科学发现报）。

**副产物（决定阶段 3 的战场）**：多峰帧占比就是"扩散是否有用"的直接证据。

## 阶段 3｜扩散后验 + 分支 R/C（2–3 周，单卡）→ 研究点 2.2

**新文件**：`uwb_osr/diffusion.py`（先验 + 采样器）、`tools/w3_post.py`

**配置**：

| 项 | 选择 |
|---|---|
| 去噪空间 | 控制点 `C ∈ R^{30×3}` → **90 维**；起点对齐 + 全局尺度归一化 |
| 先验 | DDPM 训练 1000 步 / **DDIM 50 步**采样 |
| 去噪器 | **小 LSTM 或 4 层 MLP-DiT，1–5M 参数**（UDP 的证据：CVPR 2026 在 147 维/帧上用 LSTM 就够） |
| 条件（分支 R） | 3×90 峰值距离，归一化 |
| 条件（分支 C） | `model.py:SharedDualPathEncoder` + `CrossViewFusion`，去掉 `ClosedSetHead`/`EvidentialHead` |
| 引导 | `μ̃_t ← μ_t − λΣ_t ∇_C‖A(Ĉ₀) − r‖²_W`，作用在**去噪估计 Ĉ₀** 上；`A`/`∇` 用 `reproject` + `jac` |
| 步长 | **λΣ_t**（噪声协方差缩放，自带退火，别手调 schedule） |
| 折 | **LOSO 8 折**，先验只见训练折被试的轨迹 |
| 后验样本 | 每样本 **128** 条 |
| 禁用 | 多普勒相位（`00` §5.10，32.2% 帧缠绕） |

**必做的纪律**：① LOSO 折隔离；② 起点/尺度归一化（先验只学运动形状统计，不学绝对位置——绝对位置本身
带 75 mm 偏置和 3.7% 尺度不确定性）；③ **置换检验**（CIR 条件在 batch 内打乱，信息增益必须消失）。

**指标**：

| 指标 | 期望 |
|---|---|
| 逐自由度收缩 `logdet Σ_R − logdet Σ_C`（nat） | > 0 且置换后归零 |
| 一致性：后验样本重投影残差中位 | 落在 **47.4–49.7 mm** 附近 |
| 多样性：样本间轨迹 RMS 差 | 显著大于残差能解释的范围 |
| 主方向 vs 解析 | 吻合阶段 1 的三条预言 |
| 覆盖率校准 | 在 `tools/w2_closed_loop.py` 的仿真真值上，90% 区间含真值 ≈ 90% |

**λ 的相图（有 UDP 先例背书的实验）**：UDP 的 Table 3 显示真实 UWB 误差 17.5 cm 时它**反而输给**
非扩散基线，limitations 明说对噪声敏感。我们的残差 47–50 mm + 75 mm 偏置正在这个区间。
→ **在已标定仿真器里扫"观测噪声 × 引导强度 λ"相图**，找 λ 的安全区，并把这条写进论文。

**γ 谱（先验占比审计）**：逐方向削弱似然、看后验均值移动多少 → `γ_d ∈ [0,1]`。解析预言：水平/深度
γ≈1；池化后的水平与 `R−L` 下的垂直（两个严格零）γ≈0；丢 Top 后垂直 γ 塌向 0。

**门**：收缩 ≈ 0 且置换后也一样 → **取峰是充分统计量**，负结果收官，照样写（这是 `11` §3 立论的
另一半，不是失败）。

## 阶段 4｜散射感知可微渲染器 + 残差生成 + 闭环（4–6 周）→ 研究点 2.3

**新文件**：`uwb_osr/forward_torch.py`、`uwb_osr/resid_diff.py`、`tools/w3_zeroshot.py`

**4a. 渲染器 torch 化（1–2 天）**
把 `forward.render` 搬 torch：脉冲模板延迟（用可微插值代替 `_delay` 的整数移位）、幅度衰减指数、
逐视角增益、噪声。**杂波 IIR（α=0.80）展开成有限阶**——90 帧序列可全展开，`0.80^90 ≈ 1e-9`，无截断误差。
**硬地板必须写进论文：杂波滤波器复现误差实测 13.8%**，这是任何物理骨架匹配真实回波的上限。

**4b. 散射状态物理参数化（几天）**
`z_s` = 逐视角散射中心偏移 `δ_v`（**初值取实测 L −74.5 / R +80.5 / T 深度 −74.5**）+ 宽度 + 幅度。
**不许自由学** `z_s`——自由学一定学成被试身份（论文一那边 Raw 输入的优势就是泄漏，跨人 CR 反赢 +11.3）。

**必做对照**：用现成 `probe_attributes.py` 探 `z_m` 能否解出被试身份。**高于随机即解耦失败。**
理论依据：多视角 content-style 可识别性（同一手势三视角共享运动、不共享散射）；但定理要求 style 与
content 独立，而 `δ_v` 依赖姿态 → 所以 `δ_v` 交给物理模型承担，`z_s` 只带残下的波形形状。
**无监督自由解耦本身不可识别（Locatello et al. ICML 2019），不要许诺。**

**4c. 残差生成**
`X = F_physics(p, δ_v, G) + D_gen(p, z_s, G)`，`D_gen` 是 3 通道 90×189 的条件扩散。
**对照组用现成的 `pretrain.py:MaskedViewDecoder`**（`mae_target="raw"`, out_dim=189）——它是确定性
条件均值解码器，正好演示"MSE 解码器会把多峰糊平"。

**4d. 四组验收实验**

| 实验 | 做法 | 期望 |
|---|---|---|
| **三级阶梯** | B0 纯物理 / B1 只在 G1–G4 训残差 / B2 全数据训残差 | **B1 关掉 B0→B2 的大部分差距** |
| **四族编辑** | 方向反转 G1⇄G2 / 旋向反转 G9⇄G10 / 正交组合 G1–4→G5–8 / 空程序 G12 | 每族都有**真实回波**可比；幅度/速度缩放无真值，只能定性 |
| **灵敏度体检** | 对生成器数值微分，测 3×3 矩阵 | 编辑垂直 → **L/R 几乎不动**；编辑水平 → **Top 不动**且 L/R 等幅反号；编辑深度 → 三路同向同幅 |
| **闭环负对照** | 故意喂错轨迹（打乱配对、镜像、时间反转） | 分数必须变差，报对/错轨迹 **ROC AUC > 0.8** |

**双样本检验**：真 vs 混合渲染的判别器 AUC 应从 B0 的高值降到 **0.5–0.6**。

**门**：
- B0 ≈ B2 → 生成模型无贡献，2.3 缩为"散射感知的可微渲染器"（仍是交付物，但不报生成能力）。
- 错轨迹也能过闭环检验 → **闭环无鉴别力**，2.3 的反演半部分作废，只留生成半部分。

## 每阶段一句话的"我要看到什么"

- **阶段 3**：一个数——把整张距离像喂进去，后验收窄了多少 nat；以及取峰到底是不是充分统计量。

  喂错轨迹会被拒。
