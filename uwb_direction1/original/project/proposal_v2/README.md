## 一页结论

- 导师批的是**输出空间单一**（四个点全输出标签）。破局 = 块二输出不是标签。
- 块二 = **从三路飞行时间反演手的运动 + 追问什么反演不出来**。定位是**问题设定转换 +
  独有失败台账当验证集**，**不是方法创新**（多站定位、MSTAR、CRLB 布阵、可微 RF 孪生全是成熟件）。
- 已建立：反演可用（零训练读数 84–94%）、精度有界（13.5 mm 下界 / 57 mm 上界侧 / 真值不可得）、
  失败三分类（几何性可预测、读出性已定量、域性几何无解释力）、残差主项 = 三视角不共相位中心
  （~75 mm，解释 19%），**~37 mm 未归因**。
- 下一步建议：**先成文**（路线 A），不要继续挖 37 mm。
