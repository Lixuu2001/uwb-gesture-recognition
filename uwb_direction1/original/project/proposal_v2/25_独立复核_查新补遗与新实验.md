## 0. 一页结论

1. **两块判决成立且被加强**：现状下"重建/训练"与"三视角识别"是同一件事（都输出识别指标）。
   本文补一刀：即便把视角合成按生成任务重新评价（`24` §1 的补救方案），**如果评测不控制
   类别先验，"生成"仍可以被类别模板作弊**（X3：类别均值 0.596 ≈ 学习式 0.60，全部打平）。
   两块要真正分开，必须同时换输出空间**和**换评测协议（§2）。
2. **`24` 的 X1 阶梯缺一条基线**：label-conditioned class-mean。补上之后，闭集刻板手势上的
   "视角想象"几乎被模板饱和——这不动摇方向本身，但**重写了评测协议**（§2.3）。
3. **方向的主推结论不变但理由更新**：视角/位姿外推的回波生成 + 主动观测规划。
   新增证据链：无类别先验时（LOGO/新类/连续运动），物理是唯一强先验（0.624 纹丝不动），
   线性学习只带来 +0.09，kNN 不迁移——**"物理骨架 + 条件扩散残差"从设计选择升级为
   实验必然**（§3）。
4. **查新补遗**：`24` §5 的表漏了四条更近的邻居——TGDP-P（IEEE Sensors J. 2026.05，
   **就在 UWB-Gestures 上做扩散生成+物理先验**）、iRadar（IMU→毫米波扩散翻译）、
   RF-ACCLDM（姿态条件潜在扩散）、ISAR 方位角外推（ISPRS 2025，"novel view synthesis
   for radar"概念已在 SAR 社区成立）。后果：**纯扩散增强路线彻底关闭**；
   我们的差异化支点收敛为"真实数据上的位姿外推 + 主动感知消费端"（§1）。
5. **行动项**：Bocus 2022 主文件（2.37 GB，CC0）在沙箱网络被 figshare ELB 拦截
   （curl 与 API 均 403），**需要用户在本地浏览器手动下载**；直链与验证见 `19` §8.2。

## 1. 查新补遗（`24` §5 之后的独立检索，2026-08-24）

| 工作 | 出处 | 与本方向的关系 | 压在哪 |
|---|---|---|---|
| **TGDP-P**：跨域雷达手势扩散生成（迁移引导+物理先验） | IEEE Sensors Journal, 2026.05, DOI 10.1109/jsen.2026.3694466 | **在 UWB-Gestures 基准上实验**；密度比修正做跨域、时频脊正则做运动学一致 | 跨的是**环境/被试域**，不是**传感器位姿**；评测是下游 F1（100 目标样本 F1 0.7970，+2.60pp）——**生成仍是增强的替身** |
| **iRadar** | Yang et al.（可穿戴，UbiComp 系） | IMU→毫米波**扩散翻译**合成手势雷达信号，18 手势×30 人，Top-3 99.82% | 跨**模态**（IMU→雷达），非跨视角；评测仍是识别准确率 |
| **RF-AIGC / RF-ACCLDM** | Complex Engineering Systems, 2024, DOI 10.20517/ces.2024.97 | 条件 GAN + **潜在扩散**从姿态骨架/活动标签合成 RF 数据（WiFi/RFID/FMCW） | 条件是**姿态/标签**，无传感器位姿维度；评测 HAR F1 与 3D HPE 误差（4.23 cm） |
| **ISAR 方位角外推** | ISPRS J. Photogramm. Remote Sens. 2025（基础模型+边缘引导） | 自称"首个正式定义 ISAR 图像方位角**外推**问题"（插值之外的推断） | **图像域**（ISAR 像片）、静态合作外推目标、无主动感知消费端；但证明"雷达 novel view synthesis"概念在 SAR 社区已立起来 |
| Wave-Former / RISE | MIT（Adib 组，2025-26） | 毫米波+生成模型补全遮挡物**几何**（54%→72%），机器人抓取 | 输出是**几何补全**不是位姿外推回波；单站静态雷达 |
| DART（radar NeRF） | arXiv 2403.03896 | Range-Doppler 隐式场做雷达 novel view synthesis | 静态场景建图，密集轨迹测量 |
| 3DGS-SAR / 复旦 DSR | ISPRS 2025 / 雷达学报 2024 | 可微渲染做 SAR 多视角样本增广 | 仿真/图像域，目标识别下游 |

**净结论**：`24` §5.1 的判决（唯一支点=真实数据上的位姿外推）**经过本次独立检索后仍成立**，
但要加两条：
- "radar novel view synthesis"这个**词**已被 SAR/ISAR 社区占用——写作时必须强调
  差异（原始回波 vs 图像、运动人体 vs 静态目标、主动感知闭环 vs 离线增广）；
- TGDP-P 是**最近邻居**（同基准、同"物理先验"话术），引用并对比它是审稿人一定会问的。

## 2. X3v2：闭集手势上，"想象"被类别模板饱和（`24` 阶梯缺一条基线）

**协议**：与 `24` X1 同样的 480 样本/1440 留一视角实例（同种子同抽样），包络降到 30×23
分辨率统一评测；学习臂全部 **LOSO**（留一被试）。脚本 `pilot/xview_residual.py`。

| 臂 | env corr | 说明 |
|---|---|---|
| **classmean**（类别×视角均值，训练被试） | **0.596 ± 0.19** | **`24` 阶梯没有的臂**：只用"知道这是哪个手势" |
| copy（抄邻近视角） | 0.149 | 与 `24` 全分辨率 0.131 一致（排序不变） |
| phys（两视角拟合+宽度模板渲染） | 0.304 | 与 `24` 的 0.289 一致 |
| blend（classmean⊗phys 最优固定混合） | 0.604 | 先验与物理**几乎不正交**：混合只 +0.008 |
| ridge_n（归一化特征岭回归，无标签） | 0.573 | v1 未归一化时崩溃到 0.117（残差深非线性） |
| ridge_n+lbl（+手势 one-hot） | 0.602 | ≈ classmean，无增益 |
| kNN(5) | 0.563 | ≈ classmean |
| oracle（已知真轨迹渲染） | **0.624** | 比 classmean 只高 **+0.028** |

**读法**（三条，比数字本身重要）：

1. **`24` X1 的阶梯（copy→phys→oracle）缺 classmean 这一臂。** 补上后，闭集刻板手势上
   "视角可想象性"的大头是**类别模板**（0.596），实例级物理信息（oracle−classmean=+0.028）
   在相关系数口径下很薄。X1 的三段归因（几何 +0.158 / 轨迹 +0.218 / 模型 +0.493）
   **第三段里混着"类别可预测性"**，不能全记给"学习式生成器的地盘"。
2. **任何"生成未观测视角"的评测必须把 label-conditioned 模板当强制基线**，否则生成器
   靠背模板就能刷分——这直接写进未来论文的评测协议，是我们对 `24` 的修正性贡献。
3. v1→v2 的方法学教训：线性模型在未归一化包络上崩溃（0.117<copy），归一化后恢复到
   先验水平——**跨视角映射的非线性主要在时间扭曲与幅度尺度**，这正是扩散类模型
   （非线性+分布级）而不是岭回归的用武之地。

## 3. X4：没有类别先验时，想象靠什么活着（LOGO）

**协议**：留一**手势**（整类 12 折），所有学习臂只见过其余 11 个手势；classmean 无定义。
这是"新类注册前夜"（`FSGR` 场景）与"连续非刻板运动"（Bocus 场景）的最小模型。

| 臂 | env corr | 迁移情况 |
|---|---|---|
| gmean（全体均值，手势盲底） | 0.372 | — |
| copy | 0.149 | 不迁移 |
| phys（物理渲染，零学习） | 0.304 | **天然迁移**（不含任何学习） |
| ridge_n（11 类训练的线性映射） | **0.392** | 部分迁移：+0.088 vs phys，64.7% 胜 |
| kNN5 | 0.281 | **不迁移**（<phys）：kNN 记的是类内邻域 |
| oracle（真轨迹物理） | 0.624 | 完美迁移 |

**峰位时序**（全分辨率，中位 mm，LOO 类均值无自泄漏）：

| 臂 | peak err |
|---|---|
| classmean | 83.2 |
| copy | 185.6 |
| phys | 121.6 |
| **oracle** | **44.8** |

**读法**：

1. **物理是唯一跨类迁移的强先验**（oracle 不变、phys 不变），学习式映射部分迁移
   （线性 +0.09）、记忆式完全不迁移（kNN <0）。→ "物理渲染骨架 + 学习式残差"
   从 `24` §2.1 的设计偏好，升级为**实验判决**：残差生成器必须以物理渲染为条件，
   否则换一类就死。
2. **实例级信息真实存在但被反演卡住**：oracle 峰位 44.8mm（≈类别均值的一半），
   而 phys 峰位 121.6mm ≈ 两视角轨迹拟合误差（`24` X1：111.4mm）。
   → 瓶颈在"回波→轨迹"的**逆问题**，不在渲染器。学习式生成器的最大价值可能是
   当**逆问题的先验/去噪器**（用已观测视角约束轨迹估计），其次才是前向残差。
3. 类别均值峰位 83.2mm 仍强于 phys——再次印证 §2 结论：闭集+刻板手势上，
   模板是难缠的作弊基线；**这个方向的真战场在无模板可背的地方**。

## 4. 方向判决（更新版）

### 4.1 主推（维持 `24` §2.1，理由更换）：可迁移观测 = 位姿外推的回波生成 + 主动观测规划

一句话（不变）：**会想象未观测视角的感知系统，才能决定下一眼去哪看。**

本次更新注入的三条硬证据：
- **评测协议**（§2）：生成质量必须在"控制类别先验 + 位姿外推"双口径下报告
  （classmean / phys / oracle 三点一线已在台架上跑通，Bocus 上同理换成
  leave-one-link-out 21 配置）；
- **方法结构**（§3）：条件扩散建模**物理渲染的残差**、以物理渲染+已观测视角为条件
  ——不是"套个扩散"，是被"线性不行/kNN 不迁移/物理必迁移"逼出来的结构；
- **逆问题瓶颈**（§3）：把"学习式逆问题先验"写进块一的任务清单（回波→轨迹的
  学习增强），这是比前向残差更痛的痛点，且直接服务块二的规划。

机器人接口照旧（一台雷达+会走路=空间多样性换时间多样性），应用锚点接项目一：
**inspector 拒识/低置信 → 触发主动观测请求 → 生成器反事实评估候选位姿 → 移动 →
再识别或注册新类（FSGR）**。这样三篇旧论文全部成为新故事的应用层，而不是弃子。

### 4.2 备选 A：开放世界"多看一眼"（主动开集识别）

若想最小化新数据依赖：只做"拒识→请求观测→再判决"的闭环，生成器降级为信息量估计器。
- 优点：与项目一衔接最紧，UWB-Gestures 可做（X2b 已证 22.7% 样本级 headroom）。
- 风险：头条指标（拒识 AUROC×观测代价 Pareto）仍带准确率色彩，可能再吃导师一刀；
  且位姿只有 3 个，"去哪看"的选择空间太小。**只适合当块二的第一个台架实验，不适合独立成块**。

### 4.3 备选 B：反演–生成双向闭环（`24` §2.2 维持原判）

X4 给它加了一分（逆问题被证明是瓶颈），但撞车面（RF-Diffusion/RadarTwin/V2R/RF-ACCLDM）
没有变小。维持"比 4.1 弱"的原判；其中"学习式逆问题先验"这一最有价值的部件已并入 4.1。

### 4.4 关闭的路线（本次查新后正式关闭）

- **纯扩散做手势数据增强**：TGDP-P 已在 UWB-Gestures 上做完（含物理先验与跨域），
  没有剩余空间；
- **跨模态翻译生成**（IMU/图像→雷达）：iRadar、mmGesture/ACDTM、RF-ACCLDM 占满；
- **自运动射频感知**：维持 `24` §2.3（无公开数据）。
