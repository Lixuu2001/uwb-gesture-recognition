## 3. 论文四 `paper4/owda_paper.tex`（8 页草稿已成，编译通过）——**用户问的就是这一篇**

### 它到底在做什么（大白话）

论文三交出的是一套"冻结的成品系统"。论文四做的是**给这套成品建一个压力测试台，然后照实
公布体检报告**。三步：

1. **造受控数据流**：五段伪时间结构的数据流，六类信号退化按严重度网格施加在单个视角或全部
   视角上——
   - `domain`：杂波抑制退化（ClutterRemoved 向 Raw 凸混合，混合系数=残留杂波比例）
   - `drop`：某路雷达信号消失
   - `occlude`：遮挡
   - `noise` / `shift`：加噪 / 距离平移
   - `atten`：幅度衰减
2. **审计（G0）**：冻结系统在这些退化下会不会崩、怎么崩。
3. **改进 + 复判**：试图用在线自适应把崩的地方救回来。

### 结果：一个正面判决、一个小方法、三个证伪

| 环节 | 判决 | 内容 |
|---|---|---|
| G0 漂移审计 | **PASS**（问题成立） | 6 族里 5 族能击穿冻结系统，最重单元调和精度掉 **78 分**；`domain` 是统治性杀手（全部 4 视角轴 × 2 词表双触发）；`atten` 免疫是**数学恒等**（逐视角标量乘被 abs_std 精确抵消），不是稳健性；单视角腐蚀被三视角均值稀释——这条反过来是论文一多视角设计的红利 |
| G1 calib-select 尺度对齐 | **成立** | 用部署时本就有的校准被试数据，在预注册网格上**自动选**路由尺度 s，替掉论文三手调的 1.5。新类精度较不校正基线 +8.7~18.2 分，**与最优固定常数相当**（价值=免调参，不是超越） |
| G1a 比例估计 / G1b 伪注册 | **证伪** | 中位数比例估计器 spearman 负；伪注册方向反了（编码器见过伪新类→无翻墙压力） |
| G2 在线自适应 | **FAIL** | 预注册四门，两词表 0/25 单元全过不了；**自动采纳伪标签净贡献 ≤0**，真实增益全部来自用户确认通道；污染率不是伤害度量，污染物的几何位置才是 |
| S0 根因门 | **证伪** | 推翻 §45.3 "fuse-base λ=1 是 base 覆盖崩塌的统一凶手"：只对 occlude 成立；drop/domain 的崩塌是逐视角距离几何本身被摧毁。失败模式是**族异质**的（惩罚误伤 vs 距离废墟） |
| E0-a oracle 掩蔽天花板 | **证伪** | 即使评估器先知哪个视角坏，硬掩蔽在中间严重度亏 6–18 分，只有视角全死（sev=1）才 +7.7；连完美检测的天花板都救不回 drop 族 |

### 所以"是不是失败了"

**主假设失败，论文成立。** 按预注册的分支条款自动转"路线 a"定稿，最终定位是：

> 数据驱动尺度对齐方法 + 受控开放世界漂移审计协议 + 在线自适应失败机制图谱

作为**小论文**这是站得住的（评测/审计类论文，负结果有价值，摘要已写完）。作为**学位论文的
一个独立研究内容块**，它的正向方法只剩"自动选一个标量尺度"这一条，撑不起来——上一版计划表
里把它标成"已完成"没有说清这层性质差别，是表述不准。

### 建议处置

和论文三**合并成一个研究点**。理由是用户自己在 `RESULTS.md §49.4` 里已经写下：

> §33 少样本 d 膨胀 8–10× / §38+§44.4 漂移压偏最优路由尺度 / §49 属性幅度落入 none 带
> ——**同一个病第三次出现**：几何可读、尺度错位。

论文三（少样本注册时的尺度错位）+ 论文四（漂移下的尺度错位）本来就是同一根轴上的两段，
合并叙事比拆成两个点更有说服力，审计协议作为该点的评测方法论小节。
