面向导师的要求：「一篇大论文要有 2 个研究内容块，每块下面要有 3 个左右的研究点，
每个研究点要说清技术路线（准备用什么方法思路完成）」。

## 0. 导师批评的翻译与破局点

导师的原话核心是两句：

> 「你目前只是完成了手势识别的事情」「第二个做的事情本质还是在做手势识别，只是用了另一个
> 手段来提高准确率，和第一个本质上干的是同样的事」

**翻译**：判断一个研究点是不是"另一件事"，看的不是方法新不新，而是**输出空间变不变**。

| 现有工作 | 输入 | 输出 | 任务类型 |
|---|---|---|---|
| 论文一 / 三 / 四 | 三路回波 | 类别标签 / 接受-拒识决策 | 判别 |
| 「脊柱生成」（掩蔽重建） | 三路回波 | 类别标签（重建只是中间手段） | 判别 |
| 「少样本注册」 | 三路回波 + K 个样本 | 类别标签 | 判别 |

四个点的输出空间全是"标签"，所以在导师眼里是一件事。**破局 = 让第二块的输出不是标签**。

同时导师给了第二条提示：

> 「或者更基础一点的内容有没有」

这句指向的是**前向物理模型与可观测性分析**（给定运动和布阵，回波长什么样；哪些运动分量
原理上不可观测）。这类内容比"再加一个网络模块"更"基础"，且不吃数据、不吃 GPU。

**另外一个术语问题**：不要再对导师说「脊柱生成」。那是 generative **backbone**（生成式骨干）
的内部黑话，导师很可能听成了人体脊柱/骨架。对外统一说「自监督掩蔽重建预训练」。

## 2. 技术路线（逐研究点展开，这是导师点名要的部分）

### 2.1 距离域多视角手部轨迹重建与传感几何自标定

**要回答的问题**：能否只从三路回波恢复手的连续运动轨迹，并在没有真值的条件下证明它是对的。

**输入输出**：输入 `(3, 90, 189)` 回波；输出 $\hat p(t)\in\mathbb R^3$，90 帧连续轨迹。

**四步技术路线**

1. **稳健距离跟踪**。包络（沿快时间的解析信号）→ 峰值邻域质心 → 用维特比/卡尔曼做时序路径
   搜索，抑制"手—手臂—身体"多散射中心之间的跳变。产出 $r_L(t), r_T(t), r_R(t)$。
2. **传感几何自标定**。把三台雷达位置、距离窗起点当未知量，用全体样本做类似**光束平差**的
   联合优化（残差=重投影误差）。这一步是必须的：数据集只给了"左右间距 1.1 m、顶部距中点
   0.55 m、距离窗 1.2 m/189 bin"，高度、站位、窗起点、三台之间的时间对齐**全都没有**。
   判据：标定后跨样本重投影残差显著低于固定几何。
3. **时序正则的非线性求解**。逐帧的"三距离→三维位置"是**恰定**的（3 方程 3 未知数，残差恒 0），
   必须换成轨迹级优化：B 样条参数化 $p(t)$，最小化
   $\sum_v \|\hat r_v(t) - r_v(t)\|^2 + \lambda\|\ddot p(t)\|^2$。
   这样有效自由度低于测量数，留一雷达才有残差可看。
4. **学习式残差修正**。几何解当伪标签/初值，小网络学"散射中心在手上游走"造成的系统偏差。
   这一步失败不影响 1–3 成立（退路）。

**评估（无真值三板斧，必须写进开题）**

| 协议 | 做法 | 判据 |
|---|---|---|
| ① 留一雷达重投影 | 用两路 + 时序正则重建，预测第三路的距离曲线 | 残差 < 运动幅度的 15% |
| ② 仿真闭环 | 用 2.2 的前向模型造已知轨迹 → 合成回波 → 反演 | RMSE < 20 mm |
| ③ 下游一致性 | 轴选择性 / 方向 / 旋向三项零训练读数 | 见 `03` 已测基线 |

**风险与退路**：若跨人稳定性差（先导里 HV3 旋向仍在随机线），退到"运动学量重建"（方向、
幅度、旋向、节律）而不宣称 mm 级轨迹——结论仍成立，只是措辞收紧。

### 2.2 可微前向回波模型与运动可观测性分析

**要回答的问题**：给定一条手部运动与一套雷达布阵，回波长什么样？反过来，哪些运动分量在原理
上根本不可观测？

**四步技术路线**

1. **点散射前向模型**。手建模为 $N$ 个散射中心，第 $v$ 路回波
   $s_v(t,\tau)=\sum_i a_i\, g(\tau - 2R_{v,i}(t)/c)\,e^{j4\pi R_{v,i}(t)/\lambda}$，
   $g(\cdot)$ 为脉冲响应（按 −10 dB 带宽 1.5 GHz 与 189 bin/1.2 m 标定）。用真实数据反标
   $N$、$a_i$ 与带宽响应。
2. **可微化**。整套渲染用 autograd 实现，于是"轨迹"变成可梯度下降的变量 →
   **analysis-by-synthesis 反演**（对标视觉里的可微渲染 / inverse rendering）。
   这是 2.1 第 4 步之外的另一条反演路径，两者互为对照。
3. **可观测性分析**。位移到三路径向投影的雅可比
   $J = [\hat u_L; \hat u_T; \hat u_R]$，分析其条件数随布阵/站位的变化，找出落进零空间的
   运动方向。**`RESULTS.md §49.2` 那个"对称池化下水平读数精确为 0.00"就是这个零空间的一个
   实例**——现在能从理论上讲清楚，而不是只报一个经验数字。
4. **最优布阵**。由条件数反推三/四雷达的最优摆放，给出工程建议（本数据集无法补采，但可以
   对未来采集提建议，这也是论文贡献的一种）。

**评估**：合成回波与真实回波的分布距离；用合成数据训练、真实数据测试（**TSTR** 协议）；
可观测性预测与实测退化的一致性（例如"该布阵下水平不可观测"应能在实测上复现）。

**为什么这一点强**：它把"**没有真值**"和"**数据集不能补采**"这两个死穴同时变成方法论贡献，
并且是纯理论+仿真，不吃 GPU、不受数据集规模限制。这就是导师说的"更基础一点的内容"。

### 2.3 运动学表征反哺识别与注册

**要回答的问题**：重建出的运动学量能否作为可解释中间表示，替代或增强黑盒特征去做属性分解与
新类注册。

**三步技术路线**

1. **属性从"特征方向"升级为"物理量"**。现在的属性是冻结特征空间里的线性方向（可被质疑为
   黑盒巧合）；换成轨迹的物理量后，属性就是速度不对称量 $E[v^3]$、环路有向面积、摆幅。
   并按 `RESULTS.md §49.4` 的方法学结论：**属性"存在性"不由学出来的 none 类判定，改由校准
   被试上的幅度阈值判定**，直接复用论文三 §32/§36 的共形机器。
2. **零样本注册**。属性算术合成原型 $\hat\varphi(h,v)=\mu(h)+\mu(v)-\mu(\text{单轴均值})$，
   按 `docs/superpowers/specs/2026-07-26-attribute-prior-registration-preregistration.md`
   跑 Gate 1/2（必须带 base 类竞争、真未知拒识、共形阈值——Gate 0 的 88.91 是封闭比较，
   不可与 acc_new 并列）。
3. **合成样本增广注册**。用 2.2 的前向模型渲染**词表里没有的新手势**（给定一条轨迹就能渲染），
   喂给少样本注册线，治 K=1 的短板（论文三 §37）。按 TSTR + 注册指标增量评估。

**风险**：合成-真实域差（sim-to-real gap）。这是可测量的量，测出来就是结果，不是失败。
