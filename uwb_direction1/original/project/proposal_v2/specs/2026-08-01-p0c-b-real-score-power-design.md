## 0. 目标、边界与当前停止位置

P0c-b 只回答一个问题：

> 在不打开任何外层测试被试、不运行真实轨迹基线或学习模型的条件下，冻结的最小 O1 观测尺子能否在
> 诚实的被试级审计中稳定检出约 5% 的 FRNLL 退化，并支持正式 `n=8` 被试级裁决所需的功效？

P0c-b 是**评分/观测尺子审计**，不是轨迹预测实验。正确顺序固定为：

1. P0c-a：纯合成评分实现与语义；
2. P0c-b：真实 O1、受控错误臂和被试级 5% 功效；
3. C1：另行批准后才可运行 Last/CV/CA、历史长度或学习预测器；
4. 只有后续预测门支持时，才讨论 Gaussian/MDN/flow/diffusion。

P0c-b GO 也不表示：

- 未来轨迹可预测；
- 任一轨迹模型优于 Last/CV/CA；
- O1 给出了真实轨迹真值；
- midpoint-quantile oracle 是因果预测器；
- Energy/Variogram Score 在真实数据上获得了独立联合真值；
- 研究点 2.1 或 2.2 已通过。

本次任务只写本设计文档。当前不得读取 `cache/` 或 `logs/` 中的真实信号/结果内容，不得加载
`logs/w2_pulse.npz`，不得运行 O1、W1、W3、Last/CV/CA、`--track`、`--analyze`、模型排名或功效程序，
不得写 implementation plan 或代码，不得 stage、commit 或 merge。

边界句固定为：

> `P0c-a score semantics PASS != P0c-b real-score power PASS != trajectory predictability PASS`。

## 1. 方案选择

### 1.1 采用方案

采用**嵌套被试级交叉拟合 + O1 midpoint-quantile oracle + donor 连续扰动**：

- 外层测试被试在其折内完全封存；
- 其余七名开发被试轮流充当审计被试，另外一名按固定循环充当校准被试，其余五名只拟合 O1；
- 用真实未来 O1 边缘质量构造确定性的 `K=20` oracle 尺子探针；
- 用只看当前距离和近期速度的 donor 构造连续坏臂；
- `alpha_H` 只在校准被试上调到约 5% FRNLL 退化，冻结后用于审计被试；
- 最终只保留七个审计被试级差，不把序列、帧、prefix 或不同外层折伪装成独立样本。

### 1.2 不采用的方案

- 不把八个外层折的 `8×7=56` 个差池化，因为同一被试在不同外层折反复出现；
- 不把固定距离偏移作为主臂，因为它不能代表真实条件未来之间的可混淆错误；
- 不提前运行 Last/CV/CA 或学习模型来“实测谁赢”，因为这会在尺子冻结前打开模型比较；
- 不用 O0 替代失败的 O1；O0 只允许作数值诊断；
- 不加入 O2；O1 失败就是 P0c-b NO-GO；
- 不用手势标签、被试标签特征或真实未来挑 donor；
- 不用审计结果重新选择模板、宽度网格、outlier、donor 或 `alpha_H`。

## 2. 数据角色与封存合同

### 2.1 外层 LOSO

被试 ID 按数值升序固定。对每个外层测试被试 `u`：

1. 除 §3 已批准的全折共享、预冻结模板校准产物外，`u` 的信号在该折 P0c-b 中不得读取、映射、汇总
   或参与任何参数；
2. 只允许分割控制器持有其 ID，以证明排除关系；
3. 其余七名构成有序开发集合 `D_u=(a_0,...,a_6)`；
4. 每个外层折独立输出一个 verdict bundle；
5. 不同外层折的审计差不得合并成 56 个独立观测。

这里的封存是逐外层折的逻辑封存：同一被试可在其他外层折作为开发被试，但它绝不能影响自己作为外层
测试被试那一折新估计的 O1 参数、校准参数或审计统计。§3 的预冻结模板是唯一例外，必须全折逐字节相同，
且不得在 P0c-b 内重估。

### 2.2 七次平衡循环交叉拟合

对 `j=0,...,6`：

- 审计被试：`a_j`；
- 校准被试：`a_(j+1 mod 7)`；
- O1 拟合被试：其余五名。

因此每名开发被试在一个外层折中恰好审计一次、校准一次、拟合五次。每次内层拆分独立冻结 O1 参数、
donor 匹配尺度、一个全局 `pi_out` 和三个 `alpha_H`；审计被试不得参与这些量的估计。

### 2.3 允许与禁止的信息

允许：

- P0a 冻结的 `sample_idx`、`prefix_t∈{20,30,45,60}`、`H∈{5,10,20}`、视角顺序和结构掩码；
- ClutterRemoved 的历史帧和真实未来帧，仅在相应拟合、校准或审计角色的规定步骤中使用；
- 被试 ID 仅供拆分控制器分组；
- 雷达几何、`DT=0.05 s`、`BIN_M=1.2/189 m` 等冻结物理常数。

禁止：

- 手势标签进入 O1、donor、`alpha_H`、评分或功效对象；
- 外层测试被试信号进入同折任何步骤；
- W1 伪轨迹、W3 风险/读出分数、Last/CV/CA 输出或模型预测；
- 以完整 90 帧统计量归一化历史前缀；
- 因坏臂得分差而删除键、视角、未来时刻或被试。

## 3. 固定仪器脉冲模板合同

### 3.1 固定来源

未来实施前，把 `logs/w2_pulse.npz` 作为**不含手势/被试标签字段的固定脉冲校准产物**。在读取任何
真实信号前必须冻结并写入 manifest：

- 文件逐字节 SHA-256；
- 相对路径、文件大小和 NPZ 成员名；
- 每个成员的 shape、dtype、有限性摘要；
- `W` 与 `len(env)=2W+1` 的一致性；
- 生成脚本 `tools/w2_calib_pulse.py` 的 SHA-256；
- 协议版本 `P0c-b-v1`。

预期成员固定为 `template, env, W, carrier, amp_exp, width_bins`。P0c-b O1 **只使用** `env` 与 `W`；
其余成员只记录元数据，不得进入 O1 似然、donor 或评分。特别地，P0c-b 不使用 `carrier`、`amp_exp`，
也不把该文件解释为独立的新被试验证证据。

必须同时明示其历史来源边界：生成脚本会读取真实 ClutterRemoved/Raw 缓存，以 `y<11` 选样并用
Viterbi 轨迹对齐散射回波。因此“NPZ 内没有标签/被试 ID”不等于“模板生成过程没有使用真实数据或标签”，
也不等于独立仪器台架测得的纯硬件冲激响应。本文按用户已批准决定，把它作为在 P0c-b 之前已经存在、
全折共享且不得更新的校准常量；论文必须披露这一点。若以后要求严格的外层被试无接触硬件模板，只能用
新增的独立仪器采集重新预注册，不能在本门失败后现场替换。

`env` 必须是一维、长度 `2W+1`、有限、非负、最大值严格为正，且最大值位于中心索引 `W`。检查失败
立即 NO-GO，不得现场重生成或换文件。

### 3.2 宽度模板库

先把 `env` 除以其最大值。以中心 `W` 为原点，用线性插值构造固定膨胀因子：

```text
s ∈ {1.00, 1.25, 1.50, 1.75, 2.00, 2.25, 2.50}
```

对每个 `s`，在 189-bin 网格中心对齐重采样，网格外补零；随后平方到包络能量域并做 L2 归一化，得到
`k_s`。禁止依据拟合、校准或审计结果增删膨胀因子。五名拟合被试估得的宽度先验若在两个边界因子上的
总质量超过 25%，说明库未覆盖，当前内层拆分 NO-GO；不得扩大网格后重试。

模板库对三视角共享。视角差异只允许通过 `sigma_v` 表达，不建立逐视角模板、逐手势模板或逐被试模板。

## 4. 最小 O1 观测尺子

### 4.1 包络能量与幅度 profile

对 ClutterRemoved 的单帧单视角信号 `X_(v,t)`，固定：

$$
E_{v,t}(b)=|\operatorname{analytic}(X_{v,t})(b)|^2.
$$

对候选距离 bin `rho` 和宽度因子 `s`：

$$
\widehat A(\rho,s)
=\max\left(0,
\frac{\langle E,k_s(\cdot-\rho)\rangle}
{\langle k_s,k_s\rangle}
\right),
$$

$$
L_{v,t}(\rho,s)=
\frac{\|E_{v,t}-\widehat A(\rho,s)k_s(\cdot-\rho)\|_2^2}
{2\sigma_v^2}.
$$

幅度只有这个非负闭式 profile，不设幅度网格、神经修正或被试参数。

### 4.2 五名拟合被试只估 `sigma_v` 与宽度先验

每个内层拆分采用确定性的两遍估计，不迭代到看似更好的局部解：

1. 第一遍令七个宽度等权。对每名拟合被试、每个视角和每个唯一物理帧，计算
   `R=min_(rho,s) SSE/(189-1)`；该被试的 `sigma_(u,v)=sqrt(median(R))`；
2. 每视角取五名被试 `sigma_(u,v)` 的中位数，得到三个 `sigma_v`；任一值非有限或不严格为正即停止；
3. 用冻结 `sigma_v` 计算每帧的宽度责任

   $$
   r_i(s)\propto\sum_\rho\exp\{-L_i(\rho,s)\};
   $$

4. 每名拟合被试先对自己的全部唯一帧和三视角平均责任，并加固定 Jeffreys 平滑 `+0.5`；
5. 再对五名被试的七维概率向量等权平均，得到跨视角共享的 `p(s)`。

“唯一物理帧”表示同一 `sample_idx×frame×view` 只计一次；四个 prefix 不得重复增加其权重。拟合过程不读
手势标签、校准被试、审计被试或外层测试被试。

### 4.3 全局共享 outlier 权重

每个内层拆分只允许一个 `pi_out`，三视角、四个 prefix 和三个 H 全部共用。它由校准被试在选择
`alpha_H` **之前**一次冻结。

对校准被试每个唯一物理帧和视角，计算：

$$
Q_i=\min_{\rho,s}
\frac{\|E_i-\widehat A(\rho,s)k_s(\cdot-\rho)\|_2^2}
{(189-1)\sigma_v^2}.
$$

在全部有限 `Q_i` 上令 `m=median(Q)`、`d=1.4826 median(|Q-m|)`，固定粗失配门为 `Q_i>m+3d`。
`pi_raw` 等于超过该门的比例，并四舍五入到最近的 `0.001`，正好并列时取较小值。若 `pi_raw>0.20`、
样本为空或出现非有限值，该内层拆分 NO-GO；不得把值裁到 0.20。

这只是冻结均匀鲁棒质量的污染率规则，不把 `pi_out` 宣称为真实物理 outlier 后验概率，也不得用 5%
FRNLL 检出率反向调它。

### 4.4 O1 距离质量

用 log-sum-exp 稳定计算：

$$
q_{v,t}(\rho)\propto
\sum_s p(s)\exp\{-L_{v,t}(\rho,s)\},
$$

$$
\ell^{O1}_{v,t}(\rho)
=(1-\pi_{out})q_{v,t}(\rho)+\frac{\pi_{out}}{189}.
$$

每个合法质量向量必须为 `float64`、有限、非负，并在绝对误差 `1e-12` 内和为 1。未来 H 帧组成
P0c-a 已冻结的 `ObservedRangeMass.mass`，shape 为 `(3,H,189)`，距离网格、插值、`epsilon=1e-12`、
FRNLL 和 expected range CRPS 公式全部沿用 P0c-a，不另起口径。

结构缺失产生的 `valid_mask` 必须在构造任何臂前冻结，good/bad 共用；非有限信号、质量归一化失败或整键
无合法单元均为协议错误，不得静默删除。O0 只可打印质量和、有限性、熵等数值诊断，不参与 5% 主门；
O1 失败不得改用 O0 或 O2。

O1 provenance 至少哈希：模板文件 SHA-256、宽度因子、`sigma_v`、`p(s)`、`pi_out`、距离网格、外层/内层
角色 ID、协议版本和 P0a 键 provenance。

## 5. `K=20` oracle、donor 与受控坏臂

### 5.1 确定性 midpoint-quantile oracle

对每个 `(view, future_step)` 的 O1 边缘质量，固定：

$$
q_k=\frac{k-0.5}{20},\qquad k=1,...,20.
$$

用离散距离质量的左连续逆 CDF 取对应网格距离，形成 `x_oracle`，shape `(20,3,H)`。不随机采样，
不做审计后 jitter。所有维度使用相同 `k` 顺序；这是固定的共单调配对，只为形成可复现的边缘评分探针。
它不保证三视角距离具有联合几何可实现性，因此不是轨迹、不是预测器，不能据此解释真实联合依赖。

### 5.2 donor 匹配特征

对 prefix `t`，当前帧索引为 `c=t-1`。对每视角，用历史 O1 距离中位数构造：

- 当前距离：`median_rho(v,c)`；
- 近期速度：在 `c-4,...,c` 五帧上，以 `DT=0.05 s` 做带截距普通最小二乘斜率。

得到六维特征 `[r_top,r_left,r_right,v_top,v_left,v_right]`。每一维尺度先在五名拟合被试内分别计算标准差，
再取五个标准差的中位数；任一尺度非有限或不严格为正即停止。匹配只用尺度，不用手势中心或标签。

### 5.3 donor 合同

对目标键，候选 donor 必须：

- 来自同一校准/审计被试；
- 具有相同 prefix 和 H；
- 来自另一条基础序列；
- 六维匹配特征完整有限。

取标准化欧氏距离最近者；并列时按固定 `sample_idx` 数值升序。禁止使用手势标签、真实未来、未来 O1、
坏臂得分或审计结果挑 donor。最近 donor 的未来若过于相似，也不得换为第二近者。无合法 donor 即该键
协议失败，不删键。

donor 自身的真实未来 O1 质量用同一 midpoint 规则转为 `x_donor`。donor 的未来只用于预先定义的错误
注入，不参与 donor 搜索，因此不会冒充因果可获得信息。

### 5.4 连续坏臂

对每个 H：

$$
x_{bad}(\alpha_H)
=(1-\alpha_H)x_{oracle}+\alpha_H x_{donor}.
$$

`alpha_H` 在校准被试上选择，四个 prefix 共用；不同 H 可有不同值。选择前 `sigma_v,p(s),pi_out` 和
donor 尺度均已冻结。

固定搜索网格：

```text
alpha_H ∈ {0.000, 0.001, ..., 1.000}
```

校准被试每个 prefix 先在序列内分别平均 good/bad FRNLL，再计算相对退化：

$$
d_{H,p}(\alpha)=
\frac{\overline{FRNLL}_{bad,H,p}(\alpha)-
      \overline{FRNLL}_{good,H,p}}
     {\overline{FRNLL}_{good,H,p}}.
$$

四个 prefix 等权：`d_H(alpha)=mean_p d_(H,p)(alpha)`。选择与 0.05 绝对距离最小的网格值；并列取较小
`alpha_H`。必须满足 `0.0475<=d_H<=0.0525`。若 `alpha<=1` 仍不可达，该内层拆分的该 H 立即 NO-GO，
不外推、不换 donor、不改网格。

## 6. 审计聚合与决定性统计

### 6.1 唯一聚合顺序

对一个外层折、一个审计被试 `a`、H 和 prefix：

1. 每个 ScoreKey 分别计算 good 与 bad 的 FRNLL；
2. 在该审计被试的基础序列内取算术平均，得到 `G_(a,H,p)` 与 `B_(a,H,p)`；
3. 要求 `G_(a,H,p)` 有限且严格为正；
4. 定义相对差

   $$
   d_{a,H,p}=\frac{B_{a,H,p}-G_{a,H,p}}{G_{a,H,p}};
   $$

5. 四个 prefix 等权得到 `d_(a,H)=mean_p d_(a,H,p)`；
6. 保留七名审计被试的七个 `d_(a,H)`，不再向下展开。

禁止先池化全部帧/序列/prefix 再计算一个比例，也禁止让有效键更多的 prefix 获得更大权重。H=5/10/20
分别裁决。

### 6.2 FRNLL 实际臂主检验

对每个外层折和每个 H，使用七个 `d_(a,H)`：

- 统计量：七人均值；
- 备择：bad FRNLL 相对退化 `>0`；
- 枚举 `2^7` 个符号向量，做单侧 exact sign-flip；
- `p` 等于不小于观测统计量的枚举比例，不加 Monte Carlo 修正；
- 通过反演同一符号翻转族的双侧检验给出配对 95% 位置平移区间；
- 同时报七人中 `d_(a,H)>0` 的方向数。

该 H 的实际臂必须同时满足：

1. `mean(d_(a,H))>0`；
2. 单侧 exact `p<0.05`；
3. 配对 95% 区间下界严格 `>0`。

三个 H 构成交并式裁决：全部通过才可声称尺子覆盖 0.25/0.5/1.0 s；不跨 H 池化，也不挑最好的 H。

### 6.3 12 个方向诊断格

对 `H∈{5,10,20}` 与四个 prefix 的每个格，先保留七个 `d_(a,H,p)`，再取七人等权均值。12 个格的
FRNLL 均值必须全部严格 `>0`。这些格只检查方向，不各自再做显著性门；主显著性仍由 prefix 等权后的
三个 H 检验承担。

### 6.4 expected range CRPS

沿用 P0c-a 的“对 O1 目标质量取期望”公式。对每个审计被试、H、prefix 先计算序列平均的
`CRPS_bad-CRPS_good`，再按与 FRNLL 相同的被试等权顺序聚合。

要求：

- 12 个 `H×prefix` 格的七人平均差全部严格 `>0`；
- 每个 H 的四 prefix 等权平均差严格 `>0`。

CRPS 不要求 5% 相对阈值，不另设 p 值或区间门，也不得与 FRNLL 加权成总分。

### 6.5 Energy/Variogram 边界

真实 O1 只提供边缘距离质量，没有独立联合轨迹真值。由于 midpoint oracle 使用人为固定的跨维配对，
Energy/Variogram Score 只能带 `exploratory=true` 报告，不能进入 GO、`alpha_H`、功效、模型选择或论文
联合分布主张。任何方向都不得覆盖 FRNLL/CRPS 的失败。

## 7. 正式 `n=8` 的 5% 功效审计

### 7.1 严格 5% 注入

对一个外层折和 H 的七个审计相对差 `d_i`：

$$
e_i=d_i-\bar d.
$$

功效模拟只使用中心化残差，并注入严格 5%：

$$
z_i=0.05+e_i.
$$

因此实际臂均值不会被冒充为预期模型效应；功效回答的是“在已观察到的被试离散度形状下，若真实总体
效应恰为 5%，正式八被试门有多大概率通过”。

### 7.2 七次 leave-one-subject-out 稳健功效

对七名审计被试再轮流遗漏一名，共七次：

1. 在剩余六个 `e_i` 上重新中心化；
2. 加 0.05；
3. 用有放回经验重采样生成 `B=100000` 个 `n=8` 被试数据集；
4. 每个数据集应用与正式主门相同的“单侧 exact sign-flip `p<0.05` 且双侧反演区间下界 `>0`”；
5. power 为同时通过两项的比例；
6. 对通过次数计算 one-sided 95% Clopper-Pearson 下界。

RNG 不得使用 Python `hash()`。种子由 UTF-8 文本 `P0c-b-v1-power`、外层测试被试 ID、H、被遗漏审计
被试 ID 按固定 little-endian 编码后取 SHA-256 前 8 bytes 得到，并写入 manifest。

决定性要求是：每个 H 的七个功效估计中，**最差一个的 one-sided 95% 下界仍 `>=0.80`**。只报点估计
达到 80% 不足以过门。三个 H 分别满足；不平均、不删离群 leave-one-out。

这仍是基于七名开发被试经验残差的设计功效，不是新被试覆盖保证，也不是轨迹可预测性证据。

## 8. 非决定性敏感性与数值诊断

### 8.1 固定距离偏移

保留一个与 P0c-a 对齐的非决定性敏感性臂：Top 视角全部未来步和 K 个样本统一 `+3*BIN_M`，其他视角
不变，不裁剪到网格。只报告 FRNLL/CRPS 方向和幅度，不参与 `alpha_H`、显著性、功效或 GO。

### 8.2 O0 数值诊断

若未来实现包含 O0，只允许检查：shape、质量和、有限性、熵、主峰位置和 O1/O0 的描述性差。不得用 O0
的 5% 检出结果救 O1，也不得依据 O0 调 O1 的模板、宽度、`sigma_v` 或 `pi_out`。

### 8.3 必报审计量

- 每个角色的被试 ID、唯一序列/帧/ScoreKey 数；
- 模板 SHA-256 与元数据合同；
- 每个内层拆分的三个 `sigma_v`、七维 `p(s)`、边界质量和 `pi_out`；
- 六维 donor 尺度、donor 唯一率、匹配距离分位数；
- 每个 `alpha_H` 与校准实际退化；
- 每个审计被试的 12 个 FRNLL/CRPS 差；
- 每个外层折、H 的 exact p、95% 区间、方向数；
- 七个 leave-one-out power 点估计及其下置信界；
- 所有协议错误和失败原因，禁止只打印总 PASS。

这些诊断不能产生新的排除规则或参数调整。

## 9. 失败语义与防作弊边界

以下任一情况立即使对应内层拆分、外层折或整体按 §10 传播为 NO-GO：

- 模板 SHA/元数据不符、现场重生成或更换模板；
- 审计或外层测试被试参与 `sigma_v`、宽度先验、outlier、donor 尺度或 `alpha_H`；
- 手势标签进入任何 P0c-b 算法对象；
- 四个 prefix 重复计权同一物理帧；
- O1 质量非有限、未归一、mask 不同或整键无合法单元；
- 宽度先验边界质量超过 25%；
- `pi_raw>0.20`；
- donor 缺失、同序列、使用未来挑选或临时换次近邻；
- 任一 `alpha_H` 无法在冻结网格达到 4.75%–5.25%；
- 分母 FRNLL 非有限或不严格为正；
- 把序列、帧、prefix、七次内层审计或八个外层折当独立样本；
- 任一 H、诊断格、CRPS 方向、区间或功效门失败；
- 用 O0、O2、固定偏移、Energy/Variogram 或轨迹模型补救。

失败后不得在同一批八被试上改门、换 donor、扩宽度网格、换 outlier 规则或删除 H，再声称确认性 PASS。
任何后续新方案必须明确降为探索性，或使用新增独立被试重新预注册。

---

## 10. P0c-b Go/No-Go

### 10.1 单个外层折 GO

一个外层折仅当以下全部成立才为 GO：

1. 七次内层交叉拟合均满足模板、O1、outlier、donor 和 `alpha_H` 合同；
2. H=5/10/20 的 FRNLL 实际臂均满足单侧 exact `p<0.05` 且配对 95% 区间下界 `>0`；
3. 12 个 `H×prefix` FRNLL 方向格全部正确；
4. expected range CRPS 的 12 个方向格和三个 H 汇总方向全部正确；
5. 每个 H 的七次 leave-one-subject-out 功效中，最差 one-sided 95% 下界 `>=80%`；
6. 无外层测试信号读取、无轨迹基线/模型运行、无决定性格缺失；
7. manifest 足以独立重算全部裁决。

### 10.2 整体 GO

八个外层折必须全部达到 §10.1，且三个 H 全部通过。由于这是交并式门，任一外层折或任一 H 失败即
P0c-b 整体 NO-GO；不得报告“其余折 pooled PASS”或只保留短 H。

P0c-b GO 的唯一含义是：

> 冻结 O1 与主评分在当前开发被试离散度下，具备检出预注册 5% FRNLL 退化的资格。

它仍不自动授权运行真实 Last/CV/CA 或学习模型。必须先由用户复核 P0c-b 证据，再在新任务中单独批准
C1 执行。

## 11. 未来实现与证据接口（本次不执行）

未来若用户另行批准实现，模块必须保持单一职责：

| 逻辑单元 | 单一职责 |
|---|---|
| O1 template contract | 只验证固定模板 SHA/元数据并生成宽度库 |
| O1 fit | 只用五名拟合被试估 `sigma_v,p(s)` |
| O1 calibration | 只用校准被试冻结全局 `pi_out` |
| quantile arm | 只构造 oracle、donor 与 `alpha_H` 坏臂 |
| subject audit | 只产生七个被试级 FRNLL/CRPS 差 |
| power audit | 只在中心化七人差上做严格 5% 功效 |
| verdict | 只读取冻结 manifest 和被试级结果并 fail-closed 裁决 |

必须有纯合成合同测试覆盖：角色泄漏、循环拆分、模板元数据、幅度闭式解、宽度边缘化、全局 outlier、
midpoint 逆 CDF、donor 不看未来、`alpha_H` 选择、聚合顺序、`2^7` exact sign-flip、区间反演、功效 RNG、
12 格方向和任一 H fail-closed。真实数据读取与纯合成测试必须是不同入口；本设计不预先命名 CLI，也不构成
implementation plan。

## 12. 已冻结决策记录

用户已明确批准或授权按推荐口径冻结：

- P0c-b 是纯评分/观测尺子审计，外层测试被试封存，不提前比较轨迹模型；
- 七开发被试采用平衡循环的 `1 audit + 1 calibration + 5 fit`；
- 不同外层折不池化为 56 个独立样本；
- 最小 O1 使用固定仪器脉冲、幅度闭式 profile、训练冻结宽度边缘化和拟合被试 `sigma_v`；
- 一个全局共享 `pi_out`，O0 不进门，O1 失败不换 O2；
- `K=20` 使用 midpoint quantile；
- donor 同被试、同 prefix/H、不同序列，只匹配当前距离与过去五帧速度；
- 每个 H 单独选择 `alpha_H`，四个 prefix 共用，校准目标 4.75%–5.25%；
- FRNLL 以七个审计被试为单位做单侧 exact sign-flip 和配对区间；
- 七人差中心化后注入严格 5%，估计正式 `n=8` 功效；
- 12 个 H×prefix 方向格、expected range CRPS、探索性 Energy/Variogram 和整体 NO-GO 语义按本文冻结；
- 当前只写 design doc，不读取真实数据、不实现、不运行、不提交。
