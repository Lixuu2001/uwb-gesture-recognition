> 再运行核心 L1/L2 检验。

## 2. 整个块二研究什么

### 2.1 为什么要从分类转向运动

块一输入三路 UWB 回波，输出手势类别。虽然已经完成开集识别、少样本注册和压力测试，但导师指出：
这些工作最终输出的都是“标签”，研究对象仍然过于集中。

块二因此改为研究回波背后的**运动本身**，输出不再是类别，而是：

1. 当前时刻的运动状态及其不确定度；
2. 未来一段时间的多种可能轨迹；
3. 这些轨迹在真实未来回波中是否得到支持；
4. 哪些运动或读出在物理上容易失败。

### 2.2 当前正式结构

`15` 已确定两个主研究点：

- **2.1 因果运动状态估计**：只看当前及过去回波，估计有效散射中心的位置、速度、活动状态和不确定度；
- **2.2 概率未来轨迹预测与回波闭环**：预测未来 0.25/0.5/1.0 s 的多种轨迹，再用未参与预测的
  真实未来 CIR 对预测评分。

这里的“结构已确定”不等于“实验已完成”。目前完成较多的是支撑这两点的旧物理资产；`15` 中的
因果滤波、概率预测和真实未来回波评分主体仍待实现。

### 2.3 第三研究点为什么仍是候选

第三点候选是：

> **读出失败的物理可预测性：能否在运行识别器之前，仅根据运动、阵列几何和雷达参数，预测某种
> 物理读出会在哪些样本上失效？**

它与 2.1/2.2 相对独立：不预测未来，也不输出类别，而是输出**失败风险及其机理边界**。但能否写成
硕士论文中的正式板块，必须由尚未运行的核心实验决定。

## 3. 已经完成并可以复用的东西

### 3.1 相对运动反演与物理边界

现有管线可以从三路距离回波重建有效散射中心的相对运动。零训练读数包括：

| 已记录结果 | 数值 |
|---|---:|
| 左挥 / 右挥方向判别 | 93.75% |
| 顺时针 / 逆时针的距离域轨迹读出 | 92.81%，$d'=2.77$ |
| 点目标仿真闭环误差 | 中位 13.5 mm，只能作为理想化下界 |
| 扩展目标仿真误差 | RMS 57.2 mm，只能作为上界侧量级 |

真实轨迹没有光学动捕真值，所以不能声称真实绝对精度就是上述任一数字。现有证据支持的是：
**相对运动读数可用，绝对位置精度未知。**

### 3.2 几何能否预测既有失败

`07` 已完成四条事先写下的几何预测：

- 3 条得到台账支持；
- 1 条强形式被证伪；
- 杂波、跨域退化等失败不由几何解释。

因此，几何可以预测一部分失败，但不能解释全部失败。这个结果是第三研究点候选的起点，不是核心实验
的最终结论。

### 3.3 读出风险的功效体检

`16` 在名义 9600 个样本中的 9593 个可用缓存样本上检查了风险分数是否值得继续研究：

- FIT 轨迹得到的**模型风险分数**具有足够的手势间动态范围；
- 排除无手部目标的 G12 后，手势因素解释的方差约为被试因素的 5–8 倍；
- RAW Viterbi 航迹在 Top 视角上明显失去区分力，只保留为敏感性对照；
- 分块检查发现“IQR 可分对数”随文件顺序从 20/55 漂到 28/55，因此该计数被移出冻结判据；
- 样本级分析必须记录“手势×被试单元内的文件顺序索引”，并检查重复序效应。

这一步只证明自变量有变化、混杂尚可控制，**没有检验风险能否预测读出失败**。

### 3.4 历史多普勒读出已经找回并锁定

原 `rotation_probe.py` 实现已经从会话记录取回，`tools/w3_c0_reproduce.py` 对三组历史结果逐位复现：

| 历史对照 | $d'$ | 准确率 | 逐被试范围 |
|---|---:|---:|---:|
| G9 顺时针 vs G10 逆时针 | 0.10 | 51.62% | 40–65% |
| G11 推 vs G12 空 | 0.01 | 49.38% | 34–65% |
| G1 vs G2 水平手势 | 0.69 | 63.50% | 30–75% |

因此 C0 不再是“根据一句文字重建的近似实现”，而是有来源、可复现、已锁定的历史读出。

### 3.5 Gate 0 的档位已经完成解析核查

Gate 0 只检查一件事：FIT 模型风险分数在已知真轨迹的仿真中，能否把物理风险从低到高排对。
它不读取多普勒结果，也不检验核心假说。

八个固定半径、只改变速度的档位已经通过闭式计算核对，对应真实缠绕率为：

> 0.00%、12.17%、34.83%、47.38%、56.55%、66.10%、81.46%、89.89%。

其中 3 个档位落在真实数据风险分数的主要区间内。**这只说明档位设计可用，不等于 Gate 0 已通过**；
完整渲染、FIT 重建和排序检验尚未运行。

## 4. 第三研究点候选到底在验证什么

### 4.1 用一个简单例子理解

雷达的相位读出类似一只量程有限、会循环归零的表。相邻两帧之间，如果目标沿某台雷达视线方向移动
超过四分之一波长：

$$
\lambda/4 = 10.27\ \text{mm},
$$

相位就可能“绕回去”，导致由相位计算的速度方向或大小出错。

因此，对每个样本可以从 W1 的 FIT 轨迹计算一个模型风险分数：

> 相邻帧径向位移超过 10.27 mm 的比例。

这个分数不是缠绕真值，只是根据重建轨迹得到的物理风险指标。

### 4.2 两层核心假说

核心实验分成两层，不能混为一个结论：

| 层次 | 问题 | 通过后允许说什么 |
|---|---|---|
| **L1：失败可预测** | 风险越高，历史 C0 多普勒读出是否越差？ | 物理风险可以预测既有读出失败 |
| **L2：缠绕归因** | 在相同运动和相同泛函下，多普勒通道是否随风险恶化，而距离域对照不恶化？ | 失败与相位缠绕机制一致，而不是“动作本身都很难” |

C0 承担 L1，因为它有历史失败锚点；C1 使用严格匹配的多普勒 / 距离域泛函承担 L2。H/V 两臂只是
预先声明的扩展验证，不能在 C 臂失败后替代主假说。

### 4.3 为什么必须先预注册

同一批数据可以选择不同风险定义、不同读出公式、不同正负号和不同分层方式。如果先看结果再挑定义，
很容易把偶然相关包装成物理规律。

所以 `17` 在核心实验前固定：

- 数据划分和留一被试评测；
- FIT 主风险与 RAW 敏感性对照；
- C0、C1、H、V 的精确公式；
- 正负号、分层、统计检验和缺档规则；
- Gate 0、L1、L2 的通过条件；
- 各种 PASS/FAIL 组合允许写出的结论。

## 6. 接下来严格按什么顺序做

1. **完成六项冻结审查**，解决实现接口、标签方向和数字口径问题；
2. **正式盖章 `17`**，此后不得因结果不好而修改核心定义；
3. **实现并运行 Gate 0**：
   - 若不过，说明 FIT 风险分数在仿真中连排序都不可靠，立即停止真实数据核心实验；
   - 若通过，才进入下一步；
4. **实现并运行核心 L1/L2 实验**；
5. **按预注册矩阵作结论**：
   - L1、L2 都通过：第三研究点具备写入硕士论文正式板块的核心证据；
   - L1 通过、L2 不通过：可以写“失败可预测”，但不能归因为相位缠绕；
   - L1 不通过：第三研究点主张不成立，不能靠 H/V 扩展结果挽救。

当前最重要的不是继续增加新点子，而是保护这条执行顺序，避免在看见核心结果后移动判据。

## 7. 必须避免的四种错误表述

1. **不能把 RAW 的 32.2% 直接称为真实缠绕率。** RAW 统计受距离 bin 跟踪抖动污染。
2. **不能把 FIT 风险分数称为真值。** FIT 强制三视角服从同一条三维轨迹，它只是模型风险分数。
3. **不能用 `08` 的 42 倍崩塌曲线直接证明 C0。** `08` 使用的是另一个多普勒速度估计与面积变体，
   不是已锁定的 C0。
4. **不能说第三研究点已经成立。** 目前只完成了功效体检、历史溯源和预注册准备，决定性的
   风险—读出关联实验尚未运行。
