5. **奇偶帧留出做模型选择**：相邻帧冗余，任意柔度都能插出来；用**连续 6 帧块**留出（`04` §1）。
6. **用 `pinv` 算可观测性方差**：把不可观测方向映射成方差 0 而非无穷，符号正好反（`07` §3）。
7. **躯干散射体 / RCS 时变解释残差**：能把残差凑到靶心（51.8 vs 49.7）但**轨迹误差 152–512 mm**，
   毁跟踪。单看残差会得出完全错误结论（`09` §2）。
8. **逐视角距离偏置**：只补 10.9%，且偏置散布以组内为主，不是标定常数（`09` §3）。
9. **各向同性散射云解释回波宽度**：展宽 20 cm 也只到 128 mm，达不到 154.5（`09` §0）。
10. **把 RAW 的 32.2% 直接当成真实缠绕率，或用 `08` 的 42× 崩塌曲线直接证明 C0**：均不成立。
    RAW 计数受整数距离 bin 跟踪抖动污染；FIT 也只是由 W1 拟合轨迹得到的模型风险分数，不是真值。
    `08` 使用的多普勒速度估计与面积预处理都不同于已锁定的 C0。当前正确做法是先过 Gate 0，
    再用 `17` 的 C0 检验失败可预测性、用匹配的 C1 多普勒/距离域对照检验缠绕归因。
11. **声称"UWB 感知性能优于 mmWave"**：假的（mmWave 分辨率 3.75 cm、λ 4 mm 都更好）。
    正确论证是"反问题低维适定 + 802.15.4z/4ab 已部署"（`06` §3）。
12. **把块二包装成"方法创新"**：多站 TOA 定位、MSTAR model-based ATR、CRLB/GDOP 布阵、
    可微 RF 数字孪生全是成熟件。正确定位是"问题设定转换 + 独有失败台账当验证集"（`06` §1–2）。
13. **对导师说"脊柱生成"**：他会听成人体骨架。说"自监督掩蔽重建预训练"。
14. **用"低风险样本占比"去判断读出切换有没有价值**：`16` 初稿据此宣布该分支作废，**已撤回**。
    低风险计数用的是 max-over-views（要求三路同时安静，最苛刻）；换成 min-over-views
    （逐视角读出的正确口径），FIT 下 <10% 风险的样本从 **0.26% 跳到 17.29%**——
    低风险层不但存在而且充裕。加上 `08` §4 的仿真交叉点约在 15–40%、实测跨度 28.0–58.1%
    正好骑在交叉区上，**多普勒在低风险档赢不赢只能由核心实验分层比较得出**。（`16` §3.3）
15. **用 RAW Viterbi 航迹当相位缠绕风险分数**：两个理由。(a) 盲/敏视角比 0.747，逐视角几何
    模式被跟踪抖动淹没；(b) **排除 G12 后 RAW 在 Top 上塌掉**——门 A 只剩 2/55，
    η²_手势/η²_被试 只有 1.5 倍（FIT 全场保持 5–8 倍）。
    **注意 (a) 只成立否定的一半**——`fit_trajectory` 强制三路服从同一条三维轨迹，
    FIT 的低比值部分是构造使然，**不能据此称 FIT 是真实缠绕率**。FIT 是"基于 W1 拟合轨迹的
    模型风险分数"，RAW 作敏感性对照，两者皆非真值。（`16` §3.1–3.2、§3.5）
16. **拿"真实数据风险区间"去论证仿真档位设计**：`17` §6.0.2 初稿据此选档，**已删除**。
    三重错误，引用任何风险区间前都要逐条自查：(a) **样本量口径**——25.8–57.3% 出自
    1920 条子样本，全量 9593 是 28.0–58.1%；(b) **聚合口径**——这两个都是 max-over-views，
    而 Gate 0 用三视角均值 $R^C$（匹配口径是 19.0–43.4%，C 臂逐样本 p5–p95 是 25.1–53.9%）；
    (c) **量纲**——那是 FIT **模型风险分数**，仿真档位的横轴是**真缠绕率**，
    对位等于预设 FIT 已标定，正是 #10/#15 禁止的事。**档位判据只能用设计自足量**
    （跨度、互不并列、间隔均匀度）。

## 7. 怎么跑

环境：`D:\D_conda\envs\pytorch\python.exe`（Python 3.9 / torch 2.7.1+cu126）。以下全部**零 GPU**。

```bash
python tools/traj_w1.py --reps 20                  # W1 主评测 -> logs/traj_w1.npz
python tools/traj_w1_obs.py                        # 解析可观测性
python tools/traj_w2_predict.py --reps 20          # 几何能否预测已记录失败（P1-P4）
python tools/w3_c0_reproduce.py [--extend]         # C0 溯源复现（17 §3.4b，三对 MATCH，~5 min）

python tools/traj_w2_readout_risk.py               # 读出风险功效体检，全量 9593（16 §3，~50 min）
python tools/traj_w2_readout_risk.py --analyze-only #   从 npz 重跑报告（秒级）
python tools/traj_w2_readout_risk.py --fig-only    #   仅从 npz 重画图
python tools/w2_calib_pulse.py                     # 脉冲模板标定 -> logs/w2_pulse.npz
python tools/w2_closed_loop.py                     # 仿真闭环精度
python tools/w2_selfcal.py                         # 几何自标定（已 FAIL，仅复现用）
python tools/w2_extended.py                        # 扩展目标扫描 + 混叠速度扫描
python tools/w2_body2.py                           # RCS taper 扫描 + 修正后的误差分解
python tools/w2_offsets.py                         # 逐视角距离偏置（已证伪）
python tools/w2_phasecentre.py                     # 逐视角相位中心（唯一正面机制）
```

核心库：`uwb_osr/trajectory.py`（维特比跟踪 + B 样条非线性反演 + 读出）、
`uwb_osr/forward.py`（数据标定的渲染器）。
