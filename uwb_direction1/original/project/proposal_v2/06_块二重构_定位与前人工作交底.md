## 1. 前人工作交底（先自曝，别等答辩被问）

| 曾被当作"创新点"的提法 | 已有工作 | 判定 |
|---|---|---|

| 可观测性分析 / 最优布阵 | **CRLB / Fisher 信息 / GDOP 最优传感器布置**，GPS 时代至今持续出论文（TOA / AOA / 混合源） | **教科书** |

**更正一条**：`02` §6 红线里写的"数据集作者点名 tracking 那句要保守引用"——已核实，
Scientific Data 原文确有 *"multiple radar sensors permitting hand tracking and trajectory
prediction"* 的表述，**可以正常引用**，该红线撤销。

### 1.1 结论：块二的价值不在"方法新"

方法层面几乎每一块都是成熟件。**块二真正的定位是：**

> **问题设定的转换（从"能不能认出来"换成"能反演出多少 / 什么反演不出 / 因此该怎么布阵与
> 设计词表"）+ 一份别人没有的验证集（四篇论文的失败台账）。**

对**学位论文**这个定位是够的——学位论文要的是系统性与完整性，不是每章 SOTA。
**要冲顶会必须再找更锋利的角度**（候选见 §4）。这句话必须说在前面，不要自我催眠。

## 2. 唯一没找到前人工作的一条

> **用可辨识性理论"事先预测"某个特定阵列下哪些手势对不可分，并在一份独立采集的失败记录
> 上验证。**

两条成熟线从来没接上：

- model-based ATR 用物理模型**认目标**，不用来预测"哪些目标认不出"；
- CRLB / GDOP 分析**位置估计精度**，不分析**类别可分性**；
- 从"定位精度界"推到"手势混淆预测"这座桥，未见对应工作。

而桥的另一头（验证集）你有，且是独立于该理论采集的——这是最难得的部分：

| 已记录的失败 | 出处 | 理论应给出的预测 |
|---|---|---|
| 对称池化下水平读数精确 0.00 | §49.2 | 反对称分量落入聚合零空间 → **应可预测** |
| G9/G10 旋向孪生吞噬 | §35 / §49.5 | 幅度均值不可分、需环路/相位信息 → **应可预测** |
| drop 族击穿（去掉一行雅可比） | §44 | 新零空间出现 → **应可预测** |
| domain 族击穿（杂波域漂移） | §44 | **不应可预测**（与几何无关） |

**最后一行是这条路线的证伪条款**：如果理论把 domain 族也"预测"出来了，说明它在拟合叙事，
必须打回。**一个能预测一切的理论没有价值。**

## 3. UWB 的优势论证（分三个对手，答辩必问）

### 3.1 vs 商用 WiFi CSI —— 压倒性，且是块二成立的技术前提

| | 商用 WiFi CSI | X4 IR-UWB |
|---|---|---|
| 带宽 / 距离分辨率 | 20–80 MHz / **1.9–7.5 m** | 1.5 GHz / **10 cm** |
| 能否直接测距 | 否（要靠 AoA、多普勒积分、跨信道拼接） | 是，ToF 是一等公民 |
| 前向模型维度 | 多径富集的高维 CSI，反问题**病态** | 每帧 3 个标量距离，反问题**低维、适定** |
| 因此可行的推断方式 | 只能学黑盒 | **可逐样本做物理推断，不需要训练数据** |

参照：WiTrack（MIT，NSDI'14）之所以能做 3D 跟踪，是因为他们**自建了扫频 1.69 GHz 的 FMCW
前端**（5.56→7.25 GHz），分辨率 8.8 cm——**那本质上就是一台 UWB 雷达**。用商用 WiFi 做手部
轨迹的 WiDraw（MobiCom'15）则要靠最多 25 个发射机的 AoA 遮挡。

**这条是最硬的优势**：不是"UWB 精度更高"，而是"**UWB 的反问题是适定的，WiFi 的不是**"。

### 3.2 vs mmWave FMCW —— 诚实说，纯感知性能上我们输

| | mmWave（77 GHz） | X4 |
|---|---|---|
| 带宽 / 距离分辨率 | 可达 4 GHz / **3.75 cm** | 1.5 GHz / 10 cm |
| 波长 | 4 mm | 34 mm |
| 多普勒灵敏度 | 高约一个数量级 | 32.2% 帧相位缠绕（`05_W2结果` §2 修正后） |

**不得声称"UWB 感知性能更好"**，答辩会被戳穿。UWB 的真实优势是三条：

1. **穿透与遮挡**：低频穿衣物、穿薄墙，mmWave 基本做不到；
2. **功耗与成本**；
3. **已部署的产业位置**：802.15.4z 的 UWB 测距芯片已在手机（iPhone 11 起）与数字车钥匙中
   规模部署；下一代 **IEEE 802.15.4ab 把雷达感知加进同一颗芯片**，imec 已发布首个合规器件，
   官方点名用例含**手势人机交互**与车内儿童遗留检测。

**正确的论证方式**：*"在已经铺开的测距基础设施上零硬件成本地长出感知能力"*，
**不是** *"UWB 感知性能更好"*。这也正好把"感知 + 测距结合"这句话落到产业事实上。

### 3.3 vs 摄像头 / 光学动捕 —— 精度必输，赢在隐私、光照、遮挡

WiTrack 当年用 VICON 做真值。**你没有真值不是原理问题，是没有那套设备**——这正是 W2
仿真闭环成为刚需的原因（`04` §6）。

## 4. "要轨迹干什么"：把价值链补全（`02` 里只列了功能）

| 理由 | 之前的写法（功能） | 补全后的价值链 |
|---|---|---|
| **域无关表示** | "轨迹不随人/位置漂移" | 成立，不改。对标 Widar3.0：CSI 域相关 → 解出物理量 BVP → 零重训跨域（跨位置 89.7 / 跨朝向 82.6 / 跨环境 92.4）。你的对应死穴：单视角 LOSO 55.31、换人占跨人新类误差 2/3、domain 族全网格击穿 |
| **扩词表的边际成本** | "能写字""能零样本定义"（两条并列） | 合并为一条：加一条命令的成本从"M 人 × N 样本"→ 论文三的 **K=5** → 轨迹模板的 **K=0**。**这是你自己论文三那条线的终点，不是新贴的卖点**。可证伪实验：用轨迹模板定义 G5–G8 四个对角（本就是 G1–G4 的组合），零样本注册对照论文三 K=5 |
| **可解释性** | "能看到这个人挥得斜 15°" ← 站不住 | 价值在于**把不可操作的诊断变成可操作的旋钮**：§34 只能告诉你"换人占 2/3 误差"，没有下一步；运动学表示把"人的差异"参数化（旋转角、速度比、幅度比），于是可以 ① 用逐用户仿射归一化去**修**（对应 Widar3.0 归一化传感器位置，你归一化个人风格），② 在失败前**预测**谁会失败。判据很硬：仿射归一化能否收回跨人差距，收不回就是负结果 |
| **计量应用** | 原来没写 | 分类器输出标签**没有量纲**；轨迹输出 cm / cm·s⁻¹ / 度 / jerk。康复评估的 ROM、平滑度（jerk）、震颤频率幅度、快速轮替的幅度递减都**必须有量纲**。**边界**：8 名健康被试 12 个手势做不了临床研究，只能做"计量能力"本身（重复性、跨人可比性、误差界），临床只写动机 |

## 5. 重构后的块二

**研究内容二：多视角 UWB 手势感知的运动反演、可辨识性与设计**

| 研究点 | 问题（不是方法） | 已有 |
|---|---|---|
| **2.1 多视角回波的运动反演与等效散射中心刻画** | 从三路 ToF 反演运动；并说清"跟的到底是什么"——12.1 cm 分辨单元内的**等效散射中心**，不是解剖学意义的手 | W1 已通（`04`）：轴选择性 4.03/0.20、方向 93.75、旋向 92.81 |
| **2.2 共面阵列的可辨识性理论与可微前向模型** | 哪些运动分量原理上不可反演？前向模型作为**反事实工具**（换构型/换站位会怎样），**不作数据增广器** | 镜像不可观测性（三雷达共面 ⇒ 距离对 z→−z 不变）、留一盲方向 \|û·n\|=0.77–0.83 |
| **2.3 失败的可预测性与阵列 / 词表设计** | 由几何**事先预测**哪些手势对会混淆、哪个视角载信息；在已有失败台账上验证；输出布阵与词表设计准则 | 验证集：§24–26 水平盲区、§35 孪生、§44 六族、§47 掩蔽天花板 |

**三点是一个东西的三个面**（正问题 / 反问题 / 边界），不是三件事拼接：

```
正问题：运动 → 多视角 ToF 回波（可微渲染）        [2.2]
反问题：回波 → 运动（轨迹重建）                   [2.1，已通]
边界  ：哪些分量不可反演 → 预测失败 / 指导布阵     [2.2 + 2.3]
```

**被砍掉的**：`02` 里 2.3 的"用前向模型合成新类样本喂注册线"作为独立卖点**删除**。
理由：那是 data augmentation，任何领域换个生成器都能写，说不出"为什么必须是 UWB、必须是
你"。若保留，只能作为 2.3 的一个附带实验，**不得作为研究点标题**。

## 6. 风险与止损（按预注册口径）

| 风险 | 触发条件 | 止损动作 |
|---|---|---|
| **失败台账里的现象大部分不是几何原因** | 拿 2–3 个已知失败试预测，预测方向与实测不符 | 2.3 退化为"部分可预测 + 边界刻画"，卖点缩水但仍可写；**不追第二次** |
| **sim2real 差距**：点散射模型拟合不了真实回波（手是 12 cm 内不可分辨的散射体） | W2 首个实验：合成 vs 真实回波的分布距离 | 前向模型只用于**相对比较**（换构型的差分），不用于绝对精度标定 |
| **似然式识别打不过判别式 inspector**（基线 OSCR 95.14 很高） | 闭集或随机划分上更低 | **判据本就不设在闭集**：只在开集 / 跨人 / 退化条件下比稳定性（那正是判别式已被证明会塌的地方：LOSO 55.31、domain 族击穿） |
| **镜像不可观测性无法在本数据上证伪**（手不可能出现在墙后） | 恒成立 | 只作构型分析与布阵建议的依据，**不作实验结果卖** |

## 7. 答辩话术（三句）

1. **和前人的区别**："多站定位、model-based ATR、GDOP 布阵都是成熟方法，我不声称方法创新。
   我做的是问题设定的转换——从'能不能认出这个手势'换成'从三路飞行时间能反演出多少运动信息、
   什么反演不出、因此阵列和词表该怎么设计'。"
2. **为什么用 UWB**："不是因为 UWB 感知性能最好——mmWave 分辨率和多普勒灵敏度都更高。是因为
   UWB 的飞行时间让反问题变成低维适定问题，可以逐样本做物理推断而不需要训练数据；而且
   802.15.4z 测距芯片已经铺在手机和车钥匙里，4ab 正把雷达感知加进同一颗芯片。"
3. **验证从哪来**："我有一份独立于该理论采集的失败记录——四篇论文的消融台账。理论必须能
   预测其中的几何性失败，同时**不能**预测其中的非几何性失败（域漂移族），后者是证伪条款。"
