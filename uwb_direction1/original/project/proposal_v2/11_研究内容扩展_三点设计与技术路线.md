## 3. 为什么必须把 CIR 与测距轨迹一起用（这一节是立论核心）

**关键关系（GPT 这一轮最重要的更正，必须写进论文）**：

$$r = g(X_{\mathrm{CIR}})$$

距离轨迹**不是独立模态**，是同一份观测经取峰后的**物理压缩摘要**。所以：

- **不许写"多模态融合"**——一问就穿。正确说法是"**原始回波表征 + 物理几何摘要**"。
- **正式后果（数据处理不等式）**：对任意运动量 $z$，$I(z;X)\ \ge\ I(z;r)$，**等号成立当且仅当取峰
  是 $z$ 的充分统计量**。

于是"把两样东西缝起来"不是工程拼接，而是一个**可判决的科学问题**：

> **维特比取峰把每帧每视角的 189 个数压成 1 个（17010 → 90）。这个压缩是不是充分统计量？**

不是，则 CIR 条件必然收窄后验，收窄多少就是深度模型的**定量贡献**；是，则得到一条同样可发表的
**负结果**——物理反演已经榨干了信息。**两个方向都能交付，这是这条立论最好的性质。**

已知这份数据里被取峰扔掉的东西不是噪声：回波 −6 dB 宽度 154.5 mm（宽于 10 cm 分辨率，前臂在内）、
多峰结构、幅度衰减、逐视角散射中心偏移。

**同构先例**：旋向不可分曾被归因"信息不存在"，后证明是**读出通道**问题（相位缠绕 32.2% 帧，仿真里
d′ 崩塌 42×，改距离域后单调上升）。这次是同一方法学发现的第二个实例：**把"不可辨识"与"读不出来"
分开。**

## 4. 被测量的定义（先定死，否则全盘无法自洽）

**块二的被测量是"雷达可观测的等效散射中心运动"，不是"解剖学手腕轨迹"。**

这**不是降低标准，是命名正确的被测量**：`09` 已经测出三个视角的等效散射中心各自朝**自己的**雷达
偏 74.5–80.5 mm（L −74.5 / R +80.5 / T 深度 −74.5，残差 47.4→36.8，留出帧改善 19.3%）。
**即根本不存在一个被三路共同测量的解剖学点。**

因此**不需要引入带 MoCap 的 UWB 数据集**。精度主张继续走 `00` §4.3 的三数纪律：
**13.5 mm 中位（仿真闭环下界）/ 57.2 mm RMS（扩展目标上界侧）/ 真实精度不可得**。仿真闭环里真值
按构造存在，方法学的正确性在那里验；真实数据上只报免真值指标（§5）。

## 5. 三个研究点（综合定稿）

### 5.1 研究点 2.1｜散射中心感知的概率化 UWB 观测模型

**不是** UDP 的 MDS 模块的对应物（见 §7 的错类比警告），**是**把读出步骤从"取一个数"升级成
"给一个似然函数"。

| 项 | 内容 |
|---|---|
| 输出物 | 逐视角逐帧的**距离似然** $\ell_v^t(\rho)$（不是一个数）；多峰标记；视角散射中心偏移；**3×3 灵敏度矩阵** |
| 头条数字 | **距离似然多峰帧占比**，以及**多峰率对台账已记录失败的预测力**（HV3 旋向 57.5%、垂直 6/8 折、丢 Top 垂直塌 30.9 分） |
| 方法 | 现有维特比置信度 → 似然化；相位中心模型（已标定）进观测模型；解析雅可比 |
| 证伪条款 | 多峰率对已记录失败**没有**预测力 → 2.1 缩为观测模型工程，不当科学发现报 |
| 成本 | 1–1.5 周，零 GPU |

**3×3 灵敏度矩阵**（按标称几何 L(−0.55,0,0)、T(0,0.55,0)、R(0.55,0,0)、目标 (0,0,0.45) 复算，
与 `00` §4.4 一致）：

| | ∂ρ/∂x（水平） | ∂ρ/∂y（垂直） | ∂ρ/∂z（深度） |
|---|---|---|---|
| **Left** | **+0.774** | **0** | +0.633 |
| **Top** | **0** | −0.774 | +0.633 |
| **Right** | **−0.774** | **0** | +0.633 |

**三个精确零**。这张表在 §5.3 里变成生成器的验收标准。
**概念精度（写作必须说清）**：此矩阵**满秩**——三路原始视角在标称点上把三个自由度都测到了。
那些"严格为 0 的盲方向"（`mean(L,T,R)` 对水平、`R−L` 对垂直）是**池化读出**造成的，不是物理盲。

### 5.2 研究点 2.2｜CIR 条件的生成式运动反演，与"取峰是否充分统计量"的判决

| 项 | 内容 |
|---|---|
| 输出物 | $p(\text{运动程序}\mid\text{三视角回波})$ 的样本集；充分统计量判决 |
| 头条数字 | ① **逐自由度后验体积收缩** $\log\det\Sigma_R-\log\det\Sigma_C$（nat）；② 一致性–多样性帕累托曲线；③ 后验主方向与解析零空间的余弦 |
| 证伪条款 | 收缩 ≈ 0 → **取峰是充分统计量**（负结果，照样发） |
| 成本 | 2–3 周 |

**两个条件分支**（实验主体）：**分支 R** 条件只有 3×90 峰值距离；**分支 C** 条件是整张 3×90×189
经 `SharedDualPathEncoder` + `CrossViewFusion`（去掉两个 head）。

#### 扩散的门控（**这一条必须先过，别默认扩散一定合理**）

§5.1 的矩阵满秩 ⇒ **三视角齐全时逐帧三边测距是恰定的，后验一般不多模态** ⇒ 扩散在标准条件下
**不比条件流/概率回归更有理由**。扩散真正占优的场景恰好是：

- **缺视角**（台账：丢 Top 垂直塌 30.9 分）
- **缺时段 / 遮挡**
- **多散射中心、似然多峰**（由 2.1 量出占比）
- **深度符号分支**（`00` §4.1：仅 93% 样本 z>0，**7% 解到墙的错误一侧**）
- **回波生成**（一条轨迹对应多种散射实现，见 5.3）

> **结论：扩散该被放在台账已记录失败的地方，不是当通用增强。** 这既让方法选择有理有据，又把块二
> 与块一的失败台账接上，而输出物（后验/回波）仍然不是标签。

#### 实现细节对标 Ultra Diffusion Poser（CVPR 2026, arXiv 2606.02153）

它是最接近的同构工作（稀疏 IMU + UWB 测距 + 扩散），机器几乎一样、观测量不同。**可搬四条**：

1. **"别拿标量当特征喂，先解成几何对象再当条件"**。它的立论原话是"UWB 距离此前只被当作额外的输入
   特征，忽略了它们施加的物理约束"。**我们的维特比 + 三边测距轨迹就是这个角色**：闭式几何摘要当
   条件，而非竞争输出。它的消融（TotalCapture, JPE cm）证明该分支有独立价值：
   去布局+去引导 4.39 / 只去布局 4.03 / 只去引导 4.05 / 完整 **3.76**（布局贡献 ≈ 引导贡献）。
2. **引导写法**：$\epsilon=\sum\|\hat d(\hat M_0)-d\|^2$，$\tilde\mu_t\leftarrow\mu_t-\lambda\Sigma_t\nabla\epsilon$。
   作用在**去噪估计 $\hat M_0$** 上；梯度过 in-the-loop 可微观测算子（我们是 $A(C)_v[t]$ +
   现成 `trajectory.py:jac`）；步长用 **$\lambda\Sigma_t$**（噪声协方差缩放＝自带退火）。
3. **训练时不放物理项，物理只在采样时出现**（明说不像 DiffusionPoser 那样加 FK 损失）。
   **这正是先验/似然分离的前提，也是"先验占比审计"能成立的前提。**
4. **歧义不做决定，候选一起喂**。它把 MDS 布局与其镜像 $(P_{\text{SPL}},\bar P_{\text{SPL}})$ 都放进
   条件。**我们的对应物是深度符号分支**：z>0 与 z<0 都当条件候选，不在预处理阶段硬选（治那 7%）。
   另外它"把根平移梯度置零，因为 UWB 只提供体内相对约束"——翻译版是**把逐视角相位中心偏移当
   nuisance 参数 profile 掉，别让 guidance 去硬顶系统偏置**。

**规模定心丸**：它的去噪器是 **LSTM**，去噪空间 $M\in\mathbb R^{N\times147}$，AMASS 训练。我们 90 维
控制点空间（`bspline_basis(T=90,K=30)`）容量富余。
*（GPT 转述的"Transformer 去噪器 JPE +27%"未经核实，不要引用；架构结论不依赖该数字。）*

**必须当警告读的**：其 Table 3 显示在 UIP-DB（真实 UWB 误差 **17.5 cm**）上 **UDP 反而输给 UIP**，
合成噪声越小性能单调越好；limitations 原话 *"this makes it sensitive to very noisy UWB
measurements"*。**我们的残差 47–50 mm + 75 mm 逐视角偏置正落在该区间**，λ 过大必然伤人。
→ 便宜且有先例背书的实验：**在已标定仿真器里扫"观测噪声 × 引导强度"相图**。

#### 防自欺三条纪律

① **LOSO 8 折**，扩散先验只见训练折被试的轨迹；② 起点/尺度归一化（先验只学运动形状统计，不学
绝对位置——绝对位置本身带 75 mm 偏置与 3.7% 尺度不确定性）；③ **置换检验**：CIR 条件在 batch 内
打乱，信息增益必须消失。

#### 附带的先验占比审计（γ 谱）

因先验与似然分离，可逐方向削弱似然、看后验均值移动多少，得 $\gamma_d\in[0,1]$（数据驱动份额）。
**解析可观测性给出 γ 应有的形状**：水平/深度 γ≈1；池化后的水平与 `R−L` 下的垂直（两个严格零）
γ≈0；丢 Top 后垂直 γ 应塌向 0。输出**可测性谱热图** + 一条方法学规矩：**γ≈0 的方向上的输出不得
作为测量结果报告。**

### 5.3 研究点 2.3｜散射感知可微渲染器与回波引导的双向闭环

| 项 | 内容 |
|---|---|
| 输出物 | 轨迹 → 三视角 CIR 的生成器；闭环反演器；**可编程 UWB 虚拟传感器**（软件交付物） |
| 头条数字 | ① **B0/B1/B2 三级阶梯**下对角零样本的分布距离；② **错轨迹负对照的 ROC**；③ 灵敏度矩阵体检表（编辑各向异性）；④ 分类器双样本 AUC → 0.5 |
| 硬地板 | **杂波滤波器复现误差 13.8%**（α=0.80）——任何物理骨架与真实回波的匹配上限 |
| 成本 | 4–6 周（含 `render` 的 torch 化） |

#### 结构

$$X = \underbrace{F_{\text{physics}}(p,\ \delta_v,\ G)}_{\text{峰应该出现在哪}} + \underbrace{D_{\text{gen}}(p,\ z_s,\ G)}_{\text{峰长什么样、怎么展宽、周围有什么}}$$

$z_s$ **必须物理参数化**（逐视角散射中心偏移 $\delta_v$、宽度、幅度），**不许自由学**——自由学的
$z_s$ 一定学成被试身份（论文一那边 Raw 输入的优势就是泄漏：跨人 CR 反赢 +11.3）。
**必须加对照：用 `probe_attributes.py` 探 $z_m$ 能否解出被试身份；高于随机即解耦失败。**

理论靠山：多视角 content-style 可识别性（同一手势三视角**共享运动、不共享散射**）。但定理要求
style 与 content 独立，而 $\delta_v$ 依赖姿态 → 所以把 $\delta_v$ 交给已标定的物理模型承担，
$z_s$ 只携带残下的波形形状。**无监督自由解耦本身不可识别（Locatello et al. ICML 2019），不要许诺。**

#### 对角零样本实验必须带三级基线（否则功劳错配，一问就穿）

物理渲染器是轨迹的确定性函数，**它压根不在乎见过没见过对角**；而 `04` 已证明轨迹层面组合性成立
（对角 x/y 摆幅比 G5 0.69 / G6 0.83 / G7 1.00 / G8 0.66，落在两组正交之间）。
`config.py:90` 原文：*"G5..G8 are the two-axis combinations of the four single-axis swipes G1..G4"*。

| 基线 | 内容 | 作用 |
|---|---|---|
| **B0** | 纯物理渲染器（零学习）渲合成对角轨迹 | 白送的部分有多少 |
| **B1** | 物理 + **只在 G1–G4 上训**的残差模型 | **真正的零样本主张** |
| **B2** | 物理 + 全数据（含 G5–G8）训的残差模型 | 天花板 |

主张收窄为：**B1 关掉 B0→B2 之间的大部分差距**（散射码从单轴原语外推到组合运动）。窄，但真。

#### 编辑实验只做有真实目标的四族

| 编辑 | 真实目标 | 可证伪 |
|---|---|---|
| 方向反转（x 取反） | G1 ⇄ G2 | ✅ |
| 旋向反转 | G9 ⇄ G10（d′=2.771 有基线） | ✅ |
| 正交组合 | G1–G4 → G5–G8 | ✅ |
| 空运动程序 | G12 Empty gesture | ✅ |
| 幅度/速度缩放 | **无真实目标** | ❌ 只能定性，或用类内摆幅分布做弱检验 |

#### 灵敏度矩阵体检表（生成器可控性的免真值验收标准）

对生成器做数值微分，测出实测 3×3 矩阵与 §5.1 解析表比：

- 编辑**垂直** → 生成的 **Left/Right 回波必须几乎不动**（灵敏度严格 0）。动了 = 在编。
- 编辑**水平** → **Top 必须不动**，L 与 R **等幅反号**。
- 编辑**深度** → 三路**同向同幅**（+0.633）。

#### 闭环必须带负对照（**三次强调，这是最容易漏掉的致命项**）

生成器若在全数据上训过，几乎能重生成任何回波，"重生成检验"就没有鉴别力。必须：① LOSO 折隔离；
② **故意喂错轨迹**（打乱配对、镜像、时间反转）验证分数确实变差；③ 报对/错轨迹的 **ROC**。

## 7. 文献边界与写作红线

**不能声称的**：

- ❌ "首次 UWB + diffusion" —— **Ultra Diffusion Poser（CVPR 2026）已占**。
- ❌ "首次由运动生成 RF" —— RF Genesis、WaveVerse、mmWEAVER 已占（均依赖 3D 网格 + 光追 + 毫米波）。
- ❌ 拿几十毫米的量级去比 Multi-Static UWB Passive Tracking 的 **<30 cm RMSE**——那是**行人整体**
  跟踪、**有 MoCap 真值**；我们是**手部**、**无真值**。它用来划边界，不当性能对手。
- ❌ "多模态融合"（见 §3：$r=g(X)$）。
- ❌ 标题里用"世界模型"（`00` §5.13 同类话术坑：他会听成别的）。正文用"运动—回波双向生成模型 /
  可编程 UWB 虚拟传感器"，口头可说但要立刻落到"输入运动出回波、输入回波出运动"。
- ❌ "方法创新"（沿用 `06`）：多站 TOA 定位、MSTAR、CRLB/GDOP 布阵都是成熟件。口径是
  "**问题设定转换 + 一份独有的验证集**"。

**可以主张、但仍需正式查新的差异点（四条同时成立才算）**：

> **无穿戴的被动 IR-UWB 回波**（不是佩戴标签间测距）**+ 整张 CIR**（不是标量距离）**+ 无光学真值**
> **+ 把不可辨识性与散射解耦当交付物**（UDP 自己承认不处理零空间与可辨识性、无贝叶斯不确定性建模、
> 固定六传感器佩戴配置）。

**错类比警告（别写进开题）**：**我们没有 MDS 可移植。** UDP 的 MDS 是从 6 个节点的 15 个成对距离做
闭式嵌入（超定，带反射歧义）；我们是 3 个距离对 1 个点（**恰定，无嵌入问题，无 MDS 反射歧义**）。
能移植的只有**原则**（闭式几何摘要当条件）与**做法**（歧义分支保留成候选）。把 2.1 说成"MDS 模块的
对应物"是错的，会被一句话问穿。

## 8. 答辩话术（三句）

1. **切线**："三篇论文回答'认得对不对'，输出是标签。块二研究的是**回波与运动之间的生成关系**——
   输入回波恢复可编辑的运动程序，输入运动生成三视角回波。**评价指标里没有一个是分类准确率。**"
2. **为什么不是又一个动捕**："现有物理反演每帧每视角只用了一个数，一张距离像有一万七千个数。
   我们要判决的是**这个压缩到底丢没丢信息**；同时把估不出来的部分显式画出来并审计它——三台雷达的
   几何决定了某些读出方向上灵敏度严格为零。"
3. **被测量**："我们测的是**雷达可观测的等效散射中心运动**，不是解剖学手腕轨迹——因为我们自己测出
   三个视角各自朝自己的雷达偏 75–80 毫米，**根本不存在一个被三路共同测量的解剖学点**。精度按
   下界/上界侧/不可得三个数一起报。"
