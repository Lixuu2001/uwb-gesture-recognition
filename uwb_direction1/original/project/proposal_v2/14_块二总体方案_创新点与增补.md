## 1. 一句话定位与最终形态

> **块二 = 运动—回波的双向生成与可测量性。** 反演方向：`p(运动程序 | 三视角回波)`，带不确定性；
> 生成方向：轨迹 → 三视角 CIR 的**可编程 UWB 虚拟传感器**；贯穿两向的是**可测性审计**——哪些运动
> 方向在这套几何下原则上测不到、哪些是读出通道读不出来、哪些必须靠数据先验补。

**红线（`11` §1）**：三个研究点的头条数字里**不出现分类准确率**；输出物、指标量纲、失败方式三条
必须与块一同时不同。

**与导师判据的对齐自检**：

| | 输出物 | 指标量纲 | 失败方式 |
|---|---|---|---|
| 块一（三篇论文） | 标签 / 拒识判据 / 协议 | 准确率、开集指标 | 认错类 |
| 2.1 | 逐帧距离**似然函数** + 灵敏度矩阵 | 多峰帧占比、预测力（Spearman/AUC 对失败台账） | 多峰率预测不了失败 |
| 2.2 | **后验样本集** + 充分统计量判决 + γ 谱 | **nat**（信息增益）、覆盖率、余弦 | 收缩为零（本身是可发表负结果） |
| 2.3 | **虚拟传感器**（软件）+ 功劳分账阶梯 | 分布距离、判别器 AUC→0.5、闭环 ROC | 错轨迹也过闭环（闭环无鉴别力） |

三行两两不同、且每行都与块一不同。**这张表可以直接放开题答问。**

## 2. 三个研究点 = 三个创新点（开题可用的表述 + 验收数字）

### 创新点一（研究点 2.1）｜散射中心感知的概率化 UWB 观测模型，用失败台账当验证集

**表述**：把逐帧逐视角的读出从"取一个距离数"升级为"给出一条距离似然 $\ell_v^t(\rho)$"，显式建模
多峰、逐视角散射中心偏移（已标定 L −74.5 / R +80.5 / T 深度 −74.5 mm）与 3×3 灵敏度矩阵；
并用块一四篇论文积累的**失败台账**作独立验证集，检验"似然多峰率"对已记录失败的预测力。

**新在哪**：(a) 现有 UWB 手势工作把取峰当黑箱预处理，不给似然、不建模散射中心；(b) 方法学上，
用一份**独立于理论采集的失败台账**当验证集——这份台账全领域没有第二份（`06` 定位：问题设定
转换 + 独有验证集，不是方法创新）。

**预期效果（验收数字）**：
- 3×3 灵敏度表：**3 个严格零 + 满秩**，解析与数值差 5.3e-11（**已完成**，`13` §1）。
- 多峰帧占比 X%（待测）；预注册阈：对台账三条失败（HV3 旋向 57.5%、垂直 6/8 折、丢 Top 塌
  30.9 分）的预测力 **|Spearman|>0.5 且 p<0.05，或 AUC>0.65**。
- 证伪条款：不达阈 → 2.1 降级为观测模型工程（仍是 2.2 的必要前置），不当科学发现报。

### 创新点二（研究点 2.2）｜"取峰是否充分统计量"的判决 + γ 可测性谱

**表述**：维特比取峰把每帧每视角 189 个数压成 1 个（17010→90）。构造 CIR 条件的生成式后验反演器
（扩散/流先验 + 物理引导，分支 R=峰值距离 vs 分支 C=整张 CIR），以逐自由度后验体积收缩
$\log\det\Sigma_R-\log\det\Sigma_C$（nat）量化整张距离像相对峰值摘要的信息增益；同时输出 γ 可测性谱
与一条方法学规矩：**γ≈0 的方向上的输出不得作为测量结果报告**。

**新在哪**：(a) 把"不可辨识"与"读不出来"分开的方法学（旋向案例已产出过一次发现，这是第二次
系统应用）；(b) 数据处理不等式让它成为**可判决问题**——收缩>0 是深度模型的定量贡献，≈0 是
"物理反演已榨干信息"的负结果，**两个方向都可交付**；(c) 对标 UDP 明确不做的零空间/贝叶斯
不确定性（`11` §7 查新四条件）。

**预期效果（验收数字）**：
- 收缩量 ΔlogdetΣ（nat）：>0 或 ≈0 都收官；**置换检验必须归零**（CIR 条件 batch 内打乱）。
- 仿真校准：SBC 秩统计均匀 + 期望覆盖偏差 <5%（见 §5.3，升级自 `12` 的"90% 区间含真值 ≈90%"）。
- 主图：12 手势轨迹带，**带宽沿冲程被调制、两端最胖**（P2'，`13` §1.4），肉眼可验。
- 一致性：后验样本重投影残差中位落在 **47.4–49.7 mm**；真实数据上后验样本的方向/旋向读数与
  W1 零训练基线（93.75% / 92.81%）一致（内部验证，不当头条）。
- γ 谱热图：解析预言——水平/深度 γ≈1；两个严格零方向 γ≈0；丢 Top 后垂直 γ 塌向 0。

### 创新点三（研究点 2.3）｜散射感知可微渲染器 + "功劳分账"验证方法学

**表述**：$X = F_{\text{physics}}(p,\delta_v,G) + D_{\text{gen}}(p,z_s,G)$，$z_s$ 物理参数化（逐视角
偏移 + **逐视角宽度**（`13` §2.4 实证）+ 幅度），不许自由学；以
**B0（纯物理）→ B0.5（结构化随机，§5.2 新增）→ B1（只在 G1–G4 训残差）→ B2（全数据）**
四级阶梯把每一层的贡献分开计量；四族有真值编辑 + 灵敏度体检 + 闭环负对照。

**新在哪**：(a) 相对 RF Genesis / WaveVerse / mmWEAVER（都依赖 3D 网格 + 光追 + 毫米波），这是
无穿戴被动 IR-UWB + 整张 CIR + 无光学真值场景的可微渲染器（**仍需正式查新**，`11` §7 四条件）；
(b) **功劳分账阶梯本身是方法学贡献**——阶段 0 已实证其必要性：模板宽度标定缺陷占缺口 65%，
不先修就训生成模型，生成模型会冒领这份功劳（`13` §2.2）；(c) $z_s$ 的可识别性纪律
（身份探针对照 + Locatello 不可识别性引用，不许诺无监督解耦）。

**预期效果（验收数字）**：
- 修模板：‖标准化均值差‖₂ **25.7 → 9.0**（**已实证**）；B0.5 目标 ≤5；B1 关掉 B0.5→B2 的大部分差距。
- 判别器双样本 AUC：**1.000 → 0.5–0.6**。
- 灵敏度体检：生成器数值微分复现 3 个严格零；±0.774 / +0.633 在容差内；编辑垂直时 L/R 不动。
- 闭环负对照：对/错轨迹（打乱配对、镜像、时间反转）ROC **AUC>0.8**。
- 硬地板写进论文：杂波滤波器复现误差 **13.8%**，任何物理骨架匹配真实回波的上限。

## 5. 增补（本文件新增，待批准后并入 `12`）

### 5.1 前向模型修复：从"包络展宽补丁"升级为"物理正确的非相干渲染 + 单一延展散射体模型"

`13` 的修法（包络展宽到 25 bins）是**对症**的；这里升级为**对因**的，一并治掉 `13` §2.4 的两类
剩余残差（伪峰数、逐视角宽度不对称）。

**(a) 标定侧**：`w2_calib_pulse.py` 的相干平均改为/增加**包络域（非相干）平均**，并**逐视角**出
模板——直接得到 L/T/R 各自的实测宽度（21.5 / 26.0 / 26.7 bins），而不是一个全局窄核。
相干平均版保留（它是载波相位的正确估计器），两者各司其职。

**(b) 渲染侧**：`forward.render` 增加包络域合成模式——多散射贡献在**幅度/功率域**求和后单载波
重调制，而不是复数相干求和。机制依据：`13` §2.3 已实证相干求和把 1.2λ 间距的散射体做**窄**
（散斑干涉，42–51 mm），这正是渲染器伪峰 5–16 个 vs 真实 1.6–2.5 个的来源。非相干合成
预期同时治宽度和伪峰。

**(c) 统一模型（假说 H，可证伪）**：用**一个带方向的延展散射体**（线段/长椭球：长度 ℓ、方向
ω、等效半径 r₀，共 4 参数）同时解释两套已测的逐视角不对称：
- 偏移：每台雷达看到朝向它的最近表面 → δ_v ≈ −(沿 û_v 的延展)/2，自动给出 L−/R+/T深度− 的符号结构；
- 宽度：w_v ≈ 脉冲宽度 ⊛ 沿 û_v 的投影延展 → Left 窄（136 mm）vs Top/Right 宽（165/170 mm）
  对应前臂轴向与三条视线的夹角不同。

6 个观测量（3 偏移 + 3 宽度）对 4 个参数，**超定可检验**。拟合一致 → z_s 从"3 偏移 + 3 宽度
6 个自由参数"缩到 4 个物理参数，可识别性更强、身份泄漏面更小；拟合不一致 → 退回 `13` 修改 4
的逐视角自由宽度，无损失。

**(d) 白送的可证伪预言**：线段方向随姿态变 → **逐视角宽度应当在手势内随时间被调制**（尤其
G9/G10 旋转类，前臂方向周期变化）。真实数据逐帧测 −6 dB 宽度即可验，零训练。成立的话这是
2.1/2.3 之间一张新的主图级结果（"宽度的姿态调制被物理模型预测"）。

**成本**：(a)(b) 半天–1 天；(c)(d) 1–2 天。全零 GPU。

### 5.2 阶梯里插一级 B0.5：结构化随机渲染器（防止扩散冒领结构化残差的功劳)

阶段 0 的教训（模板缺陷占 65%）说明：**凡是能用几个物理参数关掉的差距，都不该让深度模型去关**。
`13` §2.4 的剩余残差恰好高度结构化（伪峰数、逐视角宽度），所以在 B0 与 B1 之间插一级：

> **B0.5 = 非相干渲染（§5.1）+ 线段模型逐视角宽度/偏移 + 实测逐视角增益/噪声 + 乘性散斑纹理
> （相关长度 ≈ 分辨率，参数从 G1–G4 拟合）。零深度学习。**

作用：(i) B1 的残差扩散必须**赢过 B0.5** 才能主张学习贡献——这是诚实的对照；(ii) 若 B0.5 已把
‖effect‖₂ 压到很小、判别器 AUC 明显掉，则"生成缺口主要是结构化物理，不是需要大模型的纹理"
本身就是一条结论，阶段 4 的扩散规模可以砍小。**成本 2–3 天，放阶段 1c。**

### 5.3 后验校准的严谨化：SBC + 期望覆盖（治"无真值"这个最大软肋）

`12` 阶段 3 的"90% 区间含真值 ≈90%"升级为标准协议，正好适配无真值场景（校准全在已标定仿真器
里做，真实数据只报免真值指标）：

- **SBC**（Talts et al. 2018）：θ 从先验采、渲染成回波、跑后验采样器、真值在后验样本中的秩
  应均匀分布。秩直方图 U 形 = 后验过窄，倒 U = 过宽，偏斜 = 有偏。
- **期望覆盖/TARP**（Lemos et al. 2023）：报覆盖曲线，验收阈 |实际覆盖 − 名义| < 5%。
- **γ 谱的定义标准化**：主定义改为逐方向后验收缩 $\gamma_d = 1-\sigma^2_{\text{post},d}/\sigma^2_{\text{prior},d}$
  （标准贝叶斯工作流量，便宜、可比）；`12` 的"削弱似然看均值移动"版保留作稳健性检查。
  两版结论应一致，不一致本身要报。

**成本 1–2 天（复用 `w2_closed_loop.py` 的仿真闭环设施）。** 写作收益大：评审问"没真值凭什么信
你的后验"，SBC+覆盖曲线是标准答案。

### 5.4 被试物理参数的少样本自校准（把身份泄漏风险翻成一条特性，并呼应论文三）

z_s 最大的风险是学成被试身份（`12` 4b）。线段模型把它翻过来：逐被试差异显式化为 **2–4 个可
解释的物理参数**（手/臂尺寸、习惯姿态角）。LOSO 下对留出被试：用**少量无标签帧**现场拟合这
几个参数（纯最小二乘，无梯度训练），其余全部冻结。

- 这不是泄漏：参数低维、物理可解释、可审计（拟出来的尺寸应落在人手/前臂的解剖范围）；
- 身份探针对照照做：探 z_s 剩余部分（波形纹理），高于随机即解耦失败（不变）；
- **叙事收益**：块一论文三是"少样本注册新类别"，块二这里是"少样本标定新被试的物理参数"——
  同一个'few-shot 适配'思想在标签空间与物理参数空间各用一次，答辩时是漂亮的呼应而非重复
  （输出物完全不同）。

**成本**：依附在阶段 4b 上，+1–2 天。
