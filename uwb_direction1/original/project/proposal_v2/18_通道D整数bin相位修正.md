## 1. 为什么必须改（不改会制造假 L2 PASS）

L2 的全部论证是一个**匹配对照**：通道 D 与 R 只差"径向速度从哪来"，
所以「风险↑ → D 塌、R 不塌」才能把原因锁定在**相位缠绕**上。

这条推理有一个未写出的前提：**低于缠绕门限 λ/4 = 10.275 mm 时，D 必须是好的。**
否则"D 塌"就有第二个可能来源。

合成回波实测显示该前提**当前不成立**：

| 量 | 值 |
|---|---|
| 距离 bin 间隔 | 6.35 mm |
| 缠绕门限 λ/4 | 10.275 mm/帧 |
| 合成手势最大径向速度 | 0.1335 m/s（上限 0.2055 m/s） |
| **真缠绕率** | **0.00%** |
| bin 静止帧上 corr($v^D$, $v_{\text{true}}$) | −0.761 / −0.944 / −0.963 |
| **全部帧上** corr($v^D$, $v_{\text{true}}$) | **+0.007 / −0.042 / −0.011** |

即：**在完全合理的速度区间内、零缠绕的情况下，D 已经被 bin 切换破坏。**

机理是确定性的，不是噪声。设脉冲模板的解析信号为 $a(u)e^{i2\pi f_s u}$
（$f_s = 0.3203$ 周/样本，实测值，见 `uwb_osr/forward.py` 文件头与 `00` §4.1），
第 $t$ 帧的回波是模板延迟 $n_t=\rho_t/\Delta r$ 样本，在跟踪 bin $b_t$ 处读出：

$$\arg z_t(b_t) = 2\pi f_s\,(b_t-n_t) + \arg a(b_t-n_t)$$

于是帧间相位差为

$$\Delta\phi = 2\pi f_s\,(\Delta b - \Delta n)$$

其中 $-2\pi f_s\Delta n$ 才是运动项。**多出来的 $2\pi f_s\Delta b$ 是读出坐标自己变化产生的载波相位**：
每跨一个整数 bin 就凭空注入 $2\pi\times0.3203 = 2.012$ rad，
折算成速度误差约 $\frac{\lambda}{4\pi\Delta t}\times2.012 = 0.132$ m/s——
与整个手势的真实速度同量级。

**这为什么是 L2 的致命混杂**：跨 bin 频率随径向速度上升，
而风险分数（每帧 $|\Delta\rho|>\lambda/4$ 的比例）同样随径向速度上升。
两者共线。因此即便真实数据给出「风险↑ → D 差、R 不变」，
也无法区分它来自**相位缠绕**还是来自**跨 bin 次数增多**——
而后者与 λ/4 门限毫无关系。不修则 L2 的 PASS 不可解释。

## 2. 改动前后的条款原文

### 改动前（`17` §3.1，逐字）

> 设 $b_v(t)$ 为 `viterbi_track` 给出的跟踪 bin，$z_v(t)$ 为该帧解析信号在该 bin 的复值
> （`_analytic` 已有实现）。帧间相位增量取主值：
>
> $$\Delta\phi_v(t)=\arg\big(z_v(t{+}1)\,\overline{z_v(t)}\big)\in(-\pi,\pi]$$
> $$v^D_v(t)=\frac{\lambda}{4\pi\,\Delta t}\,\Delta\phi_v(t)$$

### 改动后（本文件冻结）

在取相位差**之前**，先把读出坐标自身的载波相位旋掉：

$$\boxed{\ \tilde z_v(t) = z_v(t)\,e^{-i\,2\pi f_s\,b_v(t)},\qquad
f_s = 0.3203\ \text{周/样本（实测，不可调）}\ }$$

$$\Delta\phi_v(t)=\arg\big(\tilde z_v(t{+}1)\,\overline{\tilde z_v(t)}\big)\in(-\pi,\pi],
\qquad v^D_v(t)=\frac{\lambda}{4\pi\,\Delta t}\,\Delta\phi_v(t)$$

**其余一律不变**：仍在整数 bin 上读相位（`17` §7 的复核项）、仍取主值、
仍用同一个 $\frac{\lambda}{4\pi\Delta t}$ 系数、池化与泛函（§3.3/§3.4）一字不改、
通道 R 一字不改。$b_v(t)\equiv 0$ 时本式退化为 `17` §3.1 原式。

**关键性质**：修正项是**确定性的、与运动无关的**坐标项。
它不会掩盖缠绕——缠绕发生在修正**之后**的主值取法上，
即真实运动本身超过 $\lambda/(4\Delta t)$ 时仍然折叠，这正是 L2 要测的东西。

## 3. 明确**不**改的两项

1. **相位符号约定**。`17` §3.1 的注写 $\phi=4\pi\rho/\lambda$，实际信号是 $-4\pi\rho/\lambda$
   （延迟使相位滞后）。**公式仍逐字照抄，不动。** 已证明它不影响任何判决：
   C1 面积在两分量同时反号下精确不变；H/V 的 $\sigma$ 由估计集估计，全局反号被吸收，
   `correct`/`margin` 不变。受影响的只有 `17` §3.5 几何期望表对 D 通道的预期符号，
   而该表明文"不作为判据"。
2. **极端速度档**。Gate 0 的 level 7（90 帧 8 圈）局部反转仍按 `00` §3.1 记为边界，
   **不作为阻塞项**，也不再讨论——真实手势不在那个区间。
   本次改的是**低速端的整数 bin 格子边界**，与那件事无关。

## 5. 新增证伪对照：通道 D_unwrapped（对 `17` §6.2 的第二处修改）

去旋只解决了 bin 边界。**它没有解决 D 与 R 之间除缠绕以外的其它差异**：
一个是整数 bin 上的复相位，另一个是包络峰的亚 bin 距离，两者在
相位失真、杂波滤波的影响、散射中心切换上都不同。这些若随运动增强，
同样能产生「D 差、R 不变」而与 λ/4 毫无关系——仍是假 L2 PASS。

**冻结新增第三个通道**，从**同一份去旋后的相位**生成：

$$\boxed{\ \Delta\phi^{\text{unw}}_v(t)=\Delta\phi_v(t)+2\pi k_v(t),\qquad
k_v(t)=\Big\lfloor\tfrac{\Delta\phi^{\exp}_v(t)-\Delta\phi_v(t)}{2\pi}\Big\rceil,\quad
\Delta\phi^{\exp}_v(t)=-2\pi f_s\frac{r_v(t{+}1)-r_v(t)}{\Delta r}\ }$$

其中 $r_v$ 是 RAW Viterbi 距离航迹，$\Delta r=6.35$ mm。$v^{D_{\text{unw}}}$ 用与 §2 相同的系数。

**分支必须由 RAW 距离选，不得用 `np.unwrap`**：连续性解缠假设相邻增量都在 $\pm\pi$ 内，
而那正是被检验的对象——用它等于先假设答案。距离航迹只挑整数 $k$，数值仍来自相位。

$D_{\text{unwrapped}}$ 与 $D_{\text{wrapped}}$ **共享全部上述病理，只差 $2\pi$ 模糊**。
因此三路对照才能分离：

| 结果 | 允许的解释 |
|---|---|
| $D_{\text{wrapped}}$ 变差，$D_{\text{unwrapped}}$ 与 R 稳定 | **支持相位缠绕**，§6.2 归因成立 |
| $D_{\text{wrapped}}$ 与 $D_{\text{unwrapped}}$ 都变差 | 相位通道自身失真，**L2 FAIL** |
| D 与 R 都变差 | 跟踪/剧烈运动混杂，**L2 FAIL**（同 `17` §6.5） |
| D 差、R 差而 $D_{\text{unwrapped}}$ 好 | 设计未预期的组合，**L2 FAIL**，如实报告 |

**`17` §6.2(3) 的证伪条款据此扩写**：原文只要求匹配的 $s^R_{C1}$ 不显著；
现要求 **$D_{\text{unwrapped}}$ 与 R 两个对照都不得随风险变差**，任一变差即 L2 判负。
这是**收紧**，不是放宽。

### 5b 逐被试配对差异检验（对 `17` §6.2 的第三处修改，必须与 §5 同时满足）

上面那条仍不够。「D 显著、对照不显著」**不等于两者差异显著**——
那是在比较两个显著性判决，而不是检验差异本身。8 名被试在三个通道上是**同一批人、同一顺序**，
斜率天然配对，因此差异可以直接检验：

$$\boxed{\ \delta^U_u=\beta^D_u-\beta^{D_{\text{unw}}}_u,\qquad
\delta^R_u=\beta^D_u-\beta^R_u\ }$$

对 $\delta^U$ 与 $\delta^R$ 各做一次**与 `17` §5.2 同一形式的单侧精确符号翻转检验**
（$H_1:\overline{\delta}<0$，即 D 退化得**更多**），$2^8=256$ 枚举，最小可达 $p=1/256$。

**L2 PASS 追加要求：两个配对差异都必须 $p<0.05$ 且均值为负。**
任一不满足，判决记为 **NOT SEPARATED**，不得写成 WRAPPING。

**措辞纪律**：本预注册**没有冻结非劣/等效界**，因此对照通道**一律不得称"稳定"**。
允许的表述只有「**未检出显著退化**」（no significant degradation detected）。
若日后要主张对照确实"不变"，须先在新文件中冻结等效界，再重新评估。

已实测（合成回波）：分支选择与无噪几何一致率 **97.8–100%**
（低于门限选错 1/0/0 帧，高于门限 2/1/0 帧，共 89 帧）；
低于门限 $k\neq0$ 仅 1/0/0 帧，$D_{\text{unwrapped}}$ 与 D 基本一致；
高于门限 **D 折到 0.236/0.224/0.260，而 $D_{\text{unwrapped}}$ 保持 0.978/0.990/0.999**。

## 6. 载波常数 $f_s$ 的来源与敏感性

**主值 $f_s = 0.3203$ 周/样本**，来源为 `tools/w2_calib2.py:43–49`：
对 30 个真实样本的距离剖面做 **4096 点补零 FFT**，取平均幅度谱峰。
这是仓库中该常数的唯一权威测量，`uwb_osr/forward.py` 文件头与 `00` §4.1 引的都是它。

**0.3228 的来源（初稿写错，此处更正）**：它**不是**模板数组的谱峰，
而是 `logs/w2_pulse.npz` 里存的 **`carrier` 字段 7.6199 GHz** 换算成周/样本的结果。
该 0.8% 的口径差异（对 `00` 权威值 7.56 GHz）由 `13` §4.2 记录在案。
模板数组自身的谱峰是另外两个数：原生 49 点网格 **0.3265**、补零到 4096 点 **0.3218**，
两者均不作主值，也不是 0.3228 的来源。

**固定敏感性检查**（已入自检，非判据）：用 **0.3228** 重做去旋，
低于门限的相关性为 0.957/0.982/0.994，对比主值的 0.984/0.979/0.994——**结论不依赖该常数的第三位小数**。

**非循环验收**（避免"用 0.3203 生成脉冲又用 0.3203 去旋"的自证）：

- 用 $f_s=0.28$ 与 $0.36$ 分别生成并去旋：0.978/0.976/0.993 与 0.965/0.981/0.995；
- 用 **实测脉冲模板** `logs/w2_pulse.npz` 渲染（该文件是标定产物，不是回波缓存，
  不含手势标签或风险分数）：低速 0.983/0.974/0.993；
  高速下 D 折到 0.271/0.198/0.226 而 $D_{\text{unwrapped}}$ 保持 0.899/0.892/0.902，分离度 0.666。
