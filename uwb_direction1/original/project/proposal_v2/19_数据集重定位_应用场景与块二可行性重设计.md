# 19 数据集重定位：应用场景、公开数据集全表与块二可行性重设计

**日期**：2026-08-01
**触发**：导师面谈提出致命质疑——"为什么选一个手势数据集？解释不了，也没有任何现实应用意义。"
**本文职责**：(1) 把网上现有的 UWB 相关公开数据集查清并分级；(2) 判断块二现有方案能否迁移；
(3) 给出重设计后的块二三点结构与两周先导实验。
**本文不做的事**：不修改 `15/16/17` 的历史结论，不宣布任何数字。所有"待核实"项都已标出。

## 0. 一页结论

1. **能做。** 块二的科学问题（因果状态估计 → 概率短时轨迹预测 → 观测闭环审计）**与数据集无关**，
   绑定数据集的只有观测模型那一层（单站圆 → 双站椭圆），改动量可控。
2. **换数据集不是止损，是升级。** 现在最大的软肋是"真值不可得"，所以每个精度数字都必须加三层
   免责声明（`10` §3.1）。换到带位置真值的数据集后，头条指标直接变成 **ADE/FDE（米）+ NLL + 覆盖率**，
   既解决真值死结，又天然满足导师的判据（头条不是准确率）。
3. **主数据集锁定 A1**（`target_CIR.mat`，2.37 GB，**CC0**，已核实可下载）：Bocus & Piechocki 2022，
   7 节点 / 21 条双向链路、**无标签被动 CIR**、真实住宅四房间、**真值坐标与 CIR 打包在同一文件内**。
   **A2（OPERAnet，6 人 / 8 h / Kinect 骨架真值）降为可选扩展**——用户已决定不强求跨人评测，
   泛化轴改为**留房间**（§8.1）。
4. **应用场景推荐**："**无摄像头空间的被动人体运动感知与短时轨迹预测**"，主锚点是居家养老监护，
   第二锚点是机器人 / 具身智能体的无视觉人体预测。这两个都不是编出来的场景——A1 就是在真实住宅
   采的，A2 的动作表里直接有"躺下""从地上起身"。
5. **原 UWB-Gestures 不丢**，降为**受控台架**：几何完全已知、距离分辨率高一个数量级（6.4 mm vs 30 cm），
   是唯一能把物理机制（散射中心、相位缠绕、扩展目标）做干净的地方。这句话同时回答了导师
   "为什么当初用手势数据"。
6. **雷达个数不是问题**（你已确认）。从"3 部单站雷达"换到"7 节点 21 条双站链路"，几何自由度反而
   从 3 个观测涨到 21 个，超定程度更好，反演更稳。

## 1. 导师那一刀砍在哪，以及正确的回答

导师的质疑不是"手势识别做得不好"，而是**任务设定本身没有现实落点**：
一个人对着三部雷达做 12 个规定手势 1600 次，这件事在现实里不发生。

三种应对，只有第三种能过：

| 应对 | 问题 |
|---|---|
| 辩解"手势控制在车载/无菌场景有产品" | 是事实（宝马手势控制、Google Soli），但你的数据是实验室摆拍，不构成场景证据 |
| 把手势数据硬讲成"动捕的最小单元" | `15` §1.2 已经这么写了，导师上一轮就是判这个"本质还是一件事" |
| **换任务锚点：从"人做什么手势"换成"人在哪、要去哪、什么时候不能信"** | ✅ 输出空间、指标、失败方式三条同时变，且有真实数据支撑 |

第三种同时解决了两件本来分开的麻烦：
**没有真值**（现在有了）和**没有场景**（现在有了）。

## 2. 公开数据集全表（已查证）

分级标准只有一条：**能不能拿到"连续位置/姿态真值 + 该时刻的 UWB 原始观测"**。没有连续真值的，

### A 级：无标签被动 UWB CIR + 连续位置真值 —— 直接可用

#### A1 · A comprehensive ultra-wideband dataset for non-cooperative contextual sensing

| 项 | 值 |
|---|---|
| 出处 | *Scientific Data* 9, 2022（Bocus & Piechocki，布里斯托大学） |
| 硬件 | Qorvo/Decawave **EVK1000（DW1000 芯片）× 7 个节点**，节点坐标全部给出（X 2.26–11.05 m，Y 0.58–2.97 m，Z 0.58–1.73 m） |
| 拓扑 | 节点 ID0 作为发起端，与其余 6 个做单边双向测距（SS-TWR）→ **21 条双向链路** |
| 观测 | 每次交换保存 **50 个复数 CIR 抽头**（从 1016 个里截取），抽头间隔 **1.0016 ns ≈ 30 cm 路径分辨** |
| 速率 | **单链路约 24 Hz**；21 条链路合计约 504 Hz |
| 被动性 | **人身上不带任何 UWB 标签**，测的是人体反射造成的 CIR 扰动 ✅ |
| 真值 | 另一套**主动** UWB（Qorvo MDEK1001，10 个锚点）给出目标位置，**10 Hz**；另有 NTP 同步视频做活动标注 |
| 场景 | 真实住宅一层，**四个带家具的房间 + 走廊** |
| 规模 | **1 名被试**，坐 / 站 / 走，约 **1.6 小时**，约 300 万条标注数据 |
| 下载 | figshare，DOI `10.6084/m9.figshare.c.6078021`，**CC-BY 4.0** |

**为什么它是首选**：这是唯一一个"被动多站 UWB CIR + 走遍整套房子的连续位置真值 + 家具杂波齐全"
的公开数据。你现在整条反演管线要的输入它全有。

**必须诚实说的短板**：
- **只有 1 名被试** → 不能宣称跨人泛化。**用户 08-01 拍板：跨人不做**，泛化轴换成
  **留房间（leave-one-room-out）**，见 §8.1；
- 真值本身是 UWB 定位得来的，量级是分米级，不是动捕的毫米级 → 报告误差时要写"相对该参考系"；
- 距离分辨 30 cm，比你现在的 6.4 mm 粗 47 倍 —— 但目标从 20 cm 的手换成 1.7 m 的人、
  运动范围从 30 cm 换成 10 m，**分辨率/目标尺度比反而更宽松**。

## 3. 应用场景论证（准备给导师的那一页）

### 3.1 主场景：无摄像头空间的被动人体运动感知（居家养老）

**真实痛点，不是编的**：
- 卧室、卫生间是老人跌倒的高发地，恰恰是**法规与伦理上不能装摄像头**的地方；
- 现有产品线是"事后跌倒检测"，但护理上真正值钱的是**跌倒前 0.5–1 s 的状态与去向**（能不能提前呼叫、
  能不能提前判断"这个人正在往浴缸方向失稳");
- UWB 不依赖光照、不采集图像、可穿透薄墙与家具遮挡、单价约 300 美元/节点（C3 数据集的实测报价）。

**数据支撑**：A1 就是真实住宅四房间采的；A2 的动作表里直接有"躺下""从地上起身"。

**块二输出直接对口**：当前位置/速度/不确定度 → 未来 0.5/1/2 s 的多条可能轨迹 → 这条预测可不可信。

### 3.2 第二场景：机器人 / 具身智能体的无视觉人体预测

**痛点**：服务机器人、仓储 AMR 要在人身边规划，**需要提前量**；相机在黑暗、烟雾、逆光、隐私区域失效，
LiDAR 在遮挡后就丢目标。UWB 能穿薄墙与家具，恰好补在相机失效的那一段。

**数据支撑**：B1（THÖR-UWB）有四足机器人在场、有遮挡、有毫米级动捕。

**诚实边界**：B1 的 UWB 是合作式，所以这一场景只能验证**预测头**，不能验证"被动感知也能做到"。
两件事要分开写，不能混。

### 3.3 备选场景（写进论文引言即可，不做实验）
车内乘员/儿童遗留检测（C4 是真实驾驶数据）、灾后搜救穿墙探测（C1/C2）。

### 3.4 顺带回答"那你当初为什么用手势数据"

> 手势数据集的价值不在应用，在**可控**：三部单站雷达几何完全已知、距离分辨率 6.4 mm、
> 目标是单一近场散射体、每条轨迹都是规定动作。它是唯一能把"回波—运动"的物理关系做干净的台架。
> 块一在这个台架上解决"识别与开放世界"，块二把在台架上验证过的物理模型搬到真实住宅与机器人场景，
> 去解决"人在哪、要去哪、什么时候不能信"。

这句话把手势数据从"研究对象"降为"标定台架"，导师那一刀就砍不动了。

## 4. 迁移可行性：现有资产逐项过筛

### 4.1 直接能用（零改动或调参级）

| 资产 | 位置 | 说明 |
|---|---|---|
| **P0a/P0b 因果契约与运动学基线** | `specs/2026-07-31-p0a-causal-prefix-design.md`、`specs/2026-08-01-p0b-kinematic-baseline-design.md` | F0/Last/CV(2,5,20)/CA(5,20) 全部**与数据集无关**，47/47 + 50/50 回归直接搬过去当新数据的基线地板。这是最大的一笔沉没成本保护 |
| 维特比距离峰跟踪 | `uwb_osr/trajectory.py:50` `viterbi_track` | 还是"在距离 bin 序列上找连续峰路径"，只需重调 `max_jump`（50 抽头 vs 189 bin） |

### 4.2 要改（工作量：中，2–4 周）

| 项 | 现在 | 改成 | 难度 |
|---|---|---|---|
| **观测模型** | 单站往返 `2·‖p − radar‖`（`forward.py:51` `render`） | 双站 `‖p − tx‖ + ‖p − rx‖`（椭圆） | **低**。几何简单，且 21 条链路超定，比现在 3 个观测更好解 |
| **解析雅可比** | `trajectory.py:179` `jac`，单站 → 单位向量 | 双站 → 两个单位向量相加 | **低**。这是块二能快速迁移的关键，`trajectory.py` 的 DPS 引导不用搬 torch |
| **脉冲模板** | X4 实测模板（7.56 GHz 载波，λ=41.1 mm） | 从 DW1000 的 CIR 抽头直接测 | 中。数据里有原始复数 CIR，方法照搬 `tools/w2_calib_pulse.py` |
| **幅度衰减** | `AMP_EXP=-2.41` | 双站几何要重新标定 | 低 |
| **时间对齐** | 三视角同步采集 | **21 条链路各自 24 Hz 且互相异步** | **中高。新增工作，但这本身是一个能写的方法点**（因果对齐 + 不规则采样滤波） |
| **目标模型** | 单一近场散射中心（手，20 cm） | 人体扩展目标，30 cm 分辨下约占 1–2 个 bin | 中。`tools/w2_body.py` 的扩展目标仿真可复用 |

### 4.3 会变性质、必须重新体检的（先做诊断，别先下结论）

- **相位可用性**。你现在整条相位/多普勒读出（`15`、`16`、`17` 的第三点）建立在 X4 帧间相干上。
  DW1000 的 CIR 抽头是复数，但**不同数据包之间的载波相位是否相干（是否需要 CFO 补偿）未核实**。
  → 先导实验 P5 必须先测这一条，**不许假设**。
- **相位缠绕门限**会变。DW1000 常用信道 ch2 中心 3.9936 GHz（λ ≈ 75 mm，λ/4 ≈ 18.8 mm）或
  ch5 6.4896 GHz（λ ≈ 46 mm，λ/4 ≈ 11.6 mm）；具体信道要从数据集配置里读。
  人以 1 m/s 走、单链路 24 Hz → 帧间径向位移可达 42 mm，**远超 λ/4** → 缠绕是常态而不是偶发。
  这对第三研究点是**好消息**：风险分数的动态范围会拉满，而且**这次有真值可以直接验证**
  （现在的困境正是"风险分数无法与真实缠绕对照"）。

### 4.4 会作废的
- `05` 的自标定 FAIL、`09` 的"三视角不共相位中心 ~75 mm"误差预算 —— 这些是 X4 三视角台架的结论，
  换阵列后不成立，只能作为**台架侧的机理结论**保留，不能外推。
- `07` 的四条几何预测里，依赖具体三视角布局的那几条要重做。

## 5. 重设计后的块二（三点版）

**新题目建议**：

> **面向无摄像头空间的被动 UWB 人体运动状态估计与可审计短时轨迹预测**

数据流不变（`15` §0.1），变的是三点的切分和评价口径：

$$
\underbrace{X_{1:t}}_{\text{21 条链路 CIR}}
\;\xrightarrow{\;q_\phi\;}\;
\underbrace{s_t}_{\text{位置/速度/协方差}}
\;\xrightarrow{\;p_\theta\;}\;
\underbrace{\hat p_{t+1:t+H}^{(1:K)}}_{\text{未来 0.5/1/2 s 多条轨迹}}
\;\xrightarrow{\;\text{审计}\;}\;
\underbrace{\text{可信度}}_{\text{何时不能信}}
$$

### 2.1 无标记被动 UWB 的因果运动状态估计

| | |
|---|---|
| 科学问题 | 只用当前与历史多链路 CIR，能否因果地估计人体有效散射中心的位置与速度，并给出与阵列几何一致的不确定度？ |
| 输入 / 输出 | 21 条异步链路 CIR 前缀 → 位置、速度、活动门、协方差 |
| **头条指标** | **位置 RMSE / 中位误差（米）、NLL、覆盖率、与 CRLB 的差距** ← 全部不是准确率 |
| 相对现在的升级 | **有真值了**。不用再写"下界 13.5 mm / 上界 57 mm / 真实精度不可知"这三层免责 |
| 方法点 | 双站椭圆交汇 + 21 条链路的异步因果时间对齐 + 逐时刻可观测性谱（哪条链路此刻在贡献信息） |
| 失败方式 | 目标进入链路盲区、GDOP 恶化、NLOS、被家具遮挡 |

### 2.2 物理约束的概率短时轨迹预测与真实回波闭环

| | |
|---|---|
| 科学问题 | 相似历史是否对应多个未来？概率预测是否真的强过单峰？预测轨迹能否解释**未参与预测**的真实未来 CIR？ |
| 输入 / 输出 | $s_t$ + 历史 → 未来 0.5 / 1 / 2 s 的 K 条轨迹样本及其概率 |
| **头条指标** | **ADE / FDE（米，对真值）**、future-range log score / Energy Score、经验覆盖率、错误轨迹负对照 |
| 相对现在的升级 | 现在只能用"真实未来 CIR"自评（自循环嫌疑）；**现在多了一条完全独立的真值 ADE/FDE** |
| 应用锚点 | 提前量曲线：预测水平 vs 误差 vs 机器人可用的减速/绕行时间；跌倒前兆的提前量 |
| 与块一的隔离 | 模型输入不含任何活动类别；活动标签只用于分层解释 |

### 2.3（新）部署条件下的预测可信度自审

原第三点候选（读出失败的物理可预测性，`16/17`）**不作废，而是升级**：现在它有了真值，可以做成
真正有应用价值的东西。

| | |
|---|---|
| 科学问题 | 在**没有真值**的真实部署里，系统能否只凭几何、相位与场景线索，事先判断"接下来这一段估计/预测不可信"？ |
| 输入 / 输出 | 阵列几何 + 当前后验 + CIR 质量统计 → **风险分数**（不输出位置，也不输出类别） |
| 三类失效源 | ① 几何：目标进盲区 / GDOP 恶化；② 相位：径向速度导致 CIR 相位缠绕（DW1000 λ/4 ≈ 12–19 mm）；③ 场景：NLOS、家具遮挡、多径 |
| **头条指标** | **风险分数 vs 真实误差的 AUROC / 分层误差曲线 / 选择性预测的风险—覆盖曲线** |
| 相对现在的升级 | `17` 预注册里最难受的一条是"没有真值，只能用历史读出成败当代理"。现在**可以直接对真实误差做 ROC** |
| 独立性检验（对照 `15` §0.4 的五条门槛） | ① 删掉 2.2 它仍成立（可以只审 2.1 的状态估计）✅ ② 输入输出基线指标失败条件独立 ✅ ③ 有不依赖自循环的真实评测目标（真值误差）✅ ④ 不落回分类 ✅ ⑤ 数据规模：A1 单被试 1.6 h ≈ 每链路 13.8 万次测量 × 21 链路，真值 10 Hz ≈ 5.8 万点 —— **够做，但不宽裕**；滑窗会高度重叠，统计检验必须按**时间块**而非按窗口计有效样本数 ⚠️ |
| 应用价值 | 安全相关系统的刚需：宁可说"这 0.5 s 我不知道"，也不能给机器人一个自信的错预测 |

**2.3 的备选**（若风险分数在新数据上被证伪）：换成**跨环境 / 跨阵列布局的可迁移性**——
A1 的住宅 vs A2 的两个房间 vs 不同节点坐标，问"换了房间、换了节点位置，还要重新采多少数据"。
这条同样输出非标签、同样有真值、同样是部署刚需。

### 8.1 跨人不做，泛化轴换成什么

不做跨人不等于不谈泛化 —— 直接把泛化轴换成**对部署更有意义的一条**：

> **留房间评测（leave-one-room-out）**：A1 的住宅有**四个带家具的房间 + 走廊**，节点几何固定但
> 每个房间的杂波、多径、遮挡完全不同。训练时留出一个房间，测试时问"换个房间还能不能用"。

这比跨人更贴部署现实（真实产品是换一户人家安装，不是换一个人），而且**A1 单被试就能做**。
备用轴：留时间段（同房间不同时段，测环境漂移）。

写作口径必须写死：**结论范围限定在"单被试、固定阵列、真实住宅"，不宣称跨人泛化。**
若 A2 的外参后来标定成功，跨人作为附加实验补进去；标不成功就在局限性里写清楚。
