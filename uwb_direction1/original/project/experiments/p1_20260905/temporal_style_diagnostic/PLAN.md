# 时间与风格诊断预设方案

2026-09-08，用户已授权执行诊断。按用户指示，三路逐帧对齐作为本轮假设，不进行同步否决检查，不将其记录为已验证事实。

本轮不训练新分类器、不改变旧模型、不访问外层测试输入。八折使用 cross_user_meta 已完成公共初始化的单 Right 导出模型；完整验证用户用于输入敏感性，训练用户的固定分层样本用于三视角对应。训练/验证派生统计不得使用测试用户。

1. 完整验证集：原始 Right、端点不变的平滑时间形变 ±4 帧、边界复制的时间平移 ±3 帧。两种输入分量同步变换并分别重新标准化。仅为表示空间压力测试，不宣称模拟了物理真实速度或确保标签不变。
2. 完整验证集：从训练用户随机抽取 Right 风格供体，不使用验证标签选择供体。浅层线性投影后、位置编码前，混合每特征维在时间/空间位置上的均值和标准差，供体份额 0.1、0.3；测量首个 LayerNorm 后、最终编码器输出和分类预测变化。所有样本施加，诊断其效应，不代表训练时概率。
3. 训练集固定每用户每可用类 2 个样本：已知 ±4 帧平滑形变，比较时间位置基线、Right 局部描述、三视角等权局部描述、辅助视角错配、原 Right 编码器时间特征的 DTW 对应恢复误差。辅助错配严格同用户同类且不自配。
4. 对同类不同用户训练样本，比较原始匹配与形变后匹配的时间等变性；无真实跨人阶段标签，该结果只能反映稳定性，不能证明语义对应正确。

局部描述使用准备好的幅度与相位运动分量，各自沿 189 距离格点平均为 21 格；各视角距离矩阵按正值中位数缩放。DTW 带宽 12 帧，端点相连，步型 (1,1)/(1,0)/(0,1)，按源帧平均路径目标坐标；评价内部第 5 到 84 帧。固定这些参数，不根据结果试更多版本。

保存配置、模型哈希、全部样本 ID、供体 ID、逐样本预测与对应误差，独立重算汇总。诊断后给出建议，不把敏感性或合成对齐的正向结果写成分类提升。
