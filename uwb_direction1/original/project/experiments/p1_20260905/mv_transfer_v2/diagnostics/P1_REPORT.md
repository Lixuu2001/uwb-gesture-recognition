## 1. 读数前必须先看的标定：初始化噪声有多大

新协议把 `split_seed` 固定为 2026，`model_seed` 只改初始化和 dropout 的随机流，
**不改划分、也不改采样顺序**（采样器用独立的 `sampler_seed = 7777 + fold`）。
因此 2026 与 2027 之间的差别是**固定划分与固定采样顺序下的训练随机性复验**
（初始化加 dropout 随机流），比旧协议（seed 同时改划分）更严格，但不是"只改初始化"。

- 绝对准确率只能作描述，不能用来排名。注意这个跨 seed 漂移**不是配对差值的噪声上界**，

### 3.1 唯一存活的效应

A-SC vs A-GS：两个 seed 分别 +0.34 和 +0.54，合并 +0.44 pp，
95% 用户 bootstrap CI [+0.19, +0.74] 不含零。**8/8 被试改善是先合并两个 seed 之后的
统计；单个 seed 各自为 6/8。**
损失只多了一项：把**不同人做同一手势**的样本在投影空间拉近、把跨用户异类推开。
它没有教师、没有额外视角、没有任何特权输入。

一个与之相容的解释是：跨用户不变性所需的监督信号本来就写在标签和被试 id 里，
而三台雷达提供的是视角冗余、不是跨人不变性。**这只是一个假说，本轮没有检验它**——
要检验它需要能把"视角冗余"和"跨人不变性"分开度量的实验，本轮没有做。
不要把它当成已确立的机制。

必须如实说明：+0.44 pp 远低于预设的 +2.00 pp 研发闸门。按第 11.3 节，它作为
可复现的小幅辅助保留并如实报告，**不自动升级为主创新**。

### 3.2 A：教师关系通道整体为空，与教师是否多视角无关

A-SC、A-US、A-MV 三臂的双 seed 准确率是 75.35 / 75.33 / 75.39，两两差值都在
±0.06 pp 内、CI 全部含零。两个子机制在 seed 2026 上也分别测过：教师**训练**时
见过三视角（A-TS vs A-US，−0.12）和目标**读取**三视角（A-MV vs A-TS，+0.03），
同样都是零。

这与 P0 的诊断并不矛盾，而是把两件事分开了：三视角教师的关系图确实更干净
（跨用户 top-1 纯度 0.883 vs 单视角 0.732）、确实不同（top-1 一致率仅 37.7%）。
**教师的关系图更好，不等于把它蒸馏给单雷达学生就能改善对新用户的泛化。**

方向翻转必须写明：A-US vs A-SC 在 seed 2026 是 +0.23（CI [+0.01,+0.47]，不含零），
在 seed 2027 是 **−0.27（CI [−0.52,−0.03]，也不含零）**。两个 seed 各自都给出
"统计上排除零"的结论，方向却相反。这是本轮最直接的证据，说明在这个效应量级上，
**单 seed 的置信区间不足以支撑方向性结论**。

### 3.3 B：融合过程监督在两个 seed 上一致地不如单视角过程监督

B-MV vs B-SELF 是 −0.14 / −0.16 / 合并 −0.15，方向和量级都稳定（不像 A 会翻转）。
B-SELF 相对 B-GS 也是零（−0.04），也就是说过程监督本身无效，不只是融合无效。

> **2026-09-07 更正。** 本节初稿据 B-SHUF 宣称"15 段过程目标里没有任何可用的逐实例
> 信息"。独立复核指出 B-SHUF 的实现没有真正打断实例对应，我复算确认：
> **68.42% 的训练样本呈现次数保留了原目标**（2,092,860 次呈现中只有 31.58% 可能被更换）。
> 原因是 `shuffle_within_class` 只在当前 32 样本 microbatch 内交换同类同用户目标，
> 而随机 microbatch 里绝大多数 (类别,用户) 单元只有一个样本、直接跳过。
> **该机制结论撤回**；B-MV 相对 B-SELF 的负结果不受影响。

B-SHUF 把过程目标换成同人同类另一次动作的目标，结果 +0.06 pp（CI [−0.07,+0.22]）。
但由于上述实现缺陷，这个"持平"只能说明**扰动其中约三分之一的目标不产生可测影响**，
不能证明实例对应无用。代码已修正（`relation.global_within_class_derangement`：在整个
训练集合内按 (类别,用户) 预生成无固定点置换，实测更换比例 100%，类别与用户分布不变，
训练池外的行不受影响），并加了断言测试；`shuffle_scope='microbatch'` 保留下来只为
复现已完成的那两个 run。**本轮没有用修正版重跑**——因为 B-MV 没有增益需要解释，
这条机制结论直接撤回即可，不值得为了给负结果补一个漂亮解释而新增训练。

P0 记录的两条相关预兆仍然成立，但它们本身不足以支撑上述被撤回的结论：融合活动分布熵
2.548、上限 ln15 = 2.708；真实配对相对同类错配零假设在 lag=0 的余量只有 +0.065～+0.083 相关。

### 3.4 C 的可预测性诊断：筛选失败信号成立，机制解释已撤回

> **2026-09-07 更正。** 本节初稿曾据此宣称"教师身上可迁移的分量与判别的分量基本不
> 重合"，并把它当成前面所有零结果的统一机制解释。独立复核
> （[INDEPENDENT_REVIEW_20260907.md](INDEPENDENT_REVIEW_20260907.md)）指出该对照
> 不匹配，我重新核算后确认复核正确，**该机制结论整体撤回**。下面是修正后的版本。

C 问的是"672 维教师坐标里，单台 Right 雷达原则上能预测出哪些"。教师坐标按视角拼接：
每视角 192 维时间（6 区间 × 32 通道）+ 32 维距离分支全局均值 = 224 维，L/T/R 共 672 维。
雷达探针为 Right 的 10×21 池化幅度和相位，共 420 维。在外层训练用户内部做留一用户
ridge（alpha=10）。

|指标|残差版|非残差版|
|---|---:|---:|
|通过合格判据的坐标（≥5/7 用户 skill>0 且均值>0）|332 / 672|267 / 672|
|**选中前 32 维**的平均 skill|0.900|0.897|
|用选中 32 维做类别探针|0.575|0.577|
|用随机同维 32 坐标（**从全部 672 维抽取**）|0.812|0.812|

#### 撤回的理由：选中集和对照组不是同一个来源

直接解析两份诊断 JSON 的 `selected_coordinates`：**八折共 256 个选中坐标，残差版和
非残差版都 100% 来自 Right 时间分支，Left、Top 和任何距离分支坐标一维都没有。**
而随机对照从整个 672 维抽取、PCA 也在整个 672 维上拟合。

所以 0.575 vs 0.812 这个缺口同时混入了：能否使用 Left/Top 的观测、是否覆盖距离分支、
通道和时间区间的覆盖、以及相关性差异。**它不是只改变"可预测性"的隔离实验，
不能定位失败原因。**

这个结果事后看几乎是架构的直接推论：教师的 `use_fusion=False`、`xmv_layers=0`，
各视角在读出前独立编码，因此教师的整个 Right 分支本来就是 Right 输入的确定性函数
\(z^T_R = E_{\theta_T}(x_R)\)。筛选自然会挑走它，而真正有意思的问题——Right 能否预测
**隐藏视角**的分量——恰恰是筛选一个都没选中的部分。

#### 另外三处需要收窄的表述

1. **332 个合格坐标不等于 332 个都达到 skill≈0.9。** 合格条件只是"≥5/7 用户 skill>0
   且均值>0"；0.900 只是**前 32 维**的均值。原文"近一半坐标能以少 90% 残差平方和的
   精度预测"是错的。
2. **raw 版本没有排除整个筛选准则的倾向。** 两版都仍以"相对类中心误差"的 skill 排名，
   raw 只取消了输入和目标的类中心扣除，分母仍是已知真类后的类中心误差。类别分离强、
   类内变化小的坐标分母天然小，因此更难拿到高 skill。所以 raw 与残差版接近，
   **在逻辑上排除不了这种倾向**。
3. **PCA 的 +6 pp 不能给冗余损失设上界。** PCA32 是对全部 672 维的线性组合，
   选中组是 32 个 Right 时间坐标；两者差别不只是"正交 vs 相关"。随机 32 → PCA 32 的
   +6.02 pp 只描述这两个方案的差距。（另注：类别探针脚本和多样性脚本各用了不同的随机
   种子，随机对照分别是 0.812 和 0.823，这是抽样差异，不是随机对照"变好了"；
   两者都只抽了一组，没有给出重复分布。）

#### 选择与评价复用

代码先汇总全部 7 个源用户的留一 ridge skill 选出同一组 top-32，再在这 7 个用户上做
留一类别探针。**probe 用户已经参与了坐标选择**，因此这不能称为整条"教师训练→坐标
选择→类别预测"流程对未见用户的无偏估计。它是**固定教师下的源用户内部筛选诊断**。
（这不构成外层测试用户泄漏——外层 test 折从未进入任何一步。）

#### 仍然成立的部分

按第 7.4 节的停止条件，**C 不进入训练阶段**：当前筛选方案只选出了 Right 时间分支的
一小部分，类别探针弱于全三视角随机坐标，没有产生值得直接投入学生训练的跨视角目标。
这是一个有价值的**筛选失败信号**，但它只说明"这一套筛选准则没找到可用目标"，
**不能升级为"多视角可迁移信息与判别信息不重合"**，也不能充当 A、B 为零的统一解释——
A 用的是 992 维/视角的关系目标，B 用的是运动能量过程目标，都不是 C 的 672 维坐标。

#### C0：修完诊断之后的结果（2026-09-07，判据见 configs/c0_frozen.md）

上述修诊断的四项已经做完，8 折 × 7 probe 用户 = 56 次评价，选择与评价不复用。
完整报告见 [C0_REPORT.md](C0_REPORT.md)，三条结论：

1. **来源混淆确认，撤回是对的。** 把随机对照限制到同一候选池（Right 时间分支 192 维）后，
   top-skill 与同源随机的差在 k=16/32/64 分别是 −0.022 / −0.015 / −0.001，
   **全部落在同源随机 10 次抽取的 ±1σ 内**。原来那 −24 pp 里，可预测性只贡献约 −0.015，
   其余整个来自分支归属：同源随机 vs 全 672 维随机相差 +0.147 / +0.216 / +0.245。
   （另：合格判据在这个池子里是空过滤器，56 次评价全部 `eligible = 192/192`。）
2. **单雷达预测不了隐藏视角。** 逐坐标平均 skill：Right 时间 **+0.797**、Right 距离 +0.429、
   Left 时间 −0.139、Left 距离 −0.128、Top 时间 −0.531、Top 距离 −0.324。四个隐藏分支
   全为负，即线性预测还不如"只按类别猜中心"。这也让原来的筛选结果成了同义反复：
   选中集 100% 落在 Right 时间分支，**因为那是唯一 skill 为正的分支**——而教师
   `use_fusion=False`，Right 分支本就是 Right 输入的确定性函数。
   *需如实记录的例外*：Left 时间分支有 7.0% 的坐标 skill>0.2（最大 0.381），
   Left 与 Right 几何上左右相对；Top 几乎全空（0.7% / 0%）。这只是线索，
   **本轮没有检验这批坐标是否携带类别信息**。
3. **问题不在冗余。** QR 去冗余相对同源随机只有 +0.007 / +0.007 / +0.002，
   全在随机抽取的标准差以内。

C 按判据停在这里。**不加非线性**——线性诊断没通过之前谈非线性没有意义。

## 4. 与既有结果合并后的第一部分总账

到目前为止，本项目已用**多种迁移方案**检验"三视角训练能否帮助单雷达学生"。
这些方案共享同一批样本、被试、固定教师和编码器，所以下表是一个系统比较，不是
多次相互独立的证明：

|通道|结论|来源|
|---|---|---|
|logit 软标签蒸馏|增益可由普通全局平滑解释，教师相对无教师 −0.04 pp|既有 `teacher_necessity`|
|潜在空间 1→3 重建补全|未过闸门|既有 `reconstruction`|
|跨用户折外特权软标签|−0.23 pp|既有 `oof_privileged`|
|**跨用户关系几何**|**+0.06 pp（CI [−0.06,+0.18]），单双子机制均为零**|本轮 A|
|**融合运动过程监督**|**−0.15 pp，两 seed 一致**|本轮 B|
|可预测教师分量筛选|未进入训练。C0 修完对照后：单雷达对隐藏视角分支的线性可预测性为负（见 §3.4）|本轮 C / C0|

> **2026-09-07 更正。** 初稿把这些称作"六条互相独立的通道"并说它们构成系统性证明。
> 这两点都过头了：这些路线**共享同一批样本、同一批被试、同一个固定教师和同一套编码器**，
> 因此应称为"多种迁移方案的系统比较"，不是六次相互独立的证明；而 C 从未进入训练，
> **不能计为第六个训练负结果**。

前五条方案在各自匹配的单视角对照下都没有观察到有研发价值的正增量。这支持一个
**关于当前若干实现的实证结论**，不构成"单雷达无法利用多视角训练信息"的证明。

关于普通 KD 也需要一处收窄。历史协议下幅相 CE 对照 72.41%（seed 2026）/ 72.40%（2027），
加普通 KD 后 73.42% / 73.80%，**KD 增量 +1.00 / +1.40 pp**。它确实没有优于充分匹配的
平滑基线（教师均匀投影 74.61、无教师类别自适应 74.65、全局平滑 74.77），但
**不能因此概括成"普通 KD 从来没有正增益"**。要把 KD 的增益也归因于平滑，需要针对
普通 KD 本身的匹配机制对照，本项目没有做过。此外旧协议的 seed 同时改变训练/验证划分，
不是当前固定划分下的复验。

## 5. 按第 12.1 节 P2 的决定

规则是"A/B 有独立收益才做组合"。A-MV 相对 A-US、B-MV 相对 B-SELF 都没有独立收益，
因此：

- **不跑组合臂**（AB-MV / AB-USMV / AB-MVSELF）；
- **不跑 A-SHUF / A-RKD**：它们是用来解释 A-MV 增益的机制对照，而 A-MV 没有增益可解释；
- **不跑 B-Q / B-AMP / B-TIME / B-CDF**：同理，B-MV 无增益，这些消融解释不了任何东西；
- **不做超参搜索**：外层结果已经看过，此后的任何调参都属于新探索，不能当预注册确认（第 11.1 节）。

已完成的额外工作只有两项，都是为了把负结果做实，而非寻找正结果：A-TS（预注册的
子机制拆分）和第二个 model_seed（把方向性结论钉死）。

## 6. 本轮不能声称的东西

- 不能说"三视角对单雷达无用"——只能说**在本数据、本协议、这五条通道上没有测到增益**。
  8 名被试、单一采集环境、单一数据集。
- 不能说 A-SC 的 +0.44 pp 是显著性结论。CI 不含零是描述性的；8 名被试、
  本轮比较数量较多，且这些被试已被本项目反复探索过，新增 seed 不构成外部独立确认。
- 不能把教师 88.3% 的跨用户近邻纯度当作学生可达到的上限。教师训练过那些行。
- 不能说 B 的时间监督"因为不同步而失败"。P0 显示总体 lag 峰在 0、无系统偏移。
  失败发生在哪一步本轮没有定位，只知道不是对齐。
- 不能把"审计全过"读成"所有因果对照都设计正确"。隐藏视角审计验证的是评估封装的
  单视角输入约束（构造完整/破坏后的三视角数组，两次都显式切出 Right 输入），
  它不自动覆盖上游预处理、目标构造和坐标选择过程——§3.4 的对照不匹配正是审计
  覆盖不到的那一类问题。
- 梯度审计的原实现有缺陷：它在分类损失与辅助损失合并反传后读 `.grad`，而分类 CE
  本身就能让编码器梯度非零，所以它证明不了辅助损失到达了主干。已修正为用
  `torch.autograd.grad` 单独取辅助项的梯度。修正后立刻暴露一个原实现掩盖的事实：
  **B 的过程损失只到达时间分支，距离分支梯度为 None**（过程头按设计只读时间 token）。
  已完成的 128 个 run 的审计字段是旧口径，不能当作"辅助损失确已作用于编码器"的证据。
