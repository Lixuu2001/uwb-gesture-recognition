# 第一部分 P0/P1 独立复核：保留主结果，收窄机制结论

日期：2026-09-07。对象：用户提供的 Claude 总结及当前 `mv_transfer_v2` 实验产物。

**结论：A/B 未达到继续投入门槛，这个决定可以保留；C 当前筛选方案也可以停止训练。但是，“可迁移的不判别、判别的不可迁移”“冗余已排除”“六通道统一证明多视角迁移无效”均超出了证据。独立核查发现两个报告没有交代的关键事实：C 的前 32 个坐标全部来自 Right 时间分支；B-SHUF 至少 68.4% 的训练样本呈现次数没有更换目标。**

本复核没有启动训练、重拟合 C 探针或改动原报告。新增了独立核算脚本和 JSON。下面分别标明从预测文件复算、从诊断 JSON 汇总、从实现逻辑审查得到的结论。

## 1. 哪些结果已经重新核算

对 128 个完成的 run，独立脚本检查了：

- 测试预测 ID、原始缓存标签、logit argmax 与保存预测一致；accuracy、macro-F1 与逐 run 报告一致。
- 独立重建 2026 划分，核对 train/validation/test；采样 ID 均在训练集合内。
- 验证预测重算 CE 与 best_val_ce 一致，选中 epoch 为已记录训练历史中验证 CE 最小值。
- 同 fold、同 model_seed 的初始化记录一致；同采样方式的实际采样数组及其哈希一致，包括两个 model_seed 之间。

这些检查全部通过。它们核实保存产物的内部一致性，**不是重新训练的复现，也不等于证明所有因果对照都设计正确**。本次未重新执行 128 个检查点的前向推理。

主指标为每个用户先平均两个 seed，再对 8 名用户等权平均；CI 按原报告方式进行 10,000 次配对用户 bootstrap，仅是当前已观察数据和两个 seed 下的描述性区间。

因此，**无需因为下文发现机制解释有问题而重跑全部 A/B 主实验**。它们已经支持“当前实现未观察到有实际研发价值的多视角增量”。CI 跨零不等于效应精确为零；+2 pp 是投入门槛，也不是所有正效应的定义。

## 2. 最关键的新发现：C 选中的不是三视角共同分量

### 2.1 坐标来源核查

`predictability.py::teacher_coordinates` 将每个视角整理成 224 维：6 个时间区间 × 32 通道 = 192 维，以及距离分支全局均值 32 维。三视角拼接为 672 维。

直接解析两份诊断 JSON 中的 `selected_coordinates`，得到：

|筛选版本|折数|每折 Left 入选数|每折 Top 入选数|每折 Right 入选数|每折距离分支入选数|
|---|---:|---:|---:|---:|---:|
|残差版|8|0|0|32|0|
|非残差版|8|0|0|32|0|

残差版 32 个坐标只涉及 **8–10 个不同时间通道**，其余是这些通道在不同时间区间的坐标。不同时间位置可能仍有信息，不能把它们直接算成重复维度，但这说明选择高度集中。

随机 32 维从整个 672 维抽取，PCA 也在整个 672 维上拟合。于是当前比较同时改变了：

1. 是否可以利用 Left/Top 的观测；
2. 是否覆盖距离分支；
3. 通道和时间区间的覆盖；
4. 相关性及其他特征性质。

所以 57.5% 对 82.3% 并非“只改变可预测性”的隔离实验。它是一个有价值的筛选失败信号，但不能定位失败原因。

### 2.2 为什么它还不能回答“原则上能预测什么”

当前教师的 `Classifier` 使用共享双路径编码器，`use_fusion=False`，默认 `xmv_layers=0`。各视角在读出前独立编码。固定教师参数后，Right 分支可写成：

\[
z^T_R=E_{\theta_T}(x_R).
\]

也就是说，**原始 Right 输入本来就足以计算教师的整个 Right 分支**。教师参数包含三视角训练产生的先验，但该分支在推理时不读取该样本的 Left/Top。这与预测隐藏雷达独有观测是不同问题。

C 实际检验的是“420 维粗池化输入 + 固定 alpha 的线性 Ridge，能预测哪些特定池化教师坐标”，而不是整个 Right 输入的信息论可观测上限。输入池化、线性回归、教师坐标池化、top-32 选择都可能损失判别信息。仅增加一句“不能排除非线性”仍不充分，因为尚未穷尽**其他线性子空间或筛选准则**。

本轮 A 使用另一种 992 维/视角的关系目标，B 使用运动能量过程目标，二者也不等同于 C 的 672 维坐标。因此 C 不能直接充当所有方案的统一失败原因。

## 3. C 的三处推理需要修正

### 3.1 332 个合格坐标和 skill=0.900 不是同一个集合的指标

从保存 JSON 重新汇总：

|指标|残差版|非残差版|
|---|---:|---:|
|合格坐标数均值|332.500 / 672|267.125 / 672|
|选中前 32 维的平均 skill|0.9002|0.8972|
|选中坐标线性类别探针|0.5750|0.5774|
|原始随机对照类别探针|0.8117|0.8117|

合格条件仅为至少 5/7 用户 skill > 0 且平均 > 0；0.900 是**前 32 维**的平均值。不能说近一半坐标都达到减少 90% SSE 的水平。skill 也是分坐标、分用户计算后平均的比例，不是总体重建误差一次性减少 90%。

另外，57.5% 是相对随机坐标较弱的类别探针成绩，不是“没有类别信息”。

### 3.2 raw 对照只排除一种残差化操作，未排除整个选择准则的倾向

两种版本仍然都用：

\[
\mathrm{skill}_j=1-\frac{\mathrm{SSE}_{\mathrm{predict},j}}
{\mathrm{SSE}_{\mathrm{class\ centre},j}+\epsilon}
\]

进行筛选。raw 取消了输入和目标的类别中心扣除，但基线分母仍然是已知真实类别后的类中心误差，top-32 的排名方式也没换。

如果一个坐标类别分离很强、类内变化很小，那么类中心分母会很小；一个已经能较好区分类别、但偶尔犯错的预测器，仍可能得到很低的 skill。相反，可精确预测的类别无关因素可以获得很高的 skill。因此 raw 结果接近残差版，不能逻辑上排除这种筛选倾向。

这个指标并非不能用：它适合回答“是否预测了类别中心之外的变化”。但不能把它直接当成“兼具判别性和可迁移性的最优评分”。两版记录的近零分母计数均为 0；上述问题也不依赖浮点意义上的近零分母。

残差版还使用 probe 用户的真实类别来中心化输入，所以其 skill 属于**标签条件下的诊断**，不是无标签部署预测性能。raw 版本确实去除了这项输入依赖，应肯定这个对照的作用。

### 3.3 PCA 对照无法给冗余造成的损失设定 6 pp 上限

`probe_diversity.py` 的 PCA32 是对全部 672 维进行线性组合；选中组只是 32 个 Right 时间坐标。因此两者的差异不只是“正交 vs 相关”。

PCA 基向量正交、拟合数据上的主成分得分不相关，不意味着类别信息最多，更不意味着在新用户上“多样性最优”。随机32→PCA32 的 +6.02 pp 只能描述这两个方案的差距，**不能作为选中集因冗余最多损失多少准确率的上界**。

原类别探针随机对照为 0.8117；多样性脚本更换了随机种子，随机对照为 0.8227。这不是同一组随机坐标自然“提高了”。两个脚本目前各折各用一个随机坐标集合，未给随机抽取的重复分布。

## 4. C 的“内层未见用户”还有选择复用

代码先汇总所有 7 个源用户的留一用户 Ridge skill，再选同一个 top-32；之后在这 7 个用户上重新进行类别探针 LOO。于是当前 probe 用户已经参与了坐标选择，尽管 logistic 分类器自身未用该用户拟合。

此外，固定的外层教师本来就训练过全部 7 个源用户；`predictability.py` 的注释和输出 caveat 已承认这一点。

因此，应称其为**固定教师下的源用户内部筛选诊断**，不能把它呈现为整个“教师学习→坐标选择→类别预测”流程对完全未见用户的无偏估计。这并不构成外层测试用户泄漏，但削弱了当前探针差距的泛化解释；偏差会朝哪个方向改变差距，尚未测量。

还应区分两种探针：当前分类器读到的是**真实教师坐标**，不是学生由 Right 预测得到的坐标。前者衡量所选目标的类别信息，后者才衡量该预测路径实际保留下来的类别信息。

## 5. B-SHUF 没有充分打断实例对应

`train_student.py` 在每个 32 样本 microbatch 内调用 `relation.py::shuffle_within_class`。函数仅在该批中拥有相同类别、相同用户的多个样本时交换目标；只有一个样本的组直接跳过。

对 B-SHUF 八折保存的采样数组，统计每折实际训练至 `stopped_epoch` 的所有样本呈现次数：

|外层用户|最多可能被更换目标的比例|至少保留原目标的比例|
|---|---:|---:|
|1|31.83%|68.17%|
|2|30.93%|69.07%|
|3|31.58%|68.42%|
|4|31.70%|68.30%|
|5|31.73%|68.27%|
|6|31.28%|68.72%|
|7|31.79%|68.21%|
|8|31.59%|68.41%|
|按呈现次数合并|31.58%|**68.42%**|

这是确定性上界/下界，不是 CUDA 随机置换的精确重放。拥有伙伴的组也可能在有限次尝试后保留固定点，或交换到数值相近的目标，所以实际破坏程度可能更小。

P0 报告记录有效样本比例为 100%，因此这里并非大量无效样本被屏蔽所致。

**可以保留：B-MV 相对 B-SELF 未发现收益。不能保留：因为 B-SHUF 与 B-MV 持平，所以实例级运动过程没有可用信息。**

若论文需要这条机制结论，正确做法是在整个外层训练集合内、按 `(class,user)` 分组预生成无固定点置换，再按样本 ID 查目标；不应受 microbatch 有没有伙伴限制。应记录 changed-target 比例和目标实际数值差异。若不准备提出实例对应机制结论，可以不补训练，只撤回该解释。

## 6. “所有通道为零”和“审计全过”的边界

### 6.1 不要把普通 KD 与教师均匀投影混为一谈

本次另外从历史 `results_clean/*predictions.npz` 重算了普通 KD 与幅相 CE 对照：

|历史协议|幅相 CE|幅相 + 普通 KD|KD 增量 / pp|
|---|---:|---:|---:|
|seed 2026|72.4127%|73.4174%|+1.0047|
|seed 2027|72.3968%|73.7964%|+1.3996|

旧协议 seed 同时改变训练/验证划分，不能称为当前固定划分下的纯初始化复验。这些数值也**不证明 KD 优于充分匹配的平滑基线**。但它们确实不应被改写为“普通 KD 从来没有正增益”。

教师均匀投影 74.61%、无教师类别自适应平滑 74.65%、全局平滑 74.77%，支持该投影/平滑方案没有额外教师贡献。要把普通 KD 的增益也归因于平滑，需要针对普通 KD 本身的匹配机制对照。更高的无教师平滑结果支持工程上优先采用平滑，不能单独证明两个方法的因果机制相同。

几条路线共享样本、用户、教师和编码器，应叫“多种迁移方案的系统比较”，而不是“六次相互独立的证明”。未做 C 训练也不能计为第六个训练负结果。

### 6.2 原审计通过不保证上述对照的因果效力

隐藏视角审计构造完整/破坏后的三视角数组，随后两次都显式切出 Right 输入模型。logit 不变验证了该评估封装的单视角输入约束；它不能自动覆盖所有上游预处理、目标构造和选择过程。本次没有发现因此导致的外层泄漏，只是在限制“审计全过”的含义。

梯度审计在分类损失与辅助损失合并反传后记录编码器梯度。分类 CE 本身也能使编码器梯度非零，所以这个检查单独不足以证明辅助损失贡献到编码器。代码图中存在该路径，但如果要做自动审计，应单独计算辅助损失对编码器的梯度。

当前源码与 run 保存的哈希比较：训练入口、关系函数、过程函数等本次关注的运行实现匹配；汇总脚本后来有修改，两个 run 记录的可预测性脚本版本也与当前不同。哈希差异已在独立 JSON 逐 run 保存，不能因脚本后来改过便宣称原始训练失效。

### 6.3 seed 和冻结记录应写准确

- 新协议 model_seed 改变初始化和 dropout 随机流，应称“固定划分与采样的训练随机性复验”，不是只改初始化。
- “8/8 用户改善”指先合并两个 seed 后的 A-SC 效应；不是两个 seed 各自均为 8/8。各 seed 分别是 6/8 正增益。
- 两个 seed、8 个共享训练数据的 LOSO 模型，以及反复探索过的数据，不能提供强独立确认；绝对准确率跨 seed 漂移也不是配对方法差值的噪声上界。
- `p1_frozen.yaml` 保留 `model_seeds: [2026]` 和 `not_run_in_p1: second_model_seed`，但实际补跑 2027。原文件应保留，另加追加记录交代补跑时间、当时已经看到的结果、A-TS 和 C raw/多样性等事后诊断；不宜回改原文件伪装成全部事先确定。

## 7. 对第一部分的实际决定

### 7.1 现在就能做的决定

1. **停止 A/B 组合与大范围调参。** 主对照的结果足以支持这个成本决策。
2. **停止当前 C top-32 方案的学生训练。** 它只选中了 Right 时间分支的一小部分，并没有产生值得直接投入训练的跨视角目标。
3. **保留幅相运动表征作为已验证基础，监督对比作为小幅辅助。** 不能因为做了 128 个 run 就把负结果自动升级成方法创新。
4. **第一部分暂用“单雷达跨用户运动表征与多视角训练信息利用的实证分析”之类的稳健表述。** 是否足以担任整篇硕士论文的主要创新，仍要结合第二部分和论文整体贡献判断，不能只凭实验量承诺。

### 7.2 如果还想花少量成本弄清 C，应先修诊断，不是直接加非线性网络

下面是可选择的新探索，**本轮未执行**：

|步骤|具体做法|回答的问题|
|---|---|---|
|C0-1 来源匹配|从 Right 时间分支的 192 维内重复抽随机32，另做时间区间覆盖匹配；至少报告多次随机抽取分布|57.5% 的缺口有多少来自比随机组少了隐藏视角/距离分支|
|C0-2 冗余控制|在同一候选来源内比较 top-skill32 与加入相关性惩罚/QR 选择的32；所有选择仅用 fit 用户|当前筛选是否反复选择少数通道，丢掉互补信息|
|C0-3 预测和判别联合检查|同时报告 skill、普通 R²、类间/类内结构，以及真实目标和折外预测目标各自的类别探针；报告多个固定维数|高可预测性是否真的与可用类别信息不能兼得，而非当前排名方式失效|
|C0-4 区分来源|将 Right、Left、Top 单独报告，再比较隐藏视角联合目标|到底是在做三视角训练权重迁移，还是补充该样本的隐藏视角观测|
|C0-5 防选择复用|对每个 probe 用户，只用其他源用户完成全部候选选择，再评价 probe；显式说明固定教师已见源用户|避免将选择与评价复用包装成整条流程未见用户结果|

如果仍使用固定外层教师，上述结果只能作条件于该教师的内部诊断。若要声称整条方法对新用户的泛化，需要连教师训练也排除相应评价用户；这成本更高，不必为了给已有负结果补一个漂亮解释而默认启动。

优先级：先 C0-1/C0-2 的轻量探针；若同来源、控制冗余后仍没有可用目标，就停。若出现可预测且判别的候选，再决定是否值得新建学生训练方案。所有选路都是已看过外层结果后的探索，必须另行冻结和如实标记。

### 7.3 建议替换原报告的总结段

> 在质量审计后的 UWB-Gestures 数据、Right 单雷达部署和 8 折 LOSO 设置下，跨用户监督对比获得约 0.44 个百分点的辅助改善。当前跨视角关系监督和融合运动过程监督，相对各自匹配的单视角对照未表现出稳定增量，因此停止进一步组合扩展。可预测教师坐标筛选集中于 Right 时间分支，其类别探针弱于全三视角随机坐标；由于坐标来源不匹配、选择与评价复用及冗余控制不足，该现象暂不能解释为多视角可迁移信息与判别信息不重合。现有证据支持当前若干迁移实现的局限，不构成单雷达无法利用多视角训练信息的证明。
