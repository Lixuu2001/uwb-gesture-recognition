# C0：来源匹配、去冗余、选择不复用之后的 C 重做

日期：2026-09-07。判据在运行前写定于 [configs/c0_frozen.md](../configs/c0_frozen.md)。
**性质：看过 P1 外层结果之后的新探索，不是预注册确认。**
起因是 [INDEPENDENT_REVIEW_20260907.md](INDEPENDENT_REVIEW_20260907.md) 指出原 C 诊断的
对照不匹配，以及我复算确认的"选中集 100% 来自 Right 时间分支"。

规模：8 个外层折 × 7 个 probe 用户 = 56 次评价。对每个 probe 用户，**全部 skill 计算和
坐标选择只用其余 6 个源用户**（在这 6 人内部再做留一），probe 用户直到最后打分才出现。
外层 test 折不进入任何一步。固定教师仍训练过全部源用户，所以这仍是**条件于该教师的
源用户内部诊断**。

## 1. 三个判据的结论

### Q1 来源混淆：判定成立，原 −24 pp 主要是来源伪影

把随机对照限制到与选中集同一候选池（Right 时间分支 192 维）之后：

|k|top-skill（同源）|随机（同源，10 次）|差|同源随机 ±1σ|落在 1σ 内|
|---:|---:|---:|---:|---:|---|
|16|0.5250|0.5472 ± 0.0269|−0.0222|±0.0269|**是**|
|32|0.5777|0.5930 ± 0.0214|−0.0153|±0.0214|**是**|
|64|0.6133|0.6145 ± 0.0153|−0.0012|±0.0153|**是**|

三个维数下，按可预测性选出的坐标与**同源随机**坐标在类别探针上没有可区分的差别。

原来那个缺口去了哪里，也一并定位了——它整个就是分支归属：

|k|随机（同源 192 维）|随机（全 672 维）|来源效应|
|---:|---:|---:|---:|
|16|0.5472|0.6941|**+0.147**|
|32|0.5930|0.8090|**+0.216**|
|64|0.6145|0.8597|**+0.245**|

也就是说，原报告的 0.575 vs 0.812 里，可预测性贡献 ≈ −0.015，**其余全部来自
"对照组能用 Left/Top 和距离分支的坐标，而选中组不能"**。原机制解释站不住，
撤回是对的。

附带一条：合格判据在这个池子里是**空过滤器**——56 次评价中 `eligible = 192/192`，
一个坐标都没被筛掉。原报告"332/672 合格"看起来是个筛选，实际上在 Right 时间分支内
没有起任何筛选作用。

### Q2 隐藏视角可预测性：判定成立，单雷达预测不了隐藏视角

逐坐标 skill（skill = 1 − 预测 SSE / 类中心基线 SSE，>0 才算比"只知道类别"强）：

|分支|平均 skill|最大|skill>0 的比例|skill>0.2 的比例|
|---|---:|---:|---:|---:|
|**Right 时间**|**+0.797**|+0.938|100%|**100%**|
|**Right 距离**|**+0.429**|+0.644|100%|91.4%|
|Left 时间|−0.139|+0.381|29.1%|7.0%|
|Left 距离|−0.128|+0.008|2.7%|0%|
|Top 时间|−0.531|+0.030|0.7%|0%|
|Top 距离|−0.324|−0.085|0%|0%|

四个隐藏视角分支的平均 skill 全部 ≤ 0，按冻结判据 **Q2 判定成立**。Top 分支尤其彻底：
时间分支只有 0.7% 的坐标 skill>0、最大值 0.030，距离分支一个正的都没有。

这同时把原来的选中结果变成了同义反复：选中集 100% 落在 Right 时间分支，
**因为那是唯一 skill 为正的分支**。教师 `use_fusion=False`、`xmv_layers=0`，
Right 分支本就是 Right 输入的确定性函数，可预测性接近 1 是架构的直接后果，不是发现。

**一个需要如实记录、但不要过度解读的例外**：Left 时间分支有 7.0% 的坐标 skill>0.2，
最大到 0.381。Left 与 Right 在几何上左右相对（−0.55 / +0.55 m），存在共享结构是合理的；
Top 则几乎完全不可预测。**这只是一条线索，本轮没有检验这批坐标是否携带类别信息，
也没有检验它能否支撑一个学生。** 不要把它写成"部分隐藏视角可迁移"。

### Q3 去冗余能否救回：判定成立，问题不在冗余

|k|top-skill|QR 去冗余|同源 PCA|同源随机|
|---:|---:|---:|---:|---:|
|16|0.5250|0.5542|0.6017|0.5472 ± 0.0269|
|32|0.5777|0.6003|0.6086|0.5930 ± 0.0214|
|64|0.6133|0.6160|0.6058|0.6145 ± 0.0153|

QR 去冗余相对同源随机的优势是 +0.007 / +0.007 / +0.002，全部远在随机抽取的标准差以内。
**在同一候选池内换一种不那么冗余的选法，救不回任何东西。**

### 关于停止条件的一处如实说明

`c0_frozen.md` 的停止条件第三款写的是"没有任何同源选择变体在类别探针上达到同源随机
均值"。按字面，QR（0.5542 > 0.5472）和 PCA（0.6017 > 0.5472）在 k=16 达到了，
**所以这一款字面上没有满足**。

但这一款当初就写窄了：QR 和 PCA 都不是**基于可预测性**的选择，学生也没法从雷达输入
算出它们，它们本来就不是 C 的候选方案。C 真正的变体是 top-skill，它在 k=16/32
低于同源随机、k=64 打平。我把这条记在这里而不是事后改写判据。

## 2. 预测路径保留了多少类别信息

除了在**真实**教师坐标上做探针，另报告在 **ridge 折外预测坐标**上的类别准确率
（分类器在 fit 用户的真实坐标上训练，在 probe 用户的预测坐标上测试）：

|k=32|真实坐标|预测坐标|
|---|---:|---:|
|top-skill 同源|0.5777|0.5771|

预测路径几乎无损地保留了这批坐标携带的类别信息——但那本来就只有 0.578，而且不优于
同源随机。**不是预测过程丢了信息，是这批坐标本身就没有更多信息可丢。**

## 3. C 这条线的结论

按冻结判据，C 停在这里：

> 在这个固定教师、这套池化表示和这类线性筛选下，没有找到既能由单雷达预测、
> 又比同源随机坐标保留更多类别信息的教师分量；而单雷达对隐藏视角分支的线性可预测性
> 为负。**不外推为任何关于多视角信息结构的一般结论。**

明确不能说的：

- 不能说"可迁移的不判别"。同源对照之后，可预测性对类别探针的影响是 −0.015，
  在噪声内；原来看到的落差是分支归属造成的。
- 不能说"多视角信息与判别信息不重合"。本轮只测了一个固定教师的一种池化坐标、
  一种线性回归、一种筛选准则。
- 不能说隐藏视角"完全不可预测"。Left 时间分支有 7% 的坐标 skill>0.2；只能说
  **分支平均为负，Top 分支接近全空**。

若将来还要动 C，唯一有意义的入口是 Q2 里那 7%：先查这批 Left 坐标是否携带类别信息
（同源随机对照 + 选择不复用），再谈要不要为它设计学生。这是新的探索，需要另行冻结。
