# 教师目标与标签平滑的关系

这是对当前实现的代数与只读诊断，不是新增性能结论。

设C的第y行对角为d_y，uniform矩阵保留该对角，将1−d_y均分给其他K−1类。标签目标q_Y=(e_y+e_yU)/2满足：

- q_Y(y)=(1+d_y)/2；
- q_Y(j)=(1−d_y)/(2(K−1))，j≠y。

因此该目标是类相关平滑，强度ε_y=(1−d_y)/2；它不包含指定类别之间的混淆偏向。ε只从Right训练用户的内部留一用户预测估计，原验证与测试样本不参与。

本损失为CE(e_y,p_S(T=1))+λT²KL(q,p_S(T))，λ=0.5、T=2。它保留硬标签CE并增加带温度的软目标项，不能直接声称与标准单项CE标签平滑训练完全等价。

固定同一学生logits时，将q_T替换为q_Y，软目标项对logits的梯度差精确为λT(q_Y−q_T)（teacher目标损失梯度减去label目标损失梯度；batch均值另除batch大小）。当前λT=1。因此训练目标接近意味着单个相同模型状态上的这部分梯度接近，但训练轨迹、早停选择和测试结果仍可能分化，需要完整的实际训练对照。

实测8外折教师在各自梯度训练样本上的平均真类概率T=2为0.9842，平滑后q_T与q_Y平均L1距离为0.0250。这个事实提示教师训练目标较接近标签目标；它不证明教师在测试样本上只输出标签，也不证明两种训练统计等效。

上述目标差异采用float64只读计算；实际bf16 autocast训练会有数值舍入差异，不能把分析数值理解成逐batch精确重放。

完整训练结果为：label_uniform 74.65%，teacher_uniform 74.61%，差值-0.04 pp、用户bootstrap区间[-0.31,+0.22]、3/8用户改善。该结果不证明两种方法统计等效，但在当前实现中未发现三视角教师的额外收益。
