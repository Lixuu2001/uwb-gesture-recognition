# 类别自适应平滑必要性消融：固定协议

三视角教师投影与无教师标签投影分别为74.61%和74.65%，当前实现未发现三视角教师的额外收益。新增本消融只回答：74.65%的提升是否来自训练用户折外估计的类别差异，还是普通全局标签平滑即可解释。

## 唯一变化

复用Right幅度+相位输入、seed2026、8折LOSO、原train/val/test、相同初始化、批顺序、优化器、CE、温度2、KD权重0.5、最多40 epoch、patience 8和验证CE选模。

类别自适应版本使用每类折外自类概率d_y；全局控制在每一外折按训练样本类别数加权得到d_bar，再令所有类别的矩阵对角均为d_bar，其余概率均分到其他11类。这样两者在该外折训练样本上的平均平滑概率质量相同，只移除类别间强度差异。验证和测试标签不进入d_bar。

## 判据

主比较adaptive-label-uniform减global-label-uniform。只有平均至少+2.00个百分点且至少6/8个留出用户改善，才将“跨用户类别难度自适应”保留为第一部分的方法贡献；否则将74.65%解释为常规正则化收益，停止扩展该候选。区间包含零只报告未发现增量，不声称统计等效。
