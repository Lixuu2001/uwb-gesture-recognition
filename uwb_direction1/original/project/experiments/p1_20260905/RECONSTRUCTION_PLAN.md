# 单视角补全三视角特征：实施与评估计划

用户已授权自行确定方案并执行重建实验。只使用既有公开数据。采用先验证条件特征重建的路线；原始回波生成成本更高且逐点误差难对应分类，真实三维轨迹没有独立真值，均不能混称已实现。

## 冻结协议

- 复用已核查的质量掩码、8 折 LOSO 和 seed=2026 的 train/val/test 索引；全部 L/T/R 均测试。
- 每外折复用该折 teacher_concat 的共享编码器，冻结所有参数。该编码器没有跨视角 attention；逐路特征只能依赖自身输入，增加数值独立性检查。
- 将 temporal 90×32 token 按9步均值池化成10×32，spatial 189×32 按9格池化成21×32，每视角得到992维有序特征；标准化只拟合 train。
- 此为冻结编码器的特征补全受控实验，不能将新读出头与此前端到端单视角结果的差值归因于重建。
- 新分类头固定 2976→256→12，GELU、dropout0.1；所有单视角对照保留真实视角所在槽。
- fixed_mask：训练和测试始终只提供同一个视角，另两槽为标准化后的零；不是只在测试丢路的病态基线。
- capacity：单视角992→256→1984解码器预测两槽，只有CE监督；同结构、同初始化的 joint 使用CE+0.1*MSE监督真实缺失特征。
- pure_recon：同样解码器只优化MSE，接冻结的真实三视角分类头；与该头的零填充推断单列，不能代替fixed_mask公平对照。
- real3：同一新头输入真实三路，作为对应表征上限。
- Adam1e-3、weight_decay1e-4、batch256，最大40epoch；12epoch后patience8，分类臂按验证CE，pure_recon按验证MSE选checkpoint。每臂同一shuffle RNG；不调整测试集超参数。
- 部署 forward 只接受[B,992]，真实缺失特征仅用于train损失以及训练结束后的重建质量评估。
- 汇报accuracy、macroF1、逐被试差值、缺失视角按train均值基线归一化的MSE、参数量、重建在同等容量控制之上的收益。对满足平均至少+2pp、至少6/8被试改善的joint vs capacity候选补第二种子读出试验（编码器仍为原外折冻结权重，明确这一限制）。
