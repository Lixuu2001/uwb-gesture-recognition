# 多视角辅助跨人元训练完成记录

2026-09-08：已完成正式实验与独立核验。当前固定配置未获得单 Right 准确率提升，按预设门槛停止扩展。

- 用户等权准确率：A0 71.467424%、A1 71.467424%、A2 71.394508%、A3 71.394508%。

- 预设门槛：至少 +2 个百分点、至少 6/8 改善，且 A3 高于 A0 和 A2。未通过，因此不启动条件性的第二种子与配对打乱扩展。
- 41 项测试通过。全部 32 组末轮参数更新检查通过；每种方法有 5/8 用户按验证交叉熵选择公共初始化（第 0 轮）。相同预测不代表训练未执行。

- 结论限于本轮固定网络、种子、采样预算和验证映射；未实施的时序对齐、风格扰动等建议没有效果结论。旧实验和其他项目修改未纳入本轮改动。
