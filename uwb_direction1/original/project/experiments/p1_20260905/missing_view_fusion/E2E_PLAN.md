# 编码器参与更新的缺失视角融合验证

用户在确认冻结特征筛选的限制后要求继续。本轮先执行第一条路线的端到端训练；不是重复冻结特征读出，也不一次叠加三种机制。

## 设计与比较

- 继续使用质量保留 9300 行、8 折 LOSO、固定 split_seed=2026、训练用户内部验证。不能称为新用户独立验证调参或全新数据确认。
- 输入仍为幅度＋相位 `[B,V,90,378]`；模型为既有双路编码器、1664 维分段池化、缺失标记、小型融合头。使用初始训练特征的每视角 mean/std，训练中固定这些统计量，但编码器参数可训练。
- 每折编码器从 Right-only 的 `sv_R_label_global_s2026_h*.pt` 初始化。分类头从 model_seed=2026 新初始化，不从此前各臂各自最优头初始化；两臂分类头及编码器初始值相同。
- `E2E_R`：只读取 Right。为匹配编码器计算形状和 dropout 随机数消耗，训练时内部复制为三个槽位，仅 Right 槽位参与分类，另外两槽位用缺失标记。
- `E2E_MV`：读取同一次动作的 Left/Top/Right，编码器每批前向一次；同一批特征分别用于 R、LR、TR、LTR 四个分类前向，分类损失平均。编码器及融合头均接收梯度。
- 两臂使用相同可学习缺失标记，R 臂也训练缺失槽位的标记，避免把结构差异混入信息来源比较。不加入对比损失；第一步直接检验三视角联合分类对可训练表征的影响。
- 推理 API 仅接受一个 Right 视角，不提供隐藏信号、隐藏样本特征或真实标签。单视角调用可以在网络 eval 模式下与训练图的 R 子集直接比对。

## 优化与预算

- Adam，编码器学习率 1e-5，融合头学习率 1e-3，weight_decay=1e-4；继承全局平滑分类目标；有效 batch=128，microbatch 以显存试运行决定（初始 16，两臂一致）。
- 最多 40 epoch，最少 12，patience=8；按 Right 验证 hard CE 选模型。初始零分类头作为 epoch 0 候选保留，但不把它称为原始分类器。
- 模型种子 2026，采样种子 7777+fold。学习率和停止条件在测试结果产生前固定。不按外层测试效果改参数。
- 先完成模型梯度、数据隔离和训练／导出测试；一折一轮流程测试测量耗时与显存，再顺序运行八折两臂。保存优化器、随机状态和下一轮编号，允许中断后逐轮恢复；完整运行哈希核验后跳过。
- 首轮门槛仍为相对匹配对照 +2 点、至少 6/8 用户改善，同时比较原始分类器 74.77%。若通过，追加第二初始化及同用户同类别全局错配配对控制；若未通过但明显尚未收敛，报告预算／选择限制，不将其概括为三个方向均无效。

## 必须验证

1. 单独对完整三视角分类损失反传，Left/Top 输入和编码器至少一个实际参与前向的权重获得非零梯度；优化后编码器权重改变。
2. R 臂不能读取真实 Left/Top；验证／测试只传 Right 张量。模型不使用融合过的隐藏测试缓存。
3. 两臂初始编码器、融合头、统计量和采样顺序相同；记录源码、原始数组、原始检查点、划分、模型初始化和最终编码器哈希。
4. 预测 argmax／准确率／macro-F1、最优验证 CE、划分及训练中断恢复状态均可重算；导出模型在真实 Right 输入上与保存的预测一致。

实现新增到 `missing_view_fusion/e2e/`，旧冻结实验文件和结果保持可追溯。该设计是本项目端到端缺失视角联合分类验证，不冒称完整复现原论文。
