# 2026-09-07 直接分类读出补充

本补充在直接分类实验启动前记录。初始残差试验的前几折，验证集均选择 epoch 0；例如第一折，原始验证 CE 为 0.14550，新增训练后约 0.151–0.154。训练损失正常下降。这一现象表明：在已经拟合训练数据、并按同一验证集选择过的分类器上叠加修正，没有改善验证 CE。它不能单独检验小型融合特征是否有判别能力。

因此保留残差第一路线的全部 40 个结果，并按此前讨论过的直接融合分类方案，补充独立输出目录 `runs_direct`：

- 固定同一 Right 幅度＋相位编码器、1664 维分段池化、训练划分、数据次序、全局平滑目标和参数配置。
- 唯一统一改变：分类 logits 直接取融合头输出，不再加原始分类 logits。Right-only 对照同步改变。初始零 logits 仍作为 epoch 0 候选，明确不等于原始分类器。
- 三条路线仍依次执行：缺失感知融合 5 组、共享／专属 3 组、原型字典 3 组，每组 8 折、首个模型随机种子 2026。
- 原始 74.77% 分类器保留为单独参照。改进必须先超过匹配的直接读出对照，并检查是否超过原分类器；不能以压低基线的方式报增益。
- 阈值、停止规则和验证方式不变。没有根据外层测试准确率选择新的超参数。
- 这仍是冻结编码器的小规模筛选，不等于各论文端到端方法的完整复现。如果均无有效提升，结论只限于本实现和协议。

残差与直接读出结果分开保存；不把两类输出合并计算同一组平均值。
