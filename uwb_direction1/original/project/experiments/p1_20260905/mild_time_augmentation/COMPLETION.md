# 温和时间增强：完成记录

本轮已完成实现、16 次正式训练、独立指标核算和部署模型重放。平均准确率从 71.2913% 提高到 72.2134%，增加 0.9222 个百分点，6/8 位用户改善。宏 F1 从 70.1895% 提高到 71.1899%。

这是单种子下的小幅正向结果，未达到预先约定的“平均至少 +2 个百分点且至少 6/8 位用户改善”开发门槛。用户配对 bootstrap 的准确率变化 95% 区间为 [-0.0911, +1.9583] 个百分点，跨过零。本轮停止该固定设置的扩展调参，保留代码、模型和证据；暂不将其作为已验证稳定的新默认方案。没有据此否定其他时间增强方法。

## 实际实现

- 输入为 Right 雷达去静态杂波后的有符号信号，每段 90 帧。时间映射为 `g(t)=t+a*sin(2*pi*t/89)`，保持首尾位置和时间顺序。
- 训练时每个样本有 50% 概率保持原输入，其余样本等概率使用 `a=-2` 或 `a=+2`。最大时间位移约两帧，不裁剪、不反转，也不额外叠加幅度噪声。
- 先对原始有符号信号做线性插值，再用原处理流程重新计算幅度图和相位运动图。缓存没有需要拟合的参数；训练读取仍受用户划分保护。
- 模型、损失、学习率和批次顺序沿用原训练流程。增强采用独立随机序列，不消耗模型或数据打乱的随机状态。验证集和主要测试集均使用干净输入。
- 部署仍为原 Right 分类器，不增加分支或额外推理输入。

## 实验范围与对照

质量筛选后共 9,300 个实例、8 位用户。每折六位用户训练，一位完整用户验证，一位完整用户测试；八位用户轮流作为测试用户。模型种子固定为 2026，最多 40 轮，按干净验证集 CE 的首次最小值选择模型。

发现旧环境记录 NumPy 2.0.1，而当前为 2.0.2，因此在正式结果产生前决定重新训练全部 CONTROL。最终 CONTROL 与 AUG 均为当前同一环境下的新训练结果，未拼接旧模型作对照。两组共同复用的平滑矩阵严格来自相应六位训练用户内部的 OOF 预测。

CONTROL 共训练 153 轮，AUG 共训练 145 轮；日志记录的训练轮耗时合计约 65.1 分钟，不包括准备和最终审计。AUG 的累计训练读取为 1,011,700 次，其中原输入 505,708 次，负向时间扭曲 252,933 次，正向时间扭曲 253,059 次。

历史约 74.77% 的实验使用不同的训练/验证划分，不能与本轮 72.21% 直接相减判断进退。本轮对照也没有接上此前 A0 的额外训练阶段，结论只来自本次同配置 CONTROL/AUG 配对。

## 验证证据

- 22 项增强和审计测试通过。无增强短跑与原短跑的验证及测试 logits 最大误差均为 0。
- 全部 9,593 条原缓存样本的零幅度时间变换，与原处理结果完全相同；两种增强缓存均为有限数值。
- 实际模型断点恢复后，下一轮增强序列、训练记录和完整模型状态与不中断运行完全一致，验证输出最大误差为 0。
- 正式审计覆盖 16/16 个模型，核对数据划分、来源文件、初始化、采样及增强轨迹、模型选择、参数更新和保存文件；状态为 verified，无错误、无缺失。
- 独立 NumPy/sklearn 核算没有调用项目指标汇总函数，逐一核对样本编号、标签、准确率、宏 F1 和验证 CE，结果一致。
- 16 个导出的 Right 模型独立完成 37,200 次干净验证/测试预测，logits 最大误差为 0，类别预测完全一致。
- 模型选择结束后另完成 37,200 次固定扰动预测。`a=-2` 时 CONTROL/AUG 准确率为 70.537%/71.897%（+1.360 点）；`a=+2` 时为 70.963%/72.443%（+1.480 点）。这是与训练增强同族的信号空间测试，不能解释为已验证真实手势速度变化的鲁棒性。

八个训练折存在重叠，本轮只使用一个模型种子，且这些用户数据已经用于此前开发。bootstrap 区间仅描述当前固定协议下的不确定性；不能替代新种子、新用户或现场测试。
