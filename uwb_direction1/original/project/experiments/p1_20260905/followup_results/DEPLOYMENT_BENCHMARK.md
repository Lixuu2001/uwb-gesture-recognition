# 单雷达推理成本

硬件：NVIDIA GeForce RTX 4060 Laptop GPU；PyTorch 2.7.1+cu126；batch=1，bf16 autocast，30次预热。

|配置|参数量|网络中位ms|网络P95 ms|CR预处理→GPU→预测读回中位ms|CUDA峰值MiB|
|---|---:|---:|---:|---:|---:|
|sv_R_off|18,909,420|3.401|3.973|3.988|141.6|
|sv_R_concat|31,313,868|3.446|4.227|4.637|213.5|
|sv_R_concat_kd|31,313,868|3.506|3.961|4.400|213.5|

KD在训练期增加教师，部署模型与concat完全同结构。两模型微小时延差异来自重复计时波动，不解释为KD加速。
参数量变化相对幅度基线为约+65.6%；输入宽度从189增至378，不应称低成本不变。
上述计时不包含4.5秒数据采集、原始杂波滤除和连续提交延迟；不能据此声称完整系统毫秒响应。
