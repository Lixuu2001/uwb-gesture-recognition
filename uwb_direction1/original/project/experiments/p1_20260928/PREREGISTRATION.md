## A：九个片段校准

假设：源用户中低维、与动作类别相关的用户偏移，可由目标用户的三类动作估计，并改善其他已知动作。

- 支持类只从共同类别 [0,1,2,4,5,6,7,8,9] 选择。以源用户模型的 D-optimal 信息准则选择三类，固定正则 I；并列按字典序。不利用目标查询标签挑选。
- 每位验证/测试用户、每类用固定 RNG(91000+user*100+class) 划分20个支持候选与其余查询。20个支持重复，seed=92000..92019，每个被选类取3条。查询固定且与全部支持候选不交；所有方法同一查询、同一支持。
- 源用户类均值残差使用缺失掩码的 rank2 SVD/迭代填补，最多100次，容差1e-8。缺失单元不作零观测。用户因素仅统计含义。
- 预测保留原始判别 logits，以共享对角类内方差标准化后的 Gaussian 均值移动似然比校正：logits_y + tau * ((z-mu_y)·delta_y - 0.5||delta_y||²)。这是实施前明确的 readout 补充：tau=0 必须精确回到冻结分类器，避免将弱原型读出误认为校准效果。
- 对照：冻结分类器；冻结源原型（诊断）；仅支持类别中心移动；共同平移；以类中心为输入预测中心偏移的 ridge affine；rank2 用户因素。原型移动基于各类支持均值；共同平移使用支持残差均值；ridge affine 使用含常数的源类中心拟合残差；用户因素解正则最小二乘。额外参考：所有可用类别各3条，标明预算30/33/36，不能作同预算胜利。
- 超参数预定 lambda=[0.1,1,10,100]，tau=[0,0.125,0.25,0.5,1,2]；仅验证用户20个支持重复的未校准类 macro accuracy 选择，平分依次更小 tau、更大 lambda。禁止按外层测试选择方法；报告验证选择的简单方法组合与各固定方法。
- 主指标：未参与校准的已知类别 macro accuracy；另报全类别与支持类别、最差用户、类均值误差降低、支持重复内方差。重复先在用户内平均，8用户配对 bootstrap 10000次（seed20260928）；不把160个重复当160名用户。
- Go：rank2 相对验证选出的同预算简单对照 >=2pp、>=6/8用户改善，同时优于冻结分类器、无用户平均跌幅超过2pp。否则停止该复杂机制；若简单校准明显有效，可保留更简单路线，但不宣称低维机制成立。只有通过才追加 seed2027 和小型残差 adapter 强对照。

## B：固定多雷达预算

- 第一步必须给出 L/T/R/LT/LR/TR/LTR 七种真实输入子集的同协议预测。优先独立训练共享编码器、均匀子集采样模型；源六人训练，验证CE在七子集取均值，外层测试完全隔离。相同优化上限，不把历史7人训练或开放集结果混入新表。
- 若均值融合明显弱于历史 concat 能力，必须标为架构限制，不推断真实多视角无价值。先导只评价此明确模型。
- 对照为验证选出的固定一/二/三路、匹配平均视角数的固定随机混合、仅已观测 logits 的置信度/熵级联。全部包含先观察一路的成本；oracle 只作不可部署的空间诊断。
- 先做固定子集与 oracle 诊断，若相对最强简单策略没有 >=2pp 可利用空间即停止 learned policy。若有空间，再冻结策略训练方案；不得用外层测试标签训练收益预测器。源内独立用户预测或另留未用于编码器拟合的用户产生价值标签，任何方案修订在训练策略之前记入 amendment。
- 策略允许 stop / add one / add both，需考虑负增益及双路协同；绝不可读取未请求视角特征作选择。目标平均处理路数<=2，>=2pp 胜过同成本简单对照且>=6/8用户正向，与3路差距<=1pp。真实 GPU/CPU 延迟、编码复用和策略开销另测。
- 三部硬件仍安装，90帧片段已同步采集；只宣称推理/处理预算，不宣称采集功耗减少或动作结束后可再采同一动作。
