# 条件执行：预测额外视角是否值得处理

冻结时间：2026-09-28；正式多雷达模型尚未开始训练、未查看任何正式预算结果。只在 AMENDMENT_003 的两项oracle空间门槛均达到时执行。本页不是已完成成果。

1. 外层八用户和已选多雷达模型保持不变。策略不使用外层测试标签。源六人已经参与编码器梯度拟合，不直接拿其过度乐观的训练误差教策略。使用本折整人验证用户的配对预测产生收益标签；编码器没有用此人的梯度训练，但曾用其平均CE选checkpoint，这种内部复用明确作为限制。最终效果仍在完整未见测试用户评价。
2. 验证用户每类别按 RNG(33000+fold*100+class) 随机划分60%策略拟合和40%策略选成本价格。首路和固定级联仍沿用已冻结的验证选择。每种策略获得相同拟合/选价ID。
3. 决策输入只含当前已观测子集的12维softmax概率、归一化熵、第一第二大概率间隔，共14维。没有查询标签、未请求视角特征、样本ID或用户ID输入。
4. 第一状态的动作是stop、增加另一路之一、同时增加剩余两路。对每个追加动作，训练目标为加入后是否分类正确减去当前是否正确，取值-1/0/+1。选择预测收益减去price×追加路数最大的动作；平分选择stop/较少路数/较小子集编号。双路状态可stop或增加最后一路，用对应真实收益拟合，保留已计算特征。
5. 基线：按当前预测类别分组、用20例等效强度向全局均值收缩的平均收益表；候选：ExtraTreesRegressor(n_estimators=200,max_depth=4,min_samples_leaf=20,random_state=2026,n_jobs=1)。首状态用多输出回归，两个双路状态各用单输出回归。参数固定，不作模型架构搜索。
6. price网格固定[0,.005,.01,.02,.05,.1,.15,.2,.3,.4,.5,1,2]，在40%内部验证上选择平均路数<=2时macro accuracy最高者，平分优先实际路数更少、更大price。两种策略分别选择；主候选ExtraTrees不根据测试选择赢家。记录选择文件之后再评价目标。
7. 必须比较已经冻结的固定混合、置信度/熵级联以及新增类别收益表。类别收益表和ExtraTrees用相同内部数据预算。报告候选真实测试路数，不能用测试正确率重新挑price。固定混合采用候选实际成本为上限；级联主结果同时列出其实际成本，另可在验证曲线上按价选择近似成本作描述，不以此偷换精确同成本胜利。
8. 继续门槛仍为：平均真实路数<=2；相对强简单对照>=2pp、至少6/8用户改善；距离真实三路准确率<=1pp。若不同策略实际成本不足以公平比较，按未通过处理，不拼凑结果。CPU策略耗时与按需编码的总耗时必须测量，若总耗时没有下降，不能宣称更快。
9. 8用户配对bootstrap只作为探索性不确定性描述；不把样本数或类别数当独立用户。该先导只验证一个固定低复杂度收益预测器，不宣称穷尽所有主动感知算法，也不宣称硬件或采集功耗减少。

只在读取真实追加视角之后才允许使用其预测；记录所有路由动作和cost。即使算法未通过，保留七固定子集、简单策略、oracle和费用表，以说明失败发生在信息空间、收益可预测性还是运行成本。
