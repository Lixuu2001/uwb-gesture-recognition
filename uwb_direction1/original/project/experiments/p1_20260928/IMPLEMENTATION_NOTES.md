# 实现验证记录

所有试运行目录（smoke*）与正式研究结果分开。试运行只检验程序，不进入性能表或GO判断。

2026-09-28：原始独立视角编码虽然数学上不混合视角，但CUDA BF16将多视角合成不同批形状时，首16条验证记录的单路logits与全视角缓存产生最大0.00390625的浮点差异；这16条argmax未变化。正式多雷达训练前改为逐视角、相同B×1批形状经过encoder与projection，再拼接特征。更新后七子集direct/cache逐位相等，权重拓扑不变。这是数值执行一致性修复，不基于目标准确率改结构。

断点恢复额外检查：CPU连续两epoch与在第一epoch后中断恢复，模型、Adam、采样器和RNG轨迹一致。progress保存后、单epoch日志写入前的中断窗口可能缺日志，现恢复时从history回填；不重跑epoch，不改变选择状态。

研究报告将区分GPU基础模型训练、低维校准、固定多雷达模型、选择策略的结果和成本。跨路线的直接准确率描述另用单雷达预定查询ID对应的共同样本；各自主要指标和GO规则保持预注册定义。
