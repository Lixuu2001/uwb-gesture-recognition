# 单雷达部分动作校准与多雷达预算识别：可否决先导报告

本报告由逐样本预测、来源身份、冻结选择文件和实测记录重算。所有科学结论以本轮8名研发用户、seed=2026和既定停止条件为范围；报告生成不重新训练模型，也不修改原始产物。

## 结论与投入判断

A 的 rank2 用户因素结果为 **STOP_LOW_RANK_MECHANISM**。未校准已知类准确率为68.951373%，验证选择的简单校准为72.751147%；差值-3.799774 pp，1/8名用户改善，探索性用户重采样95%区间[-9.879193, -0.208059] pp。

B 的七子集共享模型中，固定LTR为93.441667%，固定TR为90.583333%，逐折验证选出的固定两路为89.536932%。固定TR是看完开发结果后的组合描述；验证选两路才是独立于目标标签的预定配置规则。

主级联为91.920833%，实际平均2.0046155303路。该成本按未舍入数值判断；显示为约2路不能使它通过严格的2路约束。

ExtraTrees 条件策略结果为 **STOP_VALUE_POLICY_MECHANISM**：准确率90.863258%，实际平均2.0078731061路；相对主级联-1.057576 pp，0/8名用户改善。距固定三路-2.578409 pp。

**停止扩展本轮两个未通过的复杂机制。保留真实多雷达观测作为后续系统的候选工程基础。** 本先导未找到可作为主创新的有效机制；普通固定融合的工程价值、oracle信息空间和事后选组合都不能替代新机制成立的证据。本轮不在看过目标结果后继续搜索参数以补出正结果。

## 数据、实验单位与比较边界

数据来自同一 UWB 配对片段库：质量过滤前9593条，保留9300条，输出词表为12个已知类别。每折留1名用户测试、循环取下一名用户验证、其余6人训练；8折测试用户依次为HV1–HV8。HV2的零基类别10和11、HV6的类别3因既定质量规则缺失，不补造。G12对应零基标签11，是空类（idle）。

主准确率是先在每名用户实际存在的类别上平均各类召回率，再对8名用户等权平均的 macro accuracy。处理成本先对每名用户的样本求平均，再对8名用户等权平均。支持抽样20次先在用户内平均；bootstrap只重采样8名用户，10000次，seed=20260928。百分比写为%，准确率差写为百分点（pp）。多次支持抽样不是160名独立用户，9300个片段也不是9300个独立统计单位。

A固定查询共7440条，支持候选池与这些查询完全不交；B的主结果使用全部9300条测试记录。跨路线只在A的7440条查询上另作描述，逐位核对同折ID、标签和用户角色。A的“未校准已知类”主指标不能直接与B的“全部已知类”主指标相减。

### oracle机会与机制验证分开

oracle在成本上限2内的准确率为95.045455%；比固定混合高5.508523 pp，比主级联在该级联实际成本下高3.124621 pp。两项机会门槛的决定是POLICY_PILOT_WARRANTED，仅用于决定是否启动条件先导，不代表策略机制成立。

oracle的范围仅为当前冻结分类器、验证选出的首路、向包含首路的子集单调追加观测的动作族；保留原先正确的预测，按最低新增成本挽救错误，并可用分数随机化满足平均预算。它不是所有重新训练模型、丢弃已见视角或任意感知策略的普适信息上界。

## 局限、文献依据与项目衔接

这里只有8位研发用户、一个模型种子，没有外部用户、跨天或自然连续流确认。各折训练用户重叠，用户bootstrap区间仅为探索性重采样描述，不构成独立确认性统计推断。所有类已在源训练词表内，A研究的是新用户的部分已知动作支持，不是从未见过的新类别学习。

策略验证用户未用于编码器梯度更新，但曾用于选encoder checkpoint，之后又用于策略拟合和选价；这种内部复用限制需保留。收益模型拟合和价格选择仅使用验证用户，selection先保存再进入该策略目标评价。但是否启动条件策略的预定oracle机会门槛和独立重算确实使用目标标签；不能声称策略运行前从未读取任何目标标签，也不能把条件先导视为完全未经探索的独立确认。

文献支持本轮问题与候选机制，不证明本数据集有效性：[Task-Specific Adapters（CVPR 2022）](https://openaccess.thecvf.com/content/CVPR2022/html/Li_Cross-Domain_Few-Shot_Learning_With_Task-Specific_Adapters_CVPR_2022_paper.html)提供跨域少样本适配背景，但原任务含未见类别/域；[Acquisition Conditioned Oracle（ICML 2024）](https://proceedings.mlr.press/v235/valancius24a.html)提示需要考虑联合信息价值；[Explainability-driven Ranking（ICML 2025）](https://proceedings.mlr.press/v267/guney25a.html)说明个例特征获取与策略学习已有研究；[AFA Evaluation（JMLR 2025）](https://www.jmlr.org/papers/v26/23-1635.html)提示离线重放评价的假设边界。没有据相邻文献标题声称已完整复现或本轮首创。

旧稿30的“自适应省22.7%”不能继承为本轮精度或效率结论：原24第3.2节X2b指逐样本oracle留出视角测距误差中位数由86.4 mm降至66.8 mm的相对改善，不是已训练可部署策略的分类准确率提升，也不是处理路数或时延减少22.7%。
