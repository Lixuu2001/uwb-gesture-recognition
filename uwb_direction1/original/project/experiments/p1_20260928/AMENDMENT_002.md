# 实施细节补充 002：校准评价约定

2026-09-28，任何正式校准结果计算之前；只运行了独立的未训练充分 smoke 模型。

- 网格准确率相差不超过1e-12时视为浮点意义的平分，再按更小tau、更大lambda选择；简单方法之间同样使用1e-12容差并按预定顺序打破平分。避免约1e-16的求和差异改变平分规则。
- GO门槛的百分点比较使用1e-10 pp数值容差，避免0.70-0.68的浮点表示被误判为低于2pp；不足1.999pp的情形仍明确失败。该容差只是计算精度处理，不是统计或科学门槛放宽。
- 全类别每类3-shot参考使用验证用户的全类别macro accuracy选参数，再在测试时同时报告全类别和原九样本路线的未校准类别子集。它与主路线的验证目标不同，预算也更高（30/33/36），只作参考，不进入低维因素机制的同预算GO比较。
- 类中心MSE使用目标查询类均值作事后机制诊断，绝不用于模型、支持类别或参数选择；它衡量tau缩放判别校正之前的原始估计中心。参考方法的MSE同样在原九样本路线未校准类别子集计算。
- 保存 validation selection 后才构造目标用户的支持候选和查询分区，便于审计依赖顺序。目标的输入档案中保留标签供评价，不代表训练或调参使用它们。
