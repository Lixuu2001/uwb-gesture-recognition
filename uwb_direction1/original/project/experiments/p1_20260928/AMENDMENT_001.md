# 实施细节补充 001（结果揭盲前）

2026-09-28 22:44（北京时间）。基础模型已开始训练，尚未运行任何目标用户校准或多雷达评价。以下固定实现细节不基于目标性能选取。

1. 用户因素载荷 B 取 masked-SVD 的 V*S/sqrt(源用户数)，使单位潜变量对应源用户经验尺度。PCA 后共享对角方差为所有源例子相对均衡源类别中心的平方残差均值，绝对下限1e-6；它包括源用户之间的类内变化，不解释为传感器噪声。
2. 多雷达模型用各真实视角的共享256维激活，按固定 L/T/R 槽位拼接，并附3维可见掩码，融合头 Linear(771,256)-GELU-Dropout(0.1)-Linear(256,12)。未观测槽位严格置零；决策阶段不读取被遮蔽的输入。共享特征网络初始化为本折新训练的 Right 分类器，并保留其前两层 head；额外融合阶段更新所有有效网络权重。编码源用户仍为相同六人，不能加载任何其他外层折的模型。
3. 多雷达每个有效 batch 用均匀随机一个非空子集；仅编码所选真实视角。七种组合概率相同；单个 epoch 样本遍历一次。Adam lr1e-4、wd1e-4、batch128、micro16，最少12最多40 epoch、patience8；按验证用户七子集 CE 均值取最早最小。BF16 autocast、MATH attention。保存初始候选、每epoch恢复状态和选择状态，seed2026。此模型是普通子集训练对照，不将其本身作为创新。
4. 七子集验证可先将三路独立编码，再分别运行融合头；这只用于离线完整评估。部署成本必须以直接读取所需子集的执行路径测量，不能把离线三路缓存说成一路推理。代码测试缓存子集输出与直接子集输入相符，并记录数值容差。
5. 分别报告本轮新增融合训练成本与已复用 Right 训练成本。七子集模型是本轮共享模型的比较空间，不等于各子集分别从零训练的最优上限。
