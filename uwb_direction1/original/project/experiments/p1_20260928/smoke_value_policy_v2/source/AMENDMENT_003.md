# 实施细节补充 003：固定子集和预算基线

2026-09-28，多雷达模型尚未正式训练，目标预算结果尚未计算。

- 七子集顺序固定为L/T/R/LT/LR/TR/LTR。单路起点和后续固定两路组合依据验证用户macro accuracy选择。
- 简单级联分别考察softmax最大概率和归一化熵。在单路、两路不确定性的验证集0..100%（间隔5%）分位数以及总是继续/总是停止边界上穷举阈值。根据验证集准确率在预算1、1.25、1.5、1.75、2、2.25、2.5、2.75、3内选择；平分优先更低处理路数。预定主预算2不变。
- 固定随机混合允许最多两个固定子集之间随机化，按验证准确率选择最优混合。报告随机化的精确期望准确率，避免额外随机抽样误差；分类标签不会决定对某个测试片段选哪一路。
- 实际测试处理路数可能超过验证预算，必须报告真实成本。与固定混合配对比较时，将实际路数设为其成本上限；混合组合仍由验证准确率选择，不看测试正确率。若更便宜的固定方案验证表现更好，则保留它，同时报告其更低实际成本；称为“同一成本上限内的固定混合对照”，不声称成本必然严格相等。此约定由合成数值审查发现，在正式结果产生前固定。
- Oracle从验证选出的首路出发，在包含首路的预测子集中，用真实标签判断是否可以纠正单路错误，并以最少追加路数挑选可纠错样本；有利于它的分数随机化仅用于可利用空间上界。它保留原本正确的单路预测，不强行加路，允许必须同时增加两路的情况。其结果不可部署，且只对应本轮模型和此动作空间。
- 固定子集分析若显示oracle在均值2路约束下相对固定混合至少有2pp空间，再开展预先另行冻结的价值预测策略。不能把oracle得分当成学习算法成绩。
- 同时检查主置信度/熵级联在其实际成本下离oracle至少2pp；只有两项空间条件均达到才进入学习策略先导。级联成本若偏离2路，明确标出该诊断的成本，不能把它计为已满足部署预算。
