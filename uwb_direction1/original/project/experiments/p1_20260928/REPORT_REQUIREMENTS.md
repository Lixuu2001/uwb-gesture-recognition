# 最终报告生成约定

主假设、主指标与停止条件仍使用 PREREGISTRATION 及结果揭盲前的 amendment。本页约定报告展示与补充描述，不增加可用来翻转 GO 的指标。A 已完整运行且主门槛未通过；B 尚未完成。

1. 从逐样本 predictions、selection、result 和源数据身份重算表格，验证摘要一致，拒绝 smoke、缺折、重复/错误 ID、缺少或改变的产物。八位用户为统计单位，支持重复在用户内平均。所有百分数区分百分比与百分点。
2. A 主表报告未校准已知类、全部已知类、被校准类三种 macro accuracy；基线、源原型、三种简单校准、低秩因素与高预算参考都保留。高预算参考不是 oracle。附支持类、超参数、逐用户差值、最差用户与原始中心误差；负结果不删。
3. 补充 F1 仅作描述：全部查询在实际存在类和固定12输出两种口径计算；未校准类在其真实标签对应的查询上计算，只平均该折未校准类。报告这是补充而非原先筛选门槛。
4. B 主表包含七固定子集、每折验证选出的固定1/2/3路、固定随机混合、主置信度/熵级联及不可部署 oracle。完整固定模型和条件执行策略状态分别报告。显示平均路数的实际值，不能只显示验证预算。
5. B 按真实动作与 G12（零基11）空类分别给出描述，避免节省仅来自空类。HV2 的 G12 已被质量排除，不填造。收益分解保留单路错后修正、单路对后改错、两条额外路径都无效但完整三路才有效的例数。
6. 跨 A/B 路线只在 A 预定固定查询 ID（共7440条）上另做全部已知类描述性比较，使用同一个外层折对应的模型，逐位核对 ID/标签。B 的主门槛仍用其全部9300条外层测试观测，不能借跨路线表改门槛。
7. 延迟按 LATENCY_PROTOCOL 直接执行，引用测量边界、batch、硬件、样本数、mean/median/p95。训练成本从八折日志重算，Right基础训练与后续多雷达训练分别列出；统计拟合和策略训练另列。训练日志单epoch计时并非整个项目耗时，注明不含队列等待和额外审计。
8. 保存可机读 JSON、CSV、中文 REPORT.md、复现命令和简洁静态图。图来自真实数据，检查文字/坐标/渲染。至少显示 A 逐用户配对效应和 B 准确率—处理路数；oracle 图例明确“使用真实标签，不能部署”。
9. 明确只有8位研发用户、单种子、无外部/跨天/连续流确认；外层用户在不同折之间循环出现，区间只是探索性用户重采样描述。策略内部复用编码器验证用户选权重/拟合策略的限制单列。固定七子集来自一个共享网络，并非七个分别优化模型的极限。
10. 依据实际停止门槛作路线判断。没有通过时如实记录“本先导未找到可作为主创新的有效机制”，不把固定融合的工程价值、oracle 空间或事后挑选参数称为创新成立。文献支持研究问题和候选机制，不作为本数据集有效性的证据。

与整个项目衔接时，对照 proposal_v2/30 的现有三点。预算选视角曾被放在内容二，若把它升格为新内容一，就应把内容二收束为未知动作拒识与少样本注册，避免两个研究点重复计算同一贡献。此处只提出结构调整建议，原 Word 和旧路线文档保留。第一部分已看过全部12类的分类器不能直接充当第二部分“从未见过未知类”的编码器，必须按后者词表重新训练/校准。

当前两条路线使用同一 UWB 片段数据；不借此声称已有真实连续流或跨天验证。既有第三点使用的其他数据集与本次第一部分先导分开。低秩机制的失败不证明全部个性化失败；14维后验状态上的单个固定收益预测器若失败，也不证明任何已观测信号都无法预测新增视角价值。

旧稿30引用的“自适应省22.7%”需澄清口径：其来源24第3.2节X2b是逐样本 oracle 的留出视角测距误差中位数从固定策略降至66.8 mm的相对改善，不是已训练可部署策略的准确率收益，也不是推理路数/时延减少22.7%。新报告不能继承旧稿30中简写造成的误解；本轮预算、准确率与延迟必须分别由当前产物算出。

策略隔离的准确说法：拟合收益模型、选择价格只依赖验证用户；selection先保存再进入该策略的目标评价。是否启动策略的预定oracle机会门槛及其独立重算确实使用测试标签，所以不能写成“策略运行前从未读取任何目标文件/标签”，也不能将条件先导当作未经任何探索的独立确认。

oracle 的范围是当前冻结分类器、验证选出的首路、仅向包含首路的子集追加观测这一动作族；允许分数随机化以满足平均成本。它不是所有重新训练分类器、允许丢弃已见视角或任意感知策略的普适信息上界。
