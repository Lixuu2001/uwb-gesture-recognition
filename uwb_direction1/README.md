工具使用 Python 标准库，Python 3.9+，不要求安装新的深度学习环境。`transfer.py pack` 只读取原项目，代码快照和数组分块写到另一个目录；`restore` 在云端恢复并核对原文件 SHA256。原始数组、权重和中间训练恢复文件不进入普通 Git。

目录 `original/` 由本地迁移脚本生成。当前没有该目录，不能将本分支误认为已经包含原项目代码。`memory/recovered/` 是从历史聊天中的文件创建记录恢复的旧文档，注明来源，未在本次重新运行其所述实验。

云端工具检查：

```bash
python -m unittest discover -s uwb_direction1/tests -v
```

数据到达后先验证来源、原始 9593 条记录与质量筛选后的 9300 条记录的对应关系，恢复旧预处理与基线，再冻结新候选方案。软件检查通过、合成数据往返通过都不能算手势方法有效。
